<a id="L8"></a>**L8**　在计委领导小组汇报第三个五年计划时的一些插话

<a id="L9"></a>**L9**　（一九六四年五月十一日）

<a id="L10"></a>**L10**　一、搞计划要把朝、越的一些需要打进去，听说越南要××万吨油。

<a id="L11"></a>**L11**　二、一九六五年不一定有七亿二千万人口吧！一九七○有八亿？不得了。

<a id="L12"></a>**L12**　三、知识分子很重要，没有不行。理论要知识分子，理论没有知识分子不行。但是知识分子还是要总结下面的东西。

<a id="L13"></a>**L13**　四、国民经济的两个拳头，一个屁股。基础工业是一个拳头，国防工业是一个拳头，农业是屁股。

<a id="L14"></a>**L14**　五、现在的苏联是资产阶级专政，大资产阶级专政，德国法西斯专政，希特勒式的专政，是一帮流氓，比戴高乐还坏。

<a id="L15"></a>**L15**　六、所有的单位，工厂、街道、学校、机关都要划阶级。

<a id="L16"></a>**L16**　七、工资问题。再减上面的工资有困难。今后采取上面不动，下面逐步增加的办法。

<a id="L17"></a>**L17**　八、工业为谁服务？工业要为农业服务。当然，重工业之间有一个相互关系问题，但是整个工业是为农业服务的。

<a id="L18"></a>**L18**　九、稳产、高产是相对的，去年河北大雨是天老爷下的，没有办法。天老爷真难当，下多了不是，下少了也不是。

<a id="L19"></a>**L19**　十、有多少力，办多少事。不要以个人来决定。“我这个人老啦，快死啦，在我死以前，要干出什么……”这不对。

<a id="L20"></a>**L20**　十一、我要把二十四史看完。《旧唐书》比《新唐书》好，《南史》、《北史》比《旧唐书》又好些，最不满意的是《明史》。

<a id="L21"></a>**L21**　十二、工厂划阶级的目的，在于暴露那百分之一、二、三、四、五，工人中不是工人阶级出身的有百分之八至十五。
