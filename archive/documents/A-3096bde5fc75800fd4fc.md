<a id="L9"></a>**L9**　（一九四六年四月二十日）

<a id="L10"></a>**L10**　亲爱的战友们，不朽的英雄们：

<a id="L11"></a>**L11**　数十年间，你们为人民的事业做了轰轰烈烈的工作。今天，你们为人民事业而死，虽死犹生！

<a id="L12"></a>**L12**　你们的死是一个号召，它将加深中国人民对中国共产党的认识，它将加强中国人民坚持和平、民主、团结事业的决心。

<a id="L13"></a>**L13**　你们的死是一个号召，它将号召全党党员和全国人民团结起来，为和平、民主、团结的新中国而奋斗到底。

<a id="L14"></a>**L14**　全党党员和全国人民，将继承你们的遗志，继续奋斗，直到胜利，决不懈怠，决不退缩！

<a id="L15"></a>**L15**　毛泽东

<a id="L16"></a>**L16**　（一九四六年四月二十日《解放日报》）
