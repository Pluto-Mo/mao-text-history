<a id="L9"></a>**L9**　（一九六七年七月）

<a id="L10"></a>**L10**　有了错误就检讨就改正，改了就好了，只要讲三句话就行了。一句话：错了；二句话：是什么错就是什么错，在这个问题上或那个问题上是方向错了就承认这个问题上方向错了；第三句话：就改正。这样就好了。公开检查比不公开好，高姿态检查比低姿态好，早检查比晚检查好。

<a id="L11"></a>**L11**　（摘自××在1967年7月7日在昆明讲话）

<a id="L12"></a>**L12**　军队这几年群众工作做得少，错了改了就好，也不给处分，也不要治罪。
