<a id="L8"></a>**L8**　“五一”节和张×的谈话

<a id="L9"></a>**L9**　（一九六七年五月一日）

<a id="L10"></a>**L10**　五月一日晚上十点三十五分在天安门城楼上，江青同志向毛主席、林副主席单独引见了张×，接见时周总理也在座。

<a id="L11"></a>**L11**　毛主席、林副主席和张×亲切握手。毛主席红光满面，神采奕奕，身体非常健康。这是中国人民和世界人民的最大幸福。

<a id="L12"></a>**L12**　江青同志向毛主席．林付主席介绍说：这是国家科委张×，她们把韩光一伙打倒了，她们那里运动搞得不错。

<a id="L13"></a>**L13**　毛主席说：应该祝科委同志们万寿无疆，应该祝人民万寿无疆！

<a id="L14"></a>**L14**　毛主席又说：女同志也一样造反嘛！你们把反革命韩光打倒了，你们夺权夺得好！

<a id="L15"></a>**L15**　接着主席又亲切地问：你现在担任什么工作？

<a id="L16"></a>**L16**　张×同答说：在国家科委革命委员会工作。

<a id="L17"></a>**L17**　毛主席问：是革命委员会主任吧？

<a id="L18"></a>**L18**　周总理说：也就是了吧！

<a id="L19"></a>**L19**　这时，毛主席向林副主席说：她原来是个局长，和群众一起造反。
