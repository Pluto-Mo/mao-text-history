<a id="L9"></a>**L9**　（一九一五年）

<a id="L10"></a>**L10**　毛主席在第一师范求学期间，读了当时很多进步书刊。当他看了《明耻篇》以后，义愤填胸，来自挥笔在书上写道：

<a id="L11"></a>**L11**　“五月七日，

<a id="L12"></a>**L12**　国民奇耻；

<a id="L13"></a>**L13**　何以报仇，

<a id="L14"></a>**L14**　在我学子！”

<a id="L15"></a>**L15**　这十六个字充分表现了主席青少年时就立下了以天下为己任的革命的雄心壮志。
