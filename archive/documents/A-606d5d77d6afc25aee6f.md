<a id="L9"></a>**L9**　（一九六七年一月）

<a id="L10"></a>**L10**　接管是不可避免的。

<a id="L11"></a>**L11**　我们这个政府，过去是上面派去少数干部和下面大多数留用人员组成了政府，不是工人、农民起来闹革命夺得了政府，这就很容易产生封建主义、修正主义的东西。

<a id="L12"></a>**L12**　（谢副总理说：我们老一点的同志，对这个运动不理解，从开始就不理解，到现在还不理解，转不过弯来。）

<a id="L13"></a>**L13**　转不过弯来靠边站，但给饭吃。

<a id="L14"></a>**L14**　（谢副总理说：昨天向主席谈到，联合行动委员会有许多高干子弟。）这是阶级斗争。（摘自谢副总理一九六七年一月十七日对公安干部的讲话）
