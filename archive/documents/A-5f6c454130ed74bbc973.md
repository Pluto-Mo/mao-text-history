<a id="L2"></a>**L2**　中文马克思主义文库

<a id="L3"></a>**L3**　-&gt;

<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东接见法国事务部长马尔罗时的谈话

<a id="L6"></a>**L6**　（1965年8月3日）

<a id="L7"></a>**L7**　【安德烈·马尔罗（André Malraux，1901-1976），小说家，评论家。1923年，他偕同第一个夫人去远东游历。这一时期，他和当时越南、中国、苏联的革命者有过频繁接触。广州起义失败，国共两党联合破裂以后，马尔罗于1927年返回法国。他和高尼利昂·莫利尼策划对沙特阿拉伯进行了一次袭击。之后，他与另一作家安德烈·纪德极力替被德国纳粹分子诬告为纵火焚烧国会大厦主谋的保加利亚革命领导人季米特洛夫辩护。这时，他被选为世界反法西斯委员会主席。1936年，他加了支援西班牙共和国的国际纵队，担任外国空军部队的总指挥。第二次世界大战期间，马尔罗领导好几支游击队，在1945年解放阿尔萨斯的战役中，担任阿尔萨斯·洛林纵队总指挥。法国光复后，他在政治上一直与戴高乐将军紧密地站在一起。1945年~1946年，担任新闻部长。1947年~1952年间，是人民联盟的全国代表。1958年6月1日起担任法国总统府国务部长，后兼任文化部长。】

<a id="L8"></a>**L8**　毛

<a id="L9"></a>**L9**　：马尔罗先生来了多久了？

<a id="L10"></a>**L10**　马

<a id="L11"></a>**L11**　：十五、六天了。见了陈毅副总理，到延安等地去了一次，回来后见了周恩来总理。

<a id="L12"></a>**L12**　毛

<a id="L13"></a>**L13**　：喔，你到了延安。

<a id="L14"></a>**L14**　马

<a id="L15"></a>**L15**　：这次去延安，使我学到很多中国革命的历史情况，比过去知道得多，我今天能坐在除了列宁之外当代最伟大的革命家的旁边，感到很激动。

<a id="L16"></a>**L16**　毛

<a id="L17"></a>**L17**　：你说得太好了。

<a id="L18"></a>**L18**　马

<a id="L19"></a>**L19**　：我在延安看到了过去的艰苦环境，人们都住在窑洞里，我也看到了蒋介石住宅的相片，对比一下就知道中国革命为什么会成功。

<a id="L20"></a>**L20**　毛

<a id="L21"></a>**L21**　：这是历史发展的规律，弱者总是能战胜强者的。

<a id="L22"></a>**L22**　马

<a id="L23"></a>**L23**　：我也是这样想的。我也曾领导过游击队，不过当时的情况不能同你们的比。

<a id="L24"></a>**L24**　毛

<a id="L25"></a>**L25**　：我听说了，你打过游击。

<a id="L26"></a>**L26**　马

<a id="L27"></a>**L27**　：我在法国中部打过游击，领导农民军队反对德国军队。

<a id="L28"></a>**L28**　毛

<a id="L29"></a>**L29**　：十八世纪末法国革命推翻了封建统治。当时推翻封建统治的那些力量最初也不是强的，而是弱的。

<a id="L30"></a>**L30**　马

<a id="L31"></a>**L31**　：这很有意思，农民都没有打过仗，不知如何打，但他们能当很好的战士。拿破仑手下就有很多这样的战士。我认为在毛主席之前，没有任何人领导农民革命获得胜利。你们是如何启发农民这么勇敢的？

<a id="L32"></a>**L32**　毛

<a id="L33"></a>**L33**　：这个问题很简单。我们同农民吃一样的饭，穿一样的衣，使战士们感到我们不是一个特殊阶层。我们调查农村阶级关系，没收地主阶级的土地，把土地分给农民。

<a id="L34"></a>**L34**　马

<a id="L35"></a>**L35**　：主席是否认为重要的是土地改革？

<a id="L36"></a>**L36**　毛

<a id="L37"></a>**L37**　：土地改革、民主政治。此外还有一条，要打赢仗。如打不赢仗，谁听你的话？打败仗总是有的，但少要一点败仗，多打一点胜仗。

<a id="L38"></a>**L38**　马

<a id="L39"></a>**L39**　：在两千多年的历史中，农民习惯于打败仗，打胜仗的不多。

<a id="L40"></a>**L40**　毛

<a id="L41"></a>**L41**　：我们打过胜仗，也打过败仗，甚至整个南方根据地都失掉了，跑到北方来。

<a id="L42"></a>**L42**　马

<a id="L43"></a>**L43**　：尽管如此，但人民对红军的怀念仍然存在。

<a id="L44"></a>**L44**　毛

<a id="L45"></a>**L45**　：以后在北方建立了很多根据地，发展了军队，发展了党，发展了群众组织，北方人民得到了土地。我们解放了北京、天津、济南等大城市。队伍逐渐扩大到几百万，由北方向南方打。要讲经验还有一条，就是在中国要把民族资产阶级、资产阶级知识分子团结起来。团结民族资产阶级和资产阶级知识分子中凡是不跟敌人跑的人。我们在一个时期甚至跟大资产阶级蒋介石建立了统一战线。如果蒋介石不进攻我们，我们也不会进攻他。

<a id="L46"></a>**L46**　马

<a id="L47"></a>**L47**　：为什么蒋介石要进攻你们呢？

<a id="L48"></a>**L48**　毛

<a id="L49"></a>**L49**　：他想把我们吞掉，他以为他可以。

<a id="L50"></a>**L50**　马

<a id="L51"></a>**L51**　：他是否认为中国共产党很弱？

<a id="L52"></a>**L52**　毛

<a id="L53"></a>**L53**　：我们有很多根据地，人口占全国五分之一，军队有一百万左右。蒋介石却不同，他有四百多万军队，有美国的援助。我们的根据地很大，但根据地是分散的，也没有外部的援助。

<a id="L54"></a>**L54**　马

<a id="L55"></a>**L55**　：是不是还有一个原因，即蒋介石只相信城市的力量？

<a id="L56"></a>**L56**　毛

<a id="L57"></a>**L57**　：他有城市，有外国的援助，同时他在农村的人口比我们多。

<a id="L58"></a>**L58**　马

<a id="L59"></a>**L59**　：我曾去过俄国，曾同高尔基谈过这个问题，同他谈到了毛泽东，那时您还不是主席。高尔基说：中国共产党最大的困难是没有大城市。当时我问他：没有大城市，是会失败还是会成功？

<a id="L60"></a>**L60**　毛

<a id="L61"></a>**L61**　：高尔基当时回答了你没有？（马尔罗摇头）他不知道中国的情况，所以不能答复你。

<a id="L62"></a>**L62**　马

<a id="L63"></a>**L63**　：高尔基常说各地的农民都一样。但我认为每个地方的情况不一样。

<a id="L64"></a>**L64**　现在我提一个问题：中国再一次要把中国变成为伟大的中国。几世纪前，中国从技术上来说是强国，如丝绸。后来欧洲变成技术上先进的国家，有武器、军火。现在的中国也有了武器、军火，又要成为强国了。当然中国不需要成为欧洲式的强国。中国要成为中国式的强国，不知需要什么东西？

<a id="L65"></a>**L65**　毛

<a id="L66"></a>**L66**　：需要时间。

<a id="L67"></a>**L67**　马

<a id="L68"></a>**L68**　：我们希望你们有你们需要的充实的时间。

<a id="L69"></a>**L69**　毛

<a id="L70"></a>**L70**　：至少需要几十年。我们还需要朋友。例如同你们往来，建立外交关系，这就是朋友的关系。我们有各种朋友，你们就是朋友的一种。同时在北京访问的印度尼西亚共产党主席艾地，也是我们的朋友。我们还没有见到他。我们同艾地有共同点，同你们也有共同点。

<a id="L71"></a>**L71**　马

<a id="L72"></a>**L72**　：这些共同点是不一样的。

<a id="L73"></a>**L73**　毛

<a id="L74"></a>**L74**　：有一些是一样的。例如如何对待美帝国主义，对付英国的两面派。你们比英国明朗。

<a id="L75"></a>**L75**　马

<a id="L76"></a>**L76**　：实际上反对美国在越南“逐步升级”的只有法国。

<a id="L77"></a>**L77**　陈毅

<a id="L78"></a>**L78**　：英国人支持美国侵略越南，而你们反对。

<a id="L79"></a>**L79**　马

<a id="L80"></a>**L80**　：英国有马来西亚问题。

<a id="L81"></a>**L81**　毛

<a id="L82"></a>**L82**　：英美俩要交换。

<a id="L83"></a>**L83**　马

<a id="L84"></a>**L84**　：从戴高乐总统恢复政权后，法国已结束了它的殖民主义立场。每年援助阿尔及利亚几亿法朗，是我亲自去非洲四国宣布他们独立的。在戴高乐总统看来，中、法有一个绝对的共同点：如果有苏、美双重世界霸权，那么，中国要成为一个真正的中国和法国要成为一个真正的法国，是办不到的。

<a id="L85"></a>**L85**　毛

<a id="L86"></a>**L86**　：当然罗，一个是你们的盟国，一个是我们的盟国。你们的盟国美国，对你们是不怀好意的。我们的盟国苏联，对我们也不怀好意。

<a id="L87"></a>**L87**　马

<a id="L88"></a>**L88**　：列宁死后，人们谈到苏联时就会想起斯大林。斯大林死后，斯大林的制度被推翻了，至少部分被推翻了。但苏联领导人却假说苏联的制度没有改变。赫鲁晓夫就是这样亲自告诉我的。我认为现在的制度不同了，尽管用的词一样，但是内容很不同了。

<a id="L89"></a>**L89**　毛

<a id="L90"></a>**L90**　：他还进一步说要建设共产主义，这是斯大林都没有说过的。

<a id="L91"></a>**L91**　马

<a id="L92"></a>**L92**　：我感到赫鲁晓夫和柯西金使人想到似乎不是过去所理想的苏联了。

<a id="L93"></a>**L93**　毛

<a id="L94"></a>**L94**　：他是代表一个阶层的利益，不是代表广大人民的利益。

<a id="L95"></a>**L95**　马

<a id="L96"></a>**L96**　：他们甚至改变了政府行政管理的方法。

<a id="L97"></a>**L97**　毛

<a id="L98"></a>**L98**　：苏联想走资本主义复辟的道路，对这一点，美国是很欢迎的，欧洲也是欢迎的，我们是不欢迎的。

<a id="L99"></a>**L99**　马

<a id="L100"></a>**L100**　：难道主席真正认为他们想回到资本主义道路？

<a id="L101"></a>**L101**　毛

<a id="L102"></a>**L102**　：是的。

<a id="L103"></a>**L103**　马

<a id="L104"></a>**L104**　：我认为他们在想办法远离共产主义，但他们要往那里走，去找什么，连他们自己思想上也不清楚。

<a id="L105"></a>**L105**　毛

<a id="L106"></a>**L106**　：他们就是用这样一种糊里糊涂的方法迷惑群众，他们也有自己的经验。法国社会党难道真搞社会主义？法国共产党人真信马克思主义？

<a id="L107"></a>**L107**　马

<a id="L108"></a>**L108**　：法国社会党员中只剩下百分之七是工人，其余主要是职员。在这方面他们是强大的，因为有工会，是由职员们组成的。另外，还有一些党员是南方葡萄种植园主，是地主。至于说法国共产党，法国共产主义者，则是另外一个问题。法国农民的作用同中国的不一样，不只是绝对少数，占人口比例也不及中国。法国的共产主义者要起作用，只有两种可能：一是在知识分子中寻找力量，一是在真正无产者中间寻找力量。法国的共产主义者可能在感情上偏向中国，但因具体情况不同于中国，因而实际上又偏向于苏联。

<a id="L109"></a>**L109**　毛

<a id="L110"></a>**L110**　：他们是反对我们的。

<a id="L111"></a>**L111**　马

<a id="L112"></a>**L112**　：作为一个党是反对中国的，但工人、知识分子、农民并不反对中国，目前党内冲突很严重。法共就像最懒的人一样，两面都想应付，你们可能已看到很多这种情况了。

<a id="L113"></a>**L113**　陈毅

<a id="L114"></a>**L114**　：他们并没有应付我们。

<a id="L115"></a>**L115**　毛

<a id="L116"></a>**L116**　：党是可以变化的。普列汉诺夫和孟什维克过去都是马克思主义者，后来就反对列宁，反对布尔什维克，脱离了人民。现在是在布尔什维克本身内部发生了变化。中国也有两个前途，一种是坚决走马列主义的道路，一种是走修正主义的道路，我们有要走修正主义道路的社会阶层，问题看我们如何处理。我们采取了一些措施，避免走修正主义道路。但谁也不能担保，几十年后走什么道路。

<a id="L117"></a>**L117**　马

<a id="L118"></a>**L118**　：现在中国修正主义阶层是否广泛存在？

<a id="L119"></a>**L119**　毛

<a id="L120"></a>**L120**　：相当广泛，人数不多，但有影响。这些是旧地主、旧富农、旧资本家、知识分子、新闻记者、作家、艺术家以及他们的一部分子女。

<a id="L121"></a>**L121**　马

<a id="L122"></a>**L122**　：为什么有作家？

<a id="L123"></a>**L123**　毛

<a id="L124"></a>**L124**　：有一部分作家的思想是反马克思主义的，我们把旧的摊子都接受下来了。我们原来没有艺术家、记者、作家、教授、教员。这些人都是国民党留下来的。

<a id="L125"></a>**L125**　佩耶

<a id="L126"></a>**L126**　：我有一个感觉，中国青年正朝着主席所主张的方向在培养中。

<a id="L127"></a>**L127**　主席

<a id="L128"></a>**L128**　：你来了多久了？

<a id="L129"></a>**L129**　佩耶

<a id="L130"></a>**L130**　：十四个月了，从广州到北京一路上学了许多东西。以后参加使节旅行，去过华中、华南、荣幸地访问了主席的故乡韶山，还到过长沙、四川。最近又到东北去了一次，很有意思。我在工厂、公社、街上、戏院都尽量同人民接触，感到青年人没有那些要你们操劳的矛盾。

<a id="L131"></a>**L131**　毛

<a id="L132"></a>**L132**　：你看了一个方面的现象，另一方面的现象没有注意到。一个社会不是一个单体，是个复杂的社会，存在着两种可能性。

<a id="L133"></a>**L133**　佩耶

<a id="L134"></a>**L134**　：我感到有一种力量引导青年，使他们走向你们所指出的方向。矛盾当然还会有，但是方向肯定了。

<a id="L135"></a>**L135**　毛

<a id="L136"></a>**L136**　：一定有矛盾。

<a id="L137"></a>**L137**　马

<a id="L138"></a>**L138**　：主席看，在反对修正主义方面，下一步的目标是什么？我指在国内方面。

<a id="L139"></a>**L139**　毛

<a id="L140"></a>**L140**　：那就是反对修正主义，没有别的目标。我们反对贪污、盗窃、投机商人，反对修正主义的一切基础。不只是党外，党内也有。

<a id="L141"></a>**L141**　马

<a id="L142"></a>**L142**　：下一步的目标是什么，例如举行党代表大会就要确定一个目标。是否是农业问题，因为我感到工业问题已解决了，或起码是走上健全道路了。

<a id="L143"></a>**L143**　毛

<a id="L144"></a>**L144**　：工业和农业问题都没有解决。

<a id="L145"></a>**L145**　马

<a id="L146"></a>**L146**　：我在西安参观了纺织厂，在法国纺织厂同革命有很大关系。一七八九、一八三○、一八四○、一八五一年都是这样，特别在里昂。因为纺织工人是最穷困的。我在西安看到该地的纺织业已达到解放前上海的水平，大部分机器是中国造的，机器多，工人少。显然中国党能在纺织工业中执行它要执行的政策。但相反在农业方面，可耕地很少，使中国政府处境困难。现在农业方面是否考虑发动一次超过人民公社范围的大规模的运动？

<a id="L147"></a>**L147**　毛

<a id="L148"></a>**L148**　：人民公社在组织机构和生产关系方面不会有什么改变，在技术方面开始有了改变。

<a id="L149"></a>**L149**　马

<a id="L150"></a>**L150**　：你考虑可增加些耕地面积？

<a id="L151"></a>**L151**　毛

<a id="L152"></a>**L152**　：可增加一些，主要的还是增加单位面积的产量，这里有很多文章可作。今天就不多谈了。请回去问候你们的总统。

<a id="L153"></a>**L153**　马

<a id="L154"></a>**L154**　：关于外交政策的问题，我已同周总理、陈副总理谈过了，不再向主席重复了。今天谈的是戴高乐总统阁下最关心的基本问题。感谢今天的接见，并转达戴高乐总统对阁下的问候。

<a id="L155"></a>**L155**　（出门时）

<a id="L156"></a>**L156**　毛
