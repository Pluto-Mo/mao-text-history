<a id="L10"></a>**L10**　毛岸英是毛主席的儿子，他在苏联住过莫斯科大学，最近才从苏联回来。毛主席对他说：

<a id="L11"></a>**L11**　“你住过苏联的大学，还没有住过边区劳动大学，劳动大学的校长就是×××，劳动大学就在吴家枣园，那里的学生，都是爱劳动的人民，你去学习，对你有很大的帮助。”毛岸英愿意去。毛主席说：

<a id="L12"></a>**L12**　“去很好，还要带些学费去。”毛主席给了一斗米，叫毛岸英背上走，走到吴家枣园，累得他满头大汗。

<a id="L13"></a>**L13**　（原载晋冀鲁豫《人民日报》一九四六年十一月十五日第三版）
