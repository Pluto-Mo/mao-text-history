<a id="L9"></a>**L9**　（一九六三年二月二十三日）

<a id="L10"></a>**L10**　（苏修大使契尔沃年科求见主席，主席称不适。因再三要求，主席着睡衣接见。）

<a id="L11"></a>**L11**　契：听说你们要发表文章，不必要的，感到很沉重。

<a id="L12"></a>**L12**　主席：不必要，你们为什么发表那么多文章？没有什么沉重的，不过互相论战，不过是唇枪舌箭而已。

<a id="L13"></a>**L13**　契：请你到莫斯科去谈一谈，可以吗？

<a id="L14"></a>**L14**　主席：我已经老了，不中用了。老而不死，破套鞋去不成了。
