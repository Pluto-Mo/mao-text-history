<a id="L2"></a>**L2**　中文马克思主义文库

<a id="L3"></a>**L3**　-&gt;

<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东会见阿尔及利亚革命委员会主席布迈丁谈话记录节选

<a id="L6"></a>**L6**　（1974年2月25日）

<a id="L7"></a>**L7**　【胡阿里·布迈丁（Houari Boumediene，1925～1978）阿尔及利亚国务活动家，民族解放战争中的总参谋长，独立后的首任国防部长，1965年发动不流血政变废黜本·贝拉，任革命委员会主席兼总理、1976年任总统。任内大力发展经济，实行不结盟外交政策，在伊斯兰世界中反美反犹，是第三世界和北非的一个相当有影响的人物。】

<a id="L8"></a>**L8**　主席

<a id="L9"></a>**L9**　：你看欧洲安全会议的前途怎么样呢？

<a id="L10"></a>**L10**　布

<a id="L11"></a>**L11**　：欧洲安全这个问题从一开始就提错了。我们的观点是，安全问题不能在狭窄的范围内得到解决。正如你刚才所说的，地中海的确介乎欧洲和阿拉伯世界之间。欧洲安全问题和地中海联系在一起，所以关系到中东，关系到阿拉伯世界。

<a id="L12"></a>**L12**　主席

<a id="L13"></a>**L13**　：就是。欧洲安全，阿拉伯世界不安全，地中海问题不解决，那怎么行呢？

<a id="L14"></a>**L14**　布

<a id="L15"></a>**L15**　：唯一的解决办法就是所有的国家都获得真正独立。不仅阿拉伯国家，而且欧洲国家，都要摆脱出来。不容易解决，但又不是不可能解决的，主要取决于有关国家有没有这个决心。

<a id="L16"></a>**L16**　主席

<a id="L17"></a>**L17**　：几十个国家怎么能取得一致？单是欧洲就有多少个国家，三十几个国家。

<a id="L18"></a>**L18**　布

<a id="L19"></a>**L19**　：一切都取决于利益。

<a id="L20"></a>**L20**　主席

<a id="L21"></a>**L21**　：如果是听两个大国——美国跟苏联，这也不行吧。

<a id="L22"></a>**L22**　布

<a id="L23"></a>**L23**　：我们认为只要哪里有美国人和俄国人，哪里就有分歧。当然，我不知道最高级领导人之间是否已达成某种协议，所以向毛主席提出这个问题。

<a id="L24"></a>**L24**　主席

<a id="L25"></a>**L25**　：协议可能有，但是我看不那么巩固。一是暂时的，同时是骗人的。骨子里头还是争夺为主。

<a id="L26"></a>**L26**　布

<a id="L27"></a>**L27**　：面对这种情况怎么办？

<a id="L28"></a>**L28**　主席

<a id="L29"></a>**L29**　：我看会打仗。

<a id="L30"></a>**L30**　布

<a id="L31"></a>**L31**　：是热核战争吗？

<a id="L32"></a>**L32**　主席

<a id="L33"></a>**L33**　：那还不能定。总而言之，将来总有一天会要打的，我的看法。争夺的结果最后可能会武力解决，暂时还不会。现在都在讲和平。

<a id="L34"></a>**L34**　布

<a id="L35"></a>**L35**　：我能向毛主席提个问题吗？面对这种形势，中国的态度如何？

<a id="L36"></a>**L36**　主席

<a id="L37"></a>**L37**　：准备打仗！

<a id="L38"></a>**L38**　布

<a id="L39"></a>**L39**　：我们国家太小了，没有办法对付大国。

<a id="L40"></a>**L40**　主席

<a id="L41"></a>**L41**　：你们不小，你们把法国人赶走了，越南人也把美国问题解决了，朝鲜人民民主共和国也把美国军队赶到南边去了。现在美国到处霸了地方，它要保护这些地方，力量就分散。苏联要对付的地方也多，欧洲、地中海、阿拉伯世界、中东……

<a id="L42"></a>**L42**　布

<a id="L43"></a>**L43**　：对不起，我插一句话，有人说还有中国。

<a id="L44"></a>**L44**　主席

<a id="L45"></a>**L45**　：有南亚、有中国、有日本、有美国，太平洋的美国。它的事情也不好办呢。现在世界上的舆论我看要研究一下，就是不要真正相信所谓的永久和平。我跟法国朋友讲得多了，要他们准备打。第二次世界大战到现在快三十年了，再有三十年不打仗就是六十年了。

<a id="L46"></a>**L46**　布

<a id="L47"></a>**L47**　：是否在你看来，战争一定是周期性的？

<a id="L48"></a>**L48**　主席

<a id="L49"></a>**L49**　：这个社会制度不改变，战争不可避免，不是相互之间的战争，就是人民起来革命。

<a id="L50"></a>**L50**　布

<a id="L51"></a>**L51**　：尽管美苏间生活水平差距很大，但苏联竭力想赶上美国，这是否构成美苏接近的因素？

<a id="L52"></a>**L52**　第二个问题是，第三世界的人民都钦佩中国，但是它们都向自己提出这样的问题，即面对美国人和俄国人，中国所起的作用是什么？

<a id="L53"></a>**L53**　主席

<a id="L54"></a>**L54**　：准备它们在世界上闹事。绝不相信持久和平，或者说所谓一代人的和平。一代人的和平，六十年，可见得第二代人，他就不讲了。

<a id="L55"></a>**L55**　布

<a id="L56"></a>**L56**　：你是指我们这一代，还是指她（指唐闻生）这一代？

<a id="L57"></a>**L57**　主席

<a id="L58"></a>**L58**　：就是说，第二次世界大战以后，已经过了三十年了。再有三十年，就是六十年了。

<a id="L59"></a>**L59**　（对齐宗华）你们的讲法跟英国人的讲法有很大的不同呢。（按指法文同英文中“六十”的讲法不一样。）

<a id="L60"></a>**L60**　（对布）这个问题，我提给你和你的朋友们作为参考。总而言之，我不相信所谓持久和平。至于打不打原子武器，可能打，也可能不打。第二次世界大战，美国对日本打过，但是后头在朝鲜战争，就没有打。在越南战争，也没有打。在中东，以色列也好，埃及也好，美国人跟俄国人也没有援助他们原子武器。

<a id="L61"></a>**L61**　有一位你们最初的领导人到过北京，叫什么名字？

<a id="L62"></a>**L62**　总理

<a id="L63"></a>**L63**　：阿巴斯。

<a id="L64"></a>**L64**　布

<a id="L65"></a>**L65**　：阿巴斯是临时政府的第一任总理。他还活着，经营药店。

<a id="L66"></a>**L66**　总理

<a id="L67"></a>**L67**　：他的年纪比较大了。

<a id="L68"></a>**L68**　布

<a id="L69"></a>**L69**　：是的，岁数比较大一点。他是革命某一个阶段的代表。他从来不是社会主义者，并公开宣布这一点。他现在身体很好，还在工作。

<a id="L70"></a>**L70**　主席

<a id="L71"></a>**L71**　：今天你们还有什么事啊？

<a id="L72"></a>**L72**　总理

<a id="L73"></a>**L73**　：今天谈了两个钟头，他谈得多。

<a id="L74"></a>**L74**　主席

<a id="L75"></a>**L75**　：今天你就休息吧。每一天也不要过于累了。

<a id="L76"></a>**L76**　布

<a id="L77"></a>**L77**　：我想不会太累。我来就是为了看望你，同你谈一谈，看望一些老朋友和中国人民，并且了解你们的巨大成就。今天我能够认识你，对我来说是一个伟大的日子。

<a id="L78"></a>**L78**　主席

<a id="L79"></a>**L79**　：中国成就有一点，但是不大，你可以了解了解。（对总理）大概跟他们的水平差不多吧。

<a id="L80"></a>**L80**　总理

<a id="L81"></a>**L81**　：按人口比例比他们的水平低。

<a id="L82"></a>**L82**　主席

<a id="L83"></a>**L83**　：比较低。

<a id="L84"></a>**L84**　布

<a id="L85"></a>**L85**　：我们要落后得多，在很多方面，我们都要向你们学习。不仅是物质方面，还有别的方面，人民的经验，这是最主要的。

<a id="L86"></a>**L86**　主席

<a id="L87"></a>**L87**　：经验嘛，我们犯过许多错误，犯了错误就改正。

<a id="L88"></a>**L88**　布

<a id="L89"></a>**L89**　：主要是你们的作法好。

<a id="L90"></a>**L90**　主席

<a id="L91"></a>**L91**　：有时候工作方法比较好，有时候不大好。如果片面地介绍中国，说怎么好，那是不妥的。当然，说中国是一片黑暗，也是不对的。光明面是主要的，但是有时候有黑暗这一面。我们下面的工作人员就爱吹他的成绩，而不爱把自己的错误讲出来，所以你们要注意。我们这个教育老是不大好，叫他们两方面都介绍，往往办不到。

<a id="L92"></a>**L92**　布

<a id="L93"></a>**L93**　：我想，世界上只有中国才能进行这种革命中的革命。

<a id="L94"></a>**L94**　主席

<a id="L95"></a>**L95**　：也难说呢。别国大体也是如此，总是有光明的一面，也有缺点。

<a id="L96"></a>**L96**　这个世界上是有帝国主义存在。我们看呢，俄国也叫社会帝国主义，这种社会制度也就酝酿着战争。不是你们要打世界战争，我们要打，第三世界要打世界战争，也不是这些富国的人民想要打世界大战，这种东西是不以人们的意志为转移的。谁想到希特勒几乎统一了欧洲，又失败了。谁想到第一次世界大战中间又产生了十月革命。中国在第二次世界大战末尾把日本、又把蒋介石赶走了。

<a id="L97"></a>**L97**　布

<a id="L98"></a>**L98**　：近几十年中发生的最伟大的事件，就是中国的崛起。我们认为本世纪最伟大的事，就是中国站了起来。第三世界的国家对中国抱有很大的希望。

<a id="L99"></a>**L99**　主席

<a id="L100"></a>**L100**　：这个问题可能如此，但是还要等待以后的历史学家来评论。

<a id="L101"></a>**L101**　总理

<a id="L102"></a>**L102**　：中国革命也是受十月革命的影响。现在又在反对苏修社会帝国主义。

<a id="L103"></a>**L103**　布

<a id="L104"></a>**L104**　：我认为中国属于第三世界，不知道主席是否同意我这个看法。很抱歉，我提的问题太多了。

<a id="L105"></a>**L105**　主席

<a id="L106"></a>**L106**　：我跟你的看法一样，中国属于第三世界。因为政治、经济、各方面，中国不能跟富国、大国比，只能跟一些比较穷的国家在一起。

<a id="L107"></a>**L107**　今天谈到这里，可以吗？
