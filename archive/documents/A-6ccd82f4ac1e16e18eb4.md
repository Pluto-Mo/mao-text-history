<a id="L195"></a>**L195**　（B）北伐中之农民参战

<a id="L196"></a>**L196**　一、供给：北伐军所经地方，农民即均能供给饮料，或少数之食粮，代为煮饭等事。

<a id="L197"></a>**L197**　二、向导，侦探：此种工作，沿株萍路，浏阳、平江、长沙湘潭、宁乡、衡山、南县、华容等处均有。

<a id="L198"></a>**L198**　三、运输：农民自动受军队雇请运输者之外，有组织的替军队运输之事亦有。

<a id="L199"></a>**L199**　四、扰乱敌军后方：湘潭、平江、南县、浏阳、沿株萍一带等处皆有。

<a id="L200"></a>**L200**　五、参加战斗：死伤[人]数及夺得枪枝尚无精确统计，大略如左：

<a id="L201"></a>**L201**　A、株州：唐军二次攻入长沙时，农民与叶斗，缴枪百余，及机关枪大炮等。

<a id="L202"></a>**L202**　B、醴陵：北伐军入长沙时，农民夺枪二百余及机关大炮等，十一月赣方败兵入醴时，农民缴枪甚多。

<a id="L203"></a>**L203**　C、平江：七月北伐军入平，农民参战死二十五人，夺枪数百枝及机关枪等。十一月二师兵变，农民围缴变兵枪二百五十枝，现政府要收此枪，农民反对，正在相持中。

<a id="L204"></a>**L204**　D、浏阳：农民救出被围北伐军一团，击退敌溃兵，有死伤，并夺得枪枝。

<a id="L205"></a>**L205**　E、华容：一次蔡鉴军入华容，农民与驻军共同击退，二次蔡鉴入华容，农民三千余人单独击退蔡军。

<a id="L206"></a>**L206**　F、沅江：华容第一次击蔡军时，沅江农民参加。

<a id="L207"></a>**L207**　G、湘潭：农民设疑兵，助北伐军过河，攻击溃兵等。

<a id="L208"></a>**L208**　H、宁乡：救出被围北伐军一团，攻击溃兵，夺得枪枝。

<a id="L209"></a>**L209**　I、株萍沿路：与敌军冲突毁铁道。

<a id="L210"></a>**L210**　[J]、长沙：围攻溃退军官，助政府围缴溃兵变兵。

<a id="L211"></a>**L211**　六、农民参战之原因：

<a id="L212"></a>**L212**　A、党人宣传的效果，农民都知道北伐军是拥护工农利益的，要援助北伐军胜利，农民然后才能得到利益。

<a id="L213"></a>**L213**　B、对北兵叶军之仇视，两方军纪比较，使农民仇视更深。

<a id="L214"></a>**L214**　C、受农民协会的指挥（有最少数是自动的）。

<a id="L215"></a>**L215**　D、在九十月中农民之愿意参加战争，则为欲得到枪枝，因此时农民武装的要求已经起来了。

<a id="L216"></a>**L216**　七、农民参战之影响：

<a id="L217"></a>**L217**　A、农民政治观念之进步。

<a id="L218"></a>**L218**　B、农民自信力进步。

<a id="L219"></a>**L219**　C、使政府认识农民力量，影响政府左倾。

<a id="L220"></a>**L220**　（C）现在农民的倾向

<a id="L221"></a>**L221**　（一）农民已觉得他们参战有功，需要报酬了，就是没有参战的各县，也觉得党人的宣传应该兑现了。

<a id="L222"></a>**L222**　（二）经济的要求：这种要求已普遍了有农运的各县，下面的要求是最普遍。

<a id="L223"></a>**L223**　一、减租——还没有不纳租的（耕地农有）要求。

<a id="L224"></a>**L224**　二、减息——从八九分息减到四五分也就满足了。

<a id="L225"></a>**L225**　三、解决荒月食粮问题——形成了普遍的平粜阻禁运动。

<a id="L226"></a>**L226**　四、减捐税——少数地方有不纳捐税的要求。

<a id="L227"></a>**L227**　五、减押金，及不得无故退佃等——尚无明确的观念。

<a id="L228"></a>**L228**　这些要求可说是很低，都是他们直接的，有些地方是各种要求都已起来，少数地方还只觉得一二种。在湘南近广东广西一带农民的要求，比湘中一带较高。

<a id="L229"></a>**L229**　（三）政治的要求：

<a id="L230"></a>**L230**　一、改造团防——他们对团防局人还非常注意。

<a id="L231"></a>**L231**　二、反抗都团——许多地方都团已经失了作用，毁打都团总的事甚多。

<a id="L232"></a>**L232**　三、希望一个好的政府。

<a id="L233"></a>**L233**　农民的经济和政治要求，可说都还是非常幼稚。县长民选等口号农民固然没有感到，就是乡村的政治要求，也还只有消极的；至于反动派所造的“没收土地”“组织工农政府”这类谣言，更是连影子也没有。

<a id="L234"></a>**L234**　（四）武装要求：农民武装要求，现在日见急迫了。他们都愿从溃兵变兵手中夺得枪枝，如此次平江农民的留枪运动（见前参战情形）非常激烈。

<a id="L235"></a>**L235**　（D）农民已起来的斗争

<a id="L236"></a>**L236**　（一）减租运动：

<a id="L237"></a>**L237**　一、衡阳的减租运动：衡阳的租额，表面是说东佃各半，实际上佃户得不到半数。自从民国五年因大水和增加教育经费的关系，全县渐次普遍[增]加了租，增加的数目虽然不是一律，却是没有不加的。这样一来，佃户所得，比从前原来不及五成的数目更少了。自唐离湖南以后，衡阳加入了农协的农民就有很迫切的减租要求。于是提出全县复租的口号，就是要恢复五年以前（民国五年以前）的租额。结果，全县都得恢复了民五以前的租额。农民在此运动中加入农协者，约七万人。同时反动分子也就在这次运动中团结起来了。这次运动可说是全县农民加入协会的和未加入协会的都参加了。

<a id="L238"></a>**L238**　二、各地的减租情形：除衡阳外，各地只有零碎的减租运动，某一个佃农民对某个田主减租。因为各地每当更换佃户或田地易主之时增加租额，有时加得太多的，佃户即请求减少。这种事实经农协替农民解决的甚多。这虽不是一个斗争，然农民因此对农协增加信仰。

<a id="L239"></a>**L239**　三、减租运动，本为各地农民急迫的要求，但收租期间已过，故未发生斗争。一般农民的观念，都以为明年减租的问题为有一番大斗争。

<a id="L240"></a>**L240**　（二）减息运动：

<a id="L241"></a>**L241**　一、安化已全县普遍减息成功，未发生特别反动。约由月息七八分减为四五分。农民亦认为满足。

<a id="L242"></a>**L242**　二、岳阳一部分农民的减息运动，尚未结果，大约可胜利。

<a id="L243"></a>**L243**　三、湘阴牛洲农民要求免欠息失败。

<a id="L244"></a>**L244**　四、各县都有减息运动皆无大冲突。

<a id="L245"></a>**L245**　（三）减押运动：

<a id="L246"></a>**L246**　一、浏阳全县减押金为每租谷一石，押金二元，已成功。但此后是否将有冲突，尚难断定。

<a id="L247"></a>**L247**　二、岳阳一部分湖田，地主拟租每石增加押金七元，农民已起而反抗，地主亦联络三县团对付，此事将有大冲突。

<a id="L248"></a>**L248**　三、各县尚有小的减押运动。

<a id="L249"></a>**L249**　（四）减税运动：

<a id="L250"></a>**L250**　一、攸县，醴陵，宜章，皆有减税运动。

<a id="L251"></a>**L251**　二、安乡已将全县亩捐取消，但增加田赋附加。

<a id="L252"></a>**L252**　三、岳阳一部分农运要求取消亩捐与团防冲突，尚未结果。

<a id="L253"></a>**L253**　（五）[垦]荒运动：

<a id="L254"></a>**L254**　安化农民要求在冬月由农民自由种杂粮不纳租。一部分已成功。一部分尚在争持中。

<a id="L255"></a>**L255**　（六）平粜阻禁问题：

<a id="L256"></a>**L256**　一、起因：连年湖南均有灾荒，每到荒月，乡村中均缺乏食粮或食粮暴涨，于是形成了一种农民平粜阻禁运动。

<a id="L257"></a>**L257**　二、这个运动，可说是有农民组织的地方十之七八都有了，不过形式各有不同罢了。约有下列的各种形式：

<a id="L258"></a>**L258**　A，由农协或由乡民会议，议决谷价，不得高于此价卖谷。

<a id="L259"></a>**L259**　B，议定两种或三种谷价，并决定一种人吃某一种谷价。

<a id="L260"></a>**L260**　C，有限止的运谷米出境。

<a id="L261"></a>**L261**　D，谷米一概不准运出境。

<a id="L262"></a>**L262**　E，待荒月再议谷价，现时不议。

<a id="L263"></a>**L263**　F，只留租谷的几成。

<a id="L264"></a>**L264**　三、这个斗争引起来的冲突：

<a id="L265"></a>**L265**　A，闭粜：地主不粜谷，则强迫粜谷。甚至罚钱殴打。

<a id="L266"></a>**L266**　B，偷运：发觉偷运则将谷充公或罚钱。

<a id="L267"></a>**L267**　C，因议谷价而引起冲突。

<a id="L268"></a>**L268**　四、影响：地主商人都发生了大的恶感，即大自耕农，佃农亦不愿此办法，政府催还田赋，地主即推谷卖不出，政府对此举亦甚不满意。

<a id="L269"></a>**L269**　五、省农协的政策已决定只准留一部分租谷以备荒月之平粜，不准无限制的阻禁。但已成群众心理，一时甚难改变。

<a id="L270"></a>**L270**　（七）与团防的冲突：

<a id="L271"></a>**L271**　一、宁乡团防局长（在乡分局）已皆由乡民会议选举，及有农协组织之处，农民均极注意人选。

<a id="L272"></a>**L272**　二、岳阳。

<a id="L273"></a>**L273**　A，团局禁止农民开会，冲突，农民请愿结果，团局解散。

<a id="L274"></a>**L274**　B，农民为抗亩捐与团防冲突，尚未结束。

<a id="L275"></a>**L275**　C，两团防冲突，击毙农民十余人。

<a id="L276"></a>**L276**　三、嘉禾团防枪毙农民。

<a id="L277"></a>**L277**　四、桂阳反动派勾结团防调兵入城解散农民协会。

<a id="L278"></a>**L278**　五、资兴团防强迫改组农民协会。

<a id="L279"></a>**L279**　六、湘潭农民反抗团防斗殴枪杀农民一人。

<a id="L280"></a>**L280**　七、牛洲（岳阳）团防禁止农民组织协会。

<a id="L281"></a>**L281**　八、各地均有农民与团防冲突之事，多为团防胜利。

<a id="L282"></a>**L282**　（八）与土豪劣绅的冲突：

<a id="L283"></a>**L283**　农民与土豪劣绅的冲突，可以说是无时无地没有了。土豪劣绅对农民之进攻，也是一天一天的利害起来。农民对他们殴打，控告，游乡，罚款，驱逐，无一不有。自然多数是由他们对农民进攻而引起民众的愤怒。

<a id="L284"></a>**L284**　（E）乡村政权情形

<a id="L285"></a>**L285**　（一）有些乡村已由农协取了政权。

<a id="L286"></a>**L286**　（二）乡民会议在许多县中都有了，可以为乡村最高立法组织。有少数县中的团防局长和乡董等，也可由乡民会议选举。

<a id="L287"></a>**L287**　（三）有少数地方有农协教联商协工会等联合的组织取得了乡村政权。

<a id="L288"></a>**L288**　（四）有许多地方乡村政权已为国民党党部取得，同情或赞助农运。

<a id="L289"></a>**L289**　（五）多数地方仍由土豪劣绅把持以压迫农民。有农民协会的地方则时时发生冲突。

<a id="L290"></a>**L290**　（F）农民自卫的组织

<a id="L291"></a>**L291**　（一）湘南各县因唐生智的提倡，都有挨户团的组织。这种组织的指挥机关虽然是在绅士地主们手中，却团员及下层指挥人都是农民。在有农民协会的地方，自然不费力的成了农民的组织。挨户团没有枪械，多有梭镖（一种尖刀接以长柄的武器）鸟枪马刀等。多数有定期的操演，且有操演费。（每次每人约五百文）湘中各县如平江浏阳长沙……一带也有此种组织，但不普遍，且无操演费。他们此次参战及防匪，都能显出很大的作用。组织人数无统。

<a id="L292"></a>**L292**　（二）湖南的农民，除挨户团以外，没有别种自卫组织。虽然以前有农民自卫军，自卫团等名称，皆因经费无法解决而停止了。

<a id="L293"></a>**L293**　（三）平江，安化，醴陵，湘潭……等处，农民夺有少数枪枝（平江有二百五十枝，尚有问题未解决）这都可拿出来作农民自卫之用。

<a id="L294"></a>**L294**　（G）土豪劣绅之破坏农运

<a id="L295"></a>**L295**　各地土豪劣绅及一切反动势力，都渐渐团结起[来]了。他们对农民进攻约有下列各形式：

<a id="L296"></a>**L296**　一、秘密组织保富会保产会白化党三等：公开组织区董联合会，乡镇联合会。

<a id="L297"></a>**L297**　二、宣传农协是将要抽丁，抽人头税，吴佩孚来了是会杀头以恐吓农民，使之不能加入农协。

<a id="L298"></a>**L298**　三、他们宣传农协共产，行什么三三一制。

<a id="L299"></a>**L299**　四、组织假农民协会，发表宣言主张什么三三一制。

<a id="L300"></a>**L300**　五、混入农协包办，包办不成则捣乱。

<a id="L301"></a>**L301**　六、收买，煽动，或提倡乡土观念，宗法思想，迷信，使农民起来反对农协。

<a id="L302"></a>**L302**　七、混入国民党压迫农民，包办农协。

<a id="L303"></a>**L303**　八、宣传北伐军失败。

<a id="L304"></a>**L304**　九、与民右派，赵，孙勾结。

<a id="L305"></a>**L305**　十、假装农民暴动捣乱毁税局，以便各方对农运失掉同情。

<a id="L306"></a>**L306**　十一、利用团防等直接压迫农民，屠杀农民，解散农协。

<a id="L307"></a>**L307**　他们这些破坏手段，各处都似有联络的进行。
