<a id="L1"></a>**L1**　毛泽东会见美国总统尼克松的谈话（1972年2月21日）

<a id="L2"></a>**L2**　中文马克思主义文库

<a id="L3"></a>**L3**　-&gt;

<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东会见美国总统尼克松的谈话

<a id="L6"></a>**L6**　（1972年2月21日）

<a id="L7"></a>**L7**　毛主席

<a id="L8"></a>**L8**　：昨天你在飞机上给我们出了一个难题，说是我们几个要吹的问题限于哲学方面。（众笑）

<a id="L9"></a>**L9**　尼克松

<a id="L10"></a>**L10**　：我之所以这样说，是因为读了主席的诗词和讲话，我知道主席是一位思想深刻的哲学家。

<a id="L11"></a>**L11**　毛主席

<a id="L12"></a>**L12**　：（指基辛格）他是博士。

<a id="L13"></a>**L13**　尼克松

<a id="L14"></a>**L14**　：主席的著作感动了全国，改变了世界。

<a id="L15"></a>**L15**　毛主席

<a id="L16"></a>**L16**　：没有改变世界，只改变了北京附近几个地方。我们共同的老朋友，就是说蒋介石委员长，他不赞成。他说我们是“共匪”，他最近还发表了一篇讲话。

<a id="L17"></a>**L17**　周总理

<a id="L18"></a>**L18**　：就是在他们最近召开的“国会”上。

<a id="L19"></a>**L19**　尼克松

<a id="L20"></a>**L20**　：蒋介石把主席叫作“共匪”，那么主席把他叫作什么呢？

<a id="L21"></a>**L21**　周总理

<a id="L22"></a>**L22**　：我们一般叫蒋介石集团，新闻里面有时也叫匪。

<a id="L23"></a>**L23**　毛主席

<a id="L24"></a>**L24**　：那还不是匪？彼此叫匪，互相对骂。其实我们跟他作朋友的时间比你们跟他作朋友的时间长得多。

<a id="L25"></a>**L25**　周总理

<a id="L26"></a>**L26**　：从1924年开始。

<a id="L27"></a>**L27**　毛主席

<a id="L28"></a>**L28**　：不要由我们两人包办了。不让博士发表声明怎么行呢？你跑中国跑出了名嘛。头一次来，公告发表以后，全世界都震动了。

<a id="L29"></a>**L29**　尼克松

<a id="L30"></a>**L30**　：是的。

<a id="L31"></a>**L31**　基辛格

<a id="L32"></a>**L32**　：那是总统指出了方向，制订了计划。

<a id="L33"></a>**L33**　尼克松

<a id="L34"></a>**L34**　：讲这样的话助理是很聪明的。

<a id="L35"></a>**L35**　毛主席

<a id="L36"></a>**L36**　：（笑，面向基辛格）他夸奖你了。

<a id="L37"></a>**L37**　尼克松

<a id="L38"></a>**L38**　：从外表看，他并不像一个完成秘密使命的人（secret agent）。但他在受包围（incaptivity）的情况下却秘密到巴黎去了12次，到中国来了1次。而这些事只有他和一些漂亮的姑娘知道。

<a id="L39"></a>**L39**　基辛格

<a id="L40"></a>**L40**　：我利用姑娘来作掩护。

<a id="L41"></a>**L41**　毛主席

<a id="L42"></a>**L42**　：讲老实话，这个民主党如果再上台，我们也不能不同它打交道。

<a id="L43"></a>**L43**　尼克松

<a id="L44"></a>**L44**　：当然，这点我理解。重要的不是这个问题。但我们希望不给你们造成这样的形势。

<a id="L45"></a>**L45**　毛主席

<a id="L46"></a>**L46**　：我的问题是哲学问题，就是说，你当选我是投了一票的。

<a id="L47"></a>**L47**　我们这里有个美国人叫柯弗兰，他写了一个材料，当时你们正在闹得天翻地覆的时候。

<a id="L48"></a>**L48**　周总理

<a id="L49"></a>**L49**　：正在竞选的时候。

<a id="L50"></a>**L50**　毛主席

<a id="L51"></a>**L51**　：他说你会当选，我很欣赏那篇文章。这回请你来，他又不赞成。你看怪不怪？（笑）

<a id="L52"></a>**L52**　尼克松

<a id="L53"></a>**L53**　：我想主席投我一票，是在两个坏东西中间选择好一点的一个。

<a id="L54"></a>**L54**　毛主席

<a id="L55"></a>**L55**　：我是喜欢右派。人家说你们是右派，说你们共和党是右派。

<a id="L56"></a>**L56**　尼克松

<a id="L57"></a>**L57**　：是的。

<a id="L58"></a>**L58**　毛主席

<a id="L59"></a>**L59**　：说英国的希思首相是右派。

<a id="L60"></a>**L60**　尼克松

<a id="L61"></a>**L61**　：还有法国的戴高乐。

<a id="L62"></a>**L62**　毛主席

<a id="L63"></a>**L63**　：戴高乐是另一个问题。

<a id="L64"></a>**L64**　说西德的基督教民主党也是右派。我是喜欢右派，比较高兴这些右派当政。

<a id="L65"></a>**L65**　尼克松

<a id="L66"></a>**L66**　：我想重要的是，在美国，至少现在像我这样的右派可以做那些左派只能口头上说说的事情。

<a id="L67"></a>**L67**　（毛主席点头）

<a id="L68"></a>**L68**　基辛格

<a id="L69"></a>**L69**　：总统先生，我觉得左边的人是亲苏的，他们不鼓励我们向人民共和国这边移动，而且批评你这样做。

<a id="L70"></a>**L70**　毛主席

<a id="L71"></a>**L71**　：就是罗。

<a id="L72"></a>**L72**　我们国内有一派也反对我们跟你们往来，结果坐一架飞机跑到外国去了。

<a id="L73"></a>**L73**　全世界的侦察就只有美国的比较准确，其次就是日本。苏联就在那里挖尸。（笑）

<a id="L74"></a>**L74**　周总理

<a id="L75"></a>**L75**　：In outer mongolia（在外蒙）。

<a id="L76"></a>**L76**　毛主席

<a id="L77"></a>**L77**　：但又不吭声。（笑）

<a id="L78"></a>**L78**　尼克松

<a id="L79"></a>**L79**　：我在最近的印巴危机中也遇到了类似的问题。在美国，左派疯狂地批评我，说我没有站在印度一边。他们之所以这样做，首先是因为他们亲印度，其次是因为他们亲苏联。我认为重要的是要看到更大的问题，即不能允许一个国家，虽然它也许是一个大国，去吞并邻国。在这里就是指巴基斯坦。

<a id="L80"></a>**L80**　我因此受到了损失，但我并不为此而难过，因为我认为我做得正确。我在政治上蒙受了损失，但历史会证明我是正确的。

<a id="L81"></a>**L81**　毛主席

<a id="L82"></a>**L82**　：但是你们搞那个吹风会，是不是少搞一点？我这是作为一个建议。比如我跟你吹的这些东西，统统吹出去，好不好呢？这些哲学问题？

<a id="L83"></a>**L83**　尼克松

<a id="L84"></a>**L84**　：主席可以放心，我们之间或者我和总理之间谈的事情除非双方都同意，不会超出这个房间的范围。在最高一级进行讨论时，就应该限制在这一级。

<a id="L85"></a>**L85**　毛主席

<a id="L86"></a>**L86**　：这个好。

<a id="L87"></a>**L87**　尼克松

<a id="L88"></a>**L88**　：我们在这个房间的保密范围内要问问自己，为什么苏联在同中国的边界上的兵力比在同西欧边界上的兵力要多。……

<a id="L89"></a>**L89**　既然总理指出，他感到美国在伸手，苏联在伸手，那么问题是，人民共和国面临的危险，是来自美国的侵略，还是来自苏联的侵略？这是一个困难的问题，但是我们要讨论这个问题。

<a id="L90"></a>**L90**　毛主席

<a id="L91"></a>**L91**　：来自美国方面的侵略，或者来自中国方面的侵略，这个问题比较小，也可以说不是大问题，因为现在不存在我们两个国家互相打仗的问题。你们想撤一部分兵回国，我们的兵也不出国。所以我们两家也怪得很，过去22年总是谈不拢，现在从打乒乓球tabll tennis起不到10个月，如果从你们在华沙提出建议时算起，两年多了。

<a id="L92"></a>**L92**　我们办事也有官僚主义。你们要搞人员往来这些事，搞点小生意，我们就死不肯。十几年，说是不解决大问题，小问题不干，包括我在内。后来发现还是你们对，所以就打乒乓球。

<a id="L93"></a>**L93**　周总理

<a id="L94"></a>**L94**　：这也是在尼克松总统就任以后。

<a id="L95"></a>**L95**　毛主席

<a id="L96"></a>**L96**　：巴基斯坦前总统介绍你和我们认识。那时候我们驻巴基斯坦的大使死反对跟你往来，说是有个比较，还是民主党的那位前总统约翰逊，还是你尼克松，究竟哪个比较好。叶海亚说，不能比，一个是流氓。

<a id="L97"></a>**L97**　周总理

<a id="L98"></a>**L98**　：就是说约翰逊。

<a id="L99"></a>**L99**　毛主席

<a id="L100"></a>**L100**　：也不晓得他怎么得出这个印象。我们这方面也不那么高兴那位总统（注：指约翰逊）。从杜鲁门到约翰逊，我们也都不那么高兴。这个中间有8年的共和党，那个时候你们也没有想通。
