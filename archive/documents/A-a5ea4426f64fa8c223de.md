<a id="L9"></a>**L9**　（一九六四年十二月十五日下午）

<a id="L10"></a>**L10**　（注：方括号内为刘××讲话的有关内容）

<a id="L11"></a>**L11**　〔有些地方提出，出现了新生的资产阶级分子。〕

<a id="L12"></a>**L12**　叫新生资产阶级分子，农民不容易懂，还是叫贪污盗窃、投机倒把分子好，农民懂得。

<a id="L13"></a>**L13**　〔加强社教工作队的领导问题。战线是不是要缩短些？〕

<a id="L14"></a>**L14**　要短容易，收缩嘛！

<a id="L15"></a>**L15**　〔关于农村整党、建党问题〕

<a id="L16"></a>**L16**　我早就赞成。……

<a id="L17"></a>**L17**　〔要发展一批党员〕

<a id="L18"></a>**L18**　还是从贫下中农、工人积极分子中去发展党。

<a id="L19"></a>**L19**　〔下边借反资本主义来反对贫下中农〕

<a id="L20"></a>**L20**　让他搞嘛！你不让他搞，他憋不住。要反群众，他就暴露出来了。

<a id="L21"></a>**L21**　〔机关干部家属中有不少四类分子，要清理。这是个普遍的问题。〕

<a id="L22"></a>**L22**　反革命、恶霸、四类分子，就那么多嘛！几千万，几百万，分散各地，总是少数。只有那么多，有是有，清是要清，多是不多。

<a id="L23"></a>**L23**　〔领导干部蹲点，还是蹲在大队的好。〕

<a id="L24"></a>**L24**　抓中间，吃两头。

<a id="L25"></a>**L25**　〔这次社教运动中，有些地方还查出不少黑地。〕

<a id="L26"></a>**L26**　我看瞒百分之二十——三十就算好的。

<a id="L27"></a>**L27**　〔我看查出来，过三、五年再征购。〕粮食五年到十年不征购，以后增产再增购一些。粮食还是存在老百姓家里好，否则，阻止人家报黑地。

<a id="L28"></a>**L28**　〔要把干部不脱离生产的制度固定下来。〕

<a id="L29"></a>**L29**　反官僚主义，要跟班生产。

<a id="L30"></a>**L30**　〔科室人员有半天的工作时间也就够了。〕

<a id="L31"></a>**L31**　还要注意文牍主义。

<a id="L32"></a>**L32**　能够四、五小时劳动，厂长、党委书记事就少了，开会、文件也会少了，工作就能做好了。

<a id="L33"></a>**L33**　（会议结束时）我们的会议，每天下午三点半开大会，大家可以在大会上发言。上午开小会。你们如果秘密谈，出简报我也不看。你们要畅所欲言，冲口而出。讲的不对，有什么要紧？大家可以原谅嘛！
