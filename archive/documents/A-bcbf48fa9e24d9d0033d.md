<a id="L10"></a>**L10**　××同志和各位同志：

<a id="L11"></a>**L11**　慧书早已收到，迟复为歉！遵嘱将记得起来的旧体诗词，连同你们寄来的八首，一共十八首，抄寄如另纸，请加审处。

<a id="L12"></a>**L12**　这些东西，我历来不愿意正式发表，因为是旧体，怕谬种流传，遗误青年；再则诗味不多，没有什么特色。既然你们以为可以刊载，又可为已经传抄的几首改正错字，那么，就照你们的意见办吧。

<a id="L13"></a>**L13**　诗刊出版，很好，祝它成长发展。诗当然应以新诗为主体，旧诗可以写一些，但是不宜在青年中提倡，因为这种体裁束缚思想，又不易学。这些话仅供你们参考。

<a id="L14"></a>**L14**　同志的敬礼，

<a id="L15"></a>**L15**　毛泽东
