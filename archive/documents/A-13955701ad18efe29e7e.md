<a id="L9"></a>**L9**　（一九六七年三、八月）

<a id="L10"></a>**L10**　一、注释现在不要修改，这些人名都不要删掉，这些都是历史。没有司马炎、司马师、司马昭，何以成为“晋史”？

<a id="L11"></a>**L11**　二、《关于若干历史问题的决议》写得不好，可以不收。

<a id="L12"></a>**L12**　三、《整顿党的作风》中引用刘少奇的一段话没有必要，可以删去。

<a id="L13"></a>**L13**　四、新印《毛选》，仍用原来的日期。

<a id="L14"></a>**L14**　五、《毛选》五、六两卷，一年以后再说，现在你们没有时间，我也没有时间。

<a id="L15"></a>**L15**　六、《语录》第二○八页引用刘少奇的话的一段也删去；第二○八页标题“思想意识修养”改为“纠正错误思想”。

<a id="L16"></a>**L16**　（1967年3月16日，对《毛选》注释诸问题请示的答复）
