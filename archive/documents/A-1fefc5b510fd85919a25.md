<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东会见扎伊尔共和国总统蒙博托谈话记录节选

<a id="L6"></a>**L6**　（1973年1月13日）

<a id="L7"></a>**L7**　【约瑟夫·德西雷·蒙博托（Mobutu，1930—1997），扎伊尔总统、人民革命运动主席。1997年5月29日被赶下台，在他掌权32年中，巧取豪夺，聚敛了40亿美元的家产。他私人拥有丰富的铜矿、钻矿、金刚石矿等矿产资源，直接出卖国家所有的矿产，成了蒙博托敛财的第一手段。他是黑非洲国家典型的个人专制和个人崇拜者，是现代非洲三大食人魔王之一。】

<a id="L8"></a>**L8**　毛主席

<a id="L9"></a>**L9**　：怎么样，跑到北京住得惯吗？

<a id="L10"></a>**L10**　蒙

<a id="L11"></a>**L11**　：很好。在这里对我们的欢迎是非常友好、热烈的。

<a id="L12"></a>**L12**　毛主席

<a id="L13"></a>**L13**　：卢蒙巴，他没有来过。

<a id="L14"></a>**L14**　蒙

<a id="L15"></a>**L15**　：对。他没有来得及来。

<a id="L16"></a>**L16**　毛主席

<a id="L17"></a>**L17**　：我们是支持他的。我们还支持几个，有基赞加、谬勒尔，就是不支持你！（笑）

<a id="L18"></a>**L18**　蒙

<a id="L19"></a>**L19**　：我知道。还有一些和他们在一起的。

<a id="L20"></a>**L20**　毛主席

<a id="L21"></a>**L21**　：还有一些打游击的，给他们钱和武器。就是他们不会打，打你不赢啊，那我有啥办法啊！

<a id="L22"></a>**L22**　蒙

<a id="L23"></a>**L23**　：因为面对他们的是蒙博托这样有魄力的人。

<a id="L24"></a>**L24**　毛主席

<a id="L25"></a>**L25**　：因为你这个帽子（指蒙戴的豹皮帽）把他们吓住了（众笑）。

<a id="L26"></a>**L26**　蒙

<a id="L27"></a>**L27**　：不是，是我的权威。

<a id="L28"></a>**L28**　毛主席

<a id="L29"></a>**L29**　：他们那些人我看不怎么样。不少人都在外国，不到国内去，不了解情况。

<a id="L30"></a>**L30**　蒙

<a id="L31"></a>**L31**　：是这样的。

<a id="L32"></a>**L32**　毛主席

<a id="L33"></a>**L33**　：不是我们不革命，是他们自己不争气，打你不赢有啥办法啊。

<a id="L34"></a>**L34**　蒙

<a id="L35"></a>**L35**　：而且他们不仅自己不争气，还用全部时间来欺骗把他们看作朋友的人。

<a id="L36"></a>**L36**　毛主席

<a id="L37"></a>**L37**　：现在都完了吧。被你打得呜乎哀哉了吧。

<a id="L38"></a>**L38**　蒙

<a id="L39"></a>**L39**　：现在扎伊尔是非洲中心的一个大国，享有和平，是一个巩固的国家。扎伊尔的儿女们联合起来了，拥护一个领袖，一个政党。刚才说的事情已经过去了。

<a id="L40"></a>**L40**　毛主席

<a id="L41"></a>**L41**　：过去了吗？

<a id="L42"></a>**L42**　蒙

<a id="L43"></a>**L43**　：是的，这些都已经过去了，所以我们才能坐在一起共同庆祝中扎友谊。

<a id="L44"></a>**L44**　毛主席

<a id="L45"></a>**L45**　：怎么叫扎伊尔？

<a id="L46"></a>**L46**　蒙

<a id="L47"></a>**L47**　：这是我们国家原来的名字，叫扎伊尔，后来比利时殖民主义的国王利奥波德二世把它改为刚果。

<a id="L48"></a>**L48**　蒙

<a id="L49"></a>**L49**　：相反，我不怕，而且主张和平共处。

<a id="L50"></a>**L50**　毛主席

<a id="L51"></a>**L51**　：我不主张和平共处，主张革命！

<a id="L52"></a>**L52**　蒙

<a id="L53"></a>**L53**　：我也在革命，用我的方式来革命。

<a id="L54"></a>**L54**　毛主席

<a id="L55"></a>**L55**　：讲是那样讲，什么和平共处，五项原则，酝酿的一条就是世界要革命！

<a id="L56"></a>**L56**　蒙

<a id="L57"></a>**L57**　：我们也搞革命，但按照我们的方式。

<a id="L58"></a>**L58**　毛主席

<a id="L59"></a>**L59**　：各有各的方式。你们搞你们的方式，我们搞我们的方式。

<a id="L60"></a>**L60**　蒙

<a id="L61"></a>**L61**　：对。

<a id="L62"></a>**L62**　毛主席

<a id="L63"></a>**L63**　：不隐瞒自己的观点，不讲假话。

<a id="L64"></a>**L64**　蒙

<a id="L65"></a>**L65**　：我来这里后，注意到这一点了。

<a id="L66"></a>**L66**　毛主席

<a id="L67"></a>**L67**　：比如我们跟尼克松达成的公报嘛，……

<a id="L68"></a>**L68**　蒙

<a id="L69"></a>**L69**　：对，我读了好几遍。

<a id="L70"></a>**L70**　毛主席

<a id="L71"></a>**L71**　：就是各讲各的。有几处共同的，可以合作的。

<a id="L72"></a>**L72**　蒙

<a id="L73"></a>**L73**　：我也注意到这一点了。

<a id="L74"></a>**L74**　毛主席

<a id="L75"></a>**L75**　：美国人是看我们不起的。非洲人、亚洲人，他们都看不起。

<a id="L76"></a>**L76**　毛主席

<a id="L77"></a>**L77**　：我们支持反对你的人。你也不隐晦，照样讲。我们也不隐晦，照样讲。

<a id="L78"></a>**L78**　毛主席

<a id="L79"></a>**L79**　：现在呢，两国就要合作了。你讲和平共处，我也没法子反对了。

<a id="L80"></a>**L80**　感谢 佐仓绫奈 收集、录入及校对
