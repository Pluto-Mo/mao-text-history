<a id="L5"></a>**L5**　毛泽东会见斯里兰卡总理班达拉奈克夫人谈话记录节选

<a id="L6"></a>**L6**　（1972年6月28日）

<a id="L7"></a>**L7**　【班达拉奈克夫人，名西丽玛沃·拉特瓦泰·迪亚斯，（1916-2002），僧伽罗人，佛教徒，贵族出身，1940年与当时担任卫生和地方行政部长的所罗门·班达拉奈克结婚后，开始从事社会福利工作和政治活动。班达拉奈克夫人是60年代国际风云人物。她于1960年7月开创了由女子掌管一个国家军政大权的先例，成为人类历史上的第一位女总理，举世瞩目。1994年11月16日，78岁高龄的西丽玛沃·班达拉奈克夫人宣誓就任斯里兰卡新总理。这是她第三次出山，她因此成为世界上第一个三次荣登总理宝座的女人。】

<a id="L8"></a>**L8**　毛主席

<a id="L9"></a>**L9**　：有些人批评我们，说不帮助革命者。

<a id="L10"></a>**L10**　班

<a id="L11"></a>**L11**　：那些革命者中有一种印象，好像中国政府、苏联政府这些社会主义国家的政府都是支持他们的。这种印象是他们的领导人造成的。

<a id="L12"></a>**L12**　毛主席

<a id="L13"></a>**L13**　：其实他们不清楚，也难。

<a id="L14"></a>**L14**　我们这个国家也有人家骂我们，说是整了左派。我们的“左派”是什么一些人呢？就是火烧英国代办处的那些人。今天要打倒总理，明天要打倒陈毅，后天要打倒叶剑英。这些所谓“左”派现在都在班房里头。

<a id="L15"></a>**L15**　周总理

<a id="L16"></a>**L16**　：头子在班房里。他们（指斯里兰卡）那里最近放了8000多人。

<a id="L17"></a>**L17**　毛主席

<a id="L18"></a>**L18**　：那些年轻人是受骗的。

<a id="L19"></a>**L19**　我们这里早几年天下大乱，你还不知道呢。

<a id="L20"></a>**L20**　班

<a id="L21"></a>**L21**　：我听说了一点。

<a id="L22"></a>**L22**　毛主席

<a id="L23"></a>**L23**　：全国各地都打，全面内战，就是all-round civil war。现在好多了。

<a id="L24"></a>**L24**　班

<a id="L25"></a>**L25**　：就是自己人之间打内战吗？

<a id="L26"></a>**L26**　毛主席

<a id="L27"></a>**L27**　：两边都发枪，一共发了100万支枪吧。这一派军队支持这一派，那一派军队支持那一派，打。

<a id="L28"></a>**L28**　周总理

<a id="L29"></a>**L29**　：名义上是抢枪，实际上是送枪。

<a id="L30"></a>**L30**　毛主席

<a id="L31"></a>**L31**　：他们外交部，她们（指王、唐）这一派是“右”派，就是保守派，靠边站，弄得吃不下饭，睡不着觉。

<a id="L32"></a>**L32**　班

<a id="L33"></a>**L33**　：为什么？

<a id="L34"></a>**L34**　毛主席

<a id="L35"></a>**L35**　：被那些“左”派夺了权。一个月半，权不在我们手里，在那些所谓“左”派的手里。这些所谓左派，其实就是反革命。

<a id="L36"></a>**L36**　没有多少问题，几个月过去了，几年过去了，总后台的人现在也过去了，叫林彪。（班夫人点头）坐一架飞机往苏联去，其目的是想见上帝。

<a id="L37"></a>**L37**　班

<a id="L38"></a>**L38**　：见上帝？

<a id="L39"></a>**L39**　毛主席

<a id="L40"></a>**L40**　：是啊，摔下来了，见上帝去了。

<a id="L41"></a>**L41**　班

<a id="L42"></a>**L42**　：噢：我明白了。（众笑）后来飞机怎么样了？

<a id="L43"></a>**L43**　不大清楚。飞机掉下来了，还是过到苏联去了？

<a id="L44"></a>**L44**　毛主席

<a id="L45"></a>**L45**　：我也不知道。他自己要摔。

<a id="L46"></a>**L46**　毛主席

<a id="L47"></a>**L47**　：越“革命”越不好。世界上最“左”的最不好。你看英国的工党，法国的社会党，德国的社会民主党，这些都资产阶级化了。至于共产党，英国的共产党，法国的共产党，还有意大利的共产党，也不像话，天天骂我们，说我们是教条主义，它才是真马克思。你比如印度的共产党，有三四个党。马克思主义解散了。

<a id="L48"></a>**L48**　班

<a id="L49"></a>**L49**　：在我们国家也是这样，他们都说自己是马克思主义，但他们对马克思主义的解释都是按照他们各自的需要。

<a id="L50"></a>**L50**　毛主席

<a id="L51"></a>**L51**　：是啊，世界上的事情差不多，我们国家也是，我们这里马克思主义多得很，各说各都是真的，只有我是假的。他们给我取的名字叫B-52。

<a id="L52"></a>**L52**　班

<a id="L53"></a>**L53**　：那为什么？

<a id="L54"></a>**L54**　毛主席

<a id="L55"></a>**L55**　：说我无非是侵略和分化人家。又说我是秦始皇。秦始皇的名声历来不大好，因为他焚书坑儒。焚了一部分书，坑了460个知识分子。

<a id="L56"></a>**L56**　周总理

<a id="L57"></a>**L57**　：孔夫子那一派给秦始皇加了一个大罪名。

<a id="L58"></a>**L58**　毛主席

<a id="L59"></a>**L59**　：美国人也说我不好，说我比希特勒还要希特勒。

<a id="L60"></a>**L60**　班

<a id="L61"></a>**L61**　：美国人那么说吗？

<a id="L62"></a>**L62**　毛主席

<a id="L63"></a>**L63**　：过去的美国人，现在不说了。现在的美国人说我比希特勒稍微好一点。苏联也说我不好，说我是教条主义。

<a id="L64"></a>**L64**　他们（指苏联）的大使说，我们都是社会主义国家。我说不是，双方都不是社会主义。我们是教条主义，教条主义是反马克思主义的，这是你们说的，怎么还是社会主义？所以不是。我们给它一个名字，叫修正主义，所以也不是社会主义。所以我们两国在意识形态方面谈不来。

<a id="L65"></a>**L65**　他们先托罗马尼亚来讲和，后头托古巴来讲和，说是要停止公开论战。

<a id="L66"></a>**L66**　周总理

<a id="L67"></a>**L67**　：格瓦拉带队。

<a id="L68"></a>**L68**　毛主席

<a id="L69"></a>**L69**　：主要是罗德里格斯。我说，不能，要公开论战1万年，我是跟柯西金讲的。

<a id="L70"></a>**L70**　班

<a id="L71"></a>**L71**　：1万年，我们就看不到了。

<a id="L72"></a>**L72**　毛主席

<a id="L73"></a>**L73**　：我死了，有后人，后人死了，又有后人，争论一直继续下去，1万年。柯西金1965年来的时候说是太长了，too long，我说，你是苏联总理，为了你的面子，我减少一千年。你看，我的让步多大，一让就是一千年。

<a id="L74"></a>**L74**　班

<a id="L75"></a>**L75**　：那是很有意思。

<a id="L76"></a>**L76**　毛主席

<a id="L77"></a>**L77**　：我们跟赫鲁晓夫讲不来。他的接班人勃列日涅夫也说要讲和。他们经常在我们国家搞颠覆。勾结国防部长彭德怀搞颠覆，没成功。早就勾结刘少奇，也没成功。早就勾结林彪，又是一个国防部长，而且是我的“亲密战友”、“副统帅”。
