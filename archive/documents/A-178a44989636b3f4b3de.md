<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东接见蒙古人民革命党代表团谈话记录

<a id="L6"></a>**L6**　（未经本人审阅）

<a id="L7"></a>**L7**　（1956年9月24日）

<a id="L8"></a>**L8**　时　间

<a id="L9"></a>**L9**　：1956年9月24日

<a id="L10"></a>**L10**　参加人

<a id="L11"></a>**L11**　：

<a id="L12"></a>**L12**　蒙方

<a id="L13"></a>**L13**　：达姆巴（团长）、曾德、奥其尔巴特（大使）、哈什冈白、策热布又桑巴

<a id="L14"></a>**L14**　中方

<a id="L15"></a>**L15**　：王稼祥

<a id="L16"></a>**L16**　毛主席

<a id="L17"></a>**L17**　（以下简称主席）：这几天你们很累了吧？

<a id="L18"></a>**L18**　达姆巴

<a id="L19"></a>**L19**　（以下简称达）：不，不累，我们很舒服。

<a id="L20"></a>**L20**　主席

<a id="L21"></a>**L21**　：蒙古同志是好同志，好朋友。你们是友好的国家，友好的党！

<a id="L22"></a>**L22**　（接着主席就问候泽登巴尔）

<a id="L23"></a>**L23**　达

<a id="L24"></a>**L24**　：他很好，他跟桑布同志向您问候呢！

<a id="L25"></a>**L25**　主席

<a id="L26"></a>**L26**　：谢谢！请你们替我向他们问候！

<a id="L27"></a>**L27**　达

<a id="L28"></a>**L28**　：谢谢！我们感谢你们对我们的援助。

<a id="L29"></a>**L29**　主席

<a id="L30"></a>**L30**　：不，不要这样！中国是个大国，这是我们的义务，是我们的权利。我经常听到你们这样讲，同时经常看到文件上也这样写，我觉得心里不舒服。我们应该尽到自己的责任，因为三百年来我们的祖先曾剥削过你们、压迫过你们，他们曾留下了不少的债务，因此，今天我们要还这些债务。过去我国国内少数民族也同样受过压迫，我们对他们也要还债，这是我们的义务。

<a id="L31"></a>**L31**　我国藏族人口的120万人直接属于拉萨，其他100万人口分布于青海、云南、四川、甘肃等地。蒙古的宗教情况怎样？喇嘛多不多？总人口多少？

<a id="L32"></a>**L32**　达

<a id="L33"></a>**L33**　：过去很多，现在非常少了。在革命初期，有些喇嘛干过坏事情。将他们处理了，有一些参加了劳动以及其他工作。现在还有极少数的喇嘛。总人口80万。

<a id="L34"></a>**L34**　主席

<a id="L35"></a>**L35**　：蒙古工农业的发展情况如何？

<a id="L36"></a>**L36**　达

<a id="L37"></a>**L37**　：革命前我们是个很落后的国家，在革命的年代里，由于苏联的热情帮助，我国人民在工业方面、牲畜业方面以及文化教育方面都有了很好的进展。

<a id="L38"></a>**L38**　主席

<a id="L39"></a>**L39**　：蒙古农业也很发展了吧？

<a id="L40"></a>**L40**　达

<a id="L41"></a>**L41**　：今年刚开始发展农业。

<a id="L42"></a>**L42**　主席

<a id="L43"></a>**L43**　：水够不够？

<a id="L44"></a>**L44**　达

<a id="L45"></a>**L45**　：在我国水是很缺乏的。

<a id="L46"></a>**L46**　主席

<a id="L47"></a>**L47**　：雨量如何？

<a id="L48"></a>**L48**　达

<a id="L49"></a>**L49**　：平均年雨量是120至300毫米（其中森林地带是300毫米，而沙漠地区是120毫米）。

<a id="L50"></a>**L50**　主席

<a id="L51"></a>**L51**　：打井怎样？

<a id="L52"></a>**L52**　达

<a id="L53"></a>**L53**　：沙漠地区打井困难。

<a id="L54"></a>**L54**　主席

<a id="L55"></a>**L55**　：那么，建设一些蓄水库储下水来，以供使用，这样不可以吗？

<a id="L56"></a>**L56**　达

<a id="L57"></a>**L57**　：在沙漠地带很困难。水储不下，很快渗入地下。

<a id="L58"></a>**L58**　主席

<a id="L59"></a>**L59**　：你们境内有哪些大河流？

<a id="L60"></a>**L60**　达

<a id="L61"></a>**L61**　：色楞河、鄂嫩河、克鲁伦河等。

<a id="L62"></a>**L62**　主席

<a id="L63"></a>**L63**　：向西北方向流去是哪一条河？

<a id="L64"></a>**L64**　达

<a id="L65"></a>**L65**　：鄂嫩河、克鲁伦河。

<a id="L66"></a>**L66**　主席

<a id="L67"></a>**L67**　：蒙古历史、文化的发源地是哪里？

<a id="L68"></a>**L68**　达

<a id="L69"></a>**L69**　：鄂嫩、克鲁伦河一带。

<a id="L70"></a>**L70**　主席

<a id="L71"></a>**L71**　：你们不可以在这些河流上建筑一些水闸、水库、蓄洪沟等工程吗？

<a id="L72"></a>**L72**　达

<a id="L73"></a>**L73**　：人民和我们都迫切要求那样做，但力量达不到。

<a id="L74"></a>**L74**　主席

<a id="L75"></a>**L75**　：现在我们也有些困难。但几年之后，我们在这方面帮助你们。

<a id="L76"></a>**L76**　达

<a id="L77"></a>**L77**　：谢谢。

<a id="L78"></a>**L78**　主席

<a id="L79"></a>**L79**　：今年河北闹水灾，3000万亩农田遭到了水祸。中国的水利工作，至今还没有能够很大发展，再等待10年之久可能解决。不过，我们在这方面对你们的援助，用不了等10年之久。

<a id="L80"></a>**L80**　达

<a id="L81"></a>**L81**　：去年你们给予了我们很多的援助，派了13000工人和技术员，这在工业和其他建设方面起了推动作用。并且今年还给无偿的一亿六千万卢布。因此，蒙古老百姓非常欢欣鼓舞。

<a id="L82"></a>**L82**　主席

<a id="L83"></a>**L83**　：不，不，上边已经说过，这是我们的义务。那些数目是太少了，你们一提，我就觉得惭愧。

<a id="L84"></a>**L84**　达

<a id="L85"></a>**L85**　：集二线对我国的发展起了很大的作用。

<a id="L86"></a>**L86**　主席

<a id="L87"></a>**L87**　：蒙古的农业现在怎样？

<a id="L88"></a>**L88**　达

<a id="L89"></a>**L89**　：现在较过去有了一些发展，但由于人力缺乏，很大一块土地至今还未开垦。

<a id="L90"></a>**L90**　主席

<a id="L91"></a>**L91**　：这样不好，应该开荒。你们定居了吗？

<a id="L92"></a>**L92**　达

<a id="L93"></a>**L93**　：这样对我国农牧业发展，有很大好处，但理在还未定居下来。

<a id="L94"></a>**L94**　主席

<a id="L95"></a>**L95**　：这不是一下子办得到的，要逐步地办到，因为一个地方的草，是有限制的。我国安徽省也有类似这样的情况。定居下来，也可以种菜，种庄稼，这样人口才能增加。

<a id="L96"></a>**L96**　达

<a id="L97"></a>**L97**　：对！（指曾德说）他是国家计划委员会的主任。您的这些建议，对我国将来的计划工作有很大的帮助。

<a id="L98"></a>**L98**　主席

<a id="L99"></a>**L99**　：发展农业、牲畜业、首先要发展水利工作。这里包括：水闸、蓄水库、水沟等工程。另一方面，牧草是很重要的。对你们来讲，“草就是油”。因此，你们应当增殖牧草，应当采用深耕的方法，这样，牧草就能长得又高又多。然后定居下来就有条件了。

<a id="L100"></a>**L100**　达

<a id="L101"></a>**L101**　：是的！我们重视您的这些谈话。

<a id="L102"></a>**L102**　主席

<a id="L103"></a>**L103**　：你们可以早一些开始水利工程的准备工作，这方面包括地质勘察工作、人力、物力等等。而财力还不算那么重要。最重要，最要紧的是人力。

<a id="L104"></a>**L104**　你们应该先着手进行最迫切需要的工作。例如：由乌兰巴托到西部国境，这一段路的中间，你们修了一条近代化的大马路，但很少用它。这是不很需要的。

<a id="L105"></a>**L105**　达

<a id="L106"></a>**L106**　：中华人民共和国成立以来只有7年之久。在这以前，我们两国人民不大来往。虽然我国革命成功已有35年，但由于我国过去很落后，所以在这35年内未能很好地发展起来（虽然有成绩）。因此我国工农业，可以说是没有很好地发展。

<a id="L107"></a>**L107**　主席

<a id="L108"></a>**L108**　：你们应该自给自足。

<a id="L109"></a>**L109**　达

<a id="L110"></a>**L110**　：现在许多日用品都不能自已生产。

<a id="L111"></a>**L111**　主席

<a id="L112"></a>**L112**　：这是不好的，应该扩大这方面的工业。

<a id="L113"></a>**L113**　达

<a id="L114"></a>**L114**　：日本帝国主义对我国的侵略，也影响了这一方面的发展。

<a id="L115"></a>**L115**　主席

<a id="L116"></a>**L116**　：你们还有多少军队？

<a id="L117"></a>**L117**　达

<a id="L118"></a>**L118**　：将近一师。

<a id="L119"></a>**L119**　主席

<a id="L120"></a>**L120**　：这已够用了。现在，你们周围没有敌人。

<a id="L121"></a>**L121**　达

<a id="L122"></a>**L122**　：现在我们正在将这支部队的复员人员培养成为司机、建筑工人等。

<a id="L123"></a>**L123**　主席

<a id="L124"></a>**L124**　：这是很好的。这是生产军！那么文字怎样呢？

<a id="L125"></a>**L125**　达

<a id="L126"></a>**L126**　：现在都用新（俄）文字，成年人都已识字了。

<a id="L127"></a>**L127**　主席

<a id="L128"></a>**L128**　：很好，内蒙古也正在这样做。

<a id="L129"></a>**L129**　达

<a id="L130"></a>**L130**　：据说是那样。在文字方面，我们也可以帮助内蒙古。

<a id="L131"></a>**L131**　主席

<a id="L132"></a>**L132**　：对，很需要这样。你们跟内蒙古有直接联系吗？

<a id="L133"></a>**L133**　达

<a id="L134"></a>**L134**　：现在没有直接联系呢！只是通过中央取得联系。

<a id="L135"></a>**L135**　主席

<a id="L136"></a>**L136**　：不需要直接联系吗？

<a id="L137"></a>**L137**　达

<a id="L138"></a>**L138**　：需要直接联系，但未办正式手续。

<a id="L139"></a>**L139**　主席

<a id="L140"></a>**L140**　：你们可以办的。你们可以到内蒙古建立自己的领事馆。这样做，用不了什么费用！你们从自己的大使馆抽出几个人来，就可以了。苏联也这样办的。在天津、上海、沈阳、广州等地都有他们的领事馆。

<a id="L141"></a>**L141**　不过，上述这些事，是我个人的说法，也许不正确。因为我未与政府、外交部负责人商量，同样，你们也是未与自己的政府商量过。但，我认为，这些事情，能够实现的。

<a id="L142"></a>**L142**　达

<a id="L143"></a>**L143**　：谢谢！历史上的“债务”，我们连想也没想过。我们只是感谢你们。

<a id="L144"></a>**L144**　主席

<a id="L145"></a>**L145**　：不！要还债的，这是我们在追补祖先们的债务。

<a id="L146"></a>**L146**　（谈话之间主席又谈到蒙古民族的历史）

<a id="L147"></a>**L147**　主席

<a id="L148"></a>**L148**　：你们蒙古族是第三民族。第一个民族是匈奴。它占了新疆、黄河北部的土地，有的已渡过了黄河。第二个民族是突厥，它占领了阿美尼亚、保加利亚、南斯拉夫、埃及、希腊等十几个民族。建立了大帝国。但这一民族后来被蒙古族打败了。因此，蒙古是第三个民族。（由于记录员不懂蒙古通史，所以这一段话，未能全部记下来）至今还没有搞清你们的祖先的来源。是不是在西伯利亚？

<a id="L149"></a>**L149**　奥其尔巴特

<a id="L150"></a>**L150**　：噢！据说是那样！

<a id="L151"></a>**L151**　主席

<a id="L152"></a>**L152**　：西伯利亚那里曾有一个高车族，据说他们都坐在高大的车子上，高车族是不是你们的祖先？

<a id="L153"></a>**L153**　达

<a id="L154"></a>**L154**　：老人们都说：古代的祖先搬家时都用很高的车拉上所有的东西。

<a id="L155"></a>**L155**　主席

<a id="L156"></a>**L156**　：你们有没有关于这一方面的记载？

<a id="L157"></a>**L157**　达

<a id="L158"></a>**L158**　：关于十三世纪前的记载，现在不、还没有，十三世纪以后的有些记载，这一方面的工作苏联帮助着我们。十三世纪以前蒙古历史，跟中国历史有着密切的关系，因此，将来我们在这方面，可能还要跟你们一起进行研究。

<a id="L159"></a>**L159**　主席

<a id="L160"></a>**L160**　：很好，今天我们谈了许多有关历史的事情。

<a id="L161"></a>**L161**　达

<a id="L162"></a>**L162**　：我们的前途很宽广，因为有苏联和中国的援助。今后，我们更要好好努力工作。

<a id="L163"></a>**L163**　主席

<a id="L164"></a>**L164**　：应该好好发展。

<a id="L165"></a>**L165**　达

<a id="L166"></a>**L166**　：我再一次表达我们内心的感激，你们对我们的援助是兄弟般的伟大的援助。我们不能把它当做“债务”来看待。

<a id="L167"></a>**L167**　主席

<a id="L168"></a>**L168**　：但，我们是这样想的。我们同任何国家都以平等共处，过去我们压迫了你们，因此现在要向你们认错。不仅对你们这样，而且对国内少数民族也是这样的。过去，我们压迫了他们，因此，如果我们现在不认错，就不能根除大汉族主义思想，实现民族平等。这是有根据的，这不是漂亮话。是不是过去我们压迫是不是过去我们压迫过你们，但你们现在一句怨言都没有。我们给你们的援助是小小的。这是在还债，不是援助。这样才互相能信赖。并且你们说是援助，这也好，你们这样说也表示平等。

<a id="L169"></a>**L169**　达

<a id="L170"></a>**L170**　：我们对你们所给予我们的过去的和将来的一切援助表示感谢！中、蒙两国劳动人民一向是友好的。反动阶级所干的事情是另一回事。

<a id="L171"></a>**L171**　主席

<a id="L172"></a>**L172**　：有些中国工人去蒙古了。你们应该对他们进行宣传工作，以免让他们犯大汉族主义思想的毛病，以免让他们称王称霸。

<a id="L173"></a>**L173**　那里的中国工人或工作人员如果犯错误，你们应该向我们反映。

<a id="L174"></a>**L174**　达

<a id="L175"></a>**L175**　：大多数的人都很好，少数人虽有时犯毛病，但那也不是有意识的。同时，谁都会有一些缺点的。

<a id="L176"></a>**L176**　主席

<a id="L177"></a>**L177**　：应该教育他们，如果有人犯严重错误，就应当依法处分。你们应以主人翁的态度站起来，教育他们。（主席指着奥其尔巴特说：其他外国大使们都生气勃勃，仪表你不盛气，你也应该像他们那样生气勃勃）

<a id="L178"></a>**L178**　达

<a id="L179"></a>**L179**　：我们那里中国工人中也有200名党员，他们带领着其他工人很好地工作着。

<a id="L180"></a>**L180**　主席

<a id="L181"></a>**L181**　：好！工人一共有多少？

<a id="L182"></a>**L182**　达

<a id="L183"></a>**L183**　：连家属一共13000人。过去的华侨一部分已回国，现在只剩下四、五千人。但这些人都已年老了。

<a id="L184"></a>**L184**　主席

<a id="L185"></a>**L185**　：蒙古人指挥他们吗？

<a id="L186"></a>**L186**　曾德

<a id="L187"></a>**L187**　：是的！蒙古人以主人翁的态度指挥着他们。

<a id="L188"></a>**L188**　主席

<a id="L189"></a>**L189**　：中国工人中有作木工活的吗？

<a id="L190"></a>**L190**　达

<a id="L191"></a>**L191**　：有。此外还有制砖的，以及其他各种行业。

<a id="L192"></a>**L192**　主席

<a id="L193"></a>**L193**　：让他们带蒙古徒弟吗？

<a id="L194"></a>**L194**　达

<a id="L195"></a>**L195**　：他们分别地带着徒弟呢！

<a id="L196"></a>**L196**　主席

<a id="L197"></a>**L197**　：以后在农业方面，我们可以用人力援助你们，其数目可以是10万，也可以是20万，甚至也可以达到30万。其中某些人也可以帮助你们搞畜牧业。

<a id="L198"></a>**L198**　达

<a id="L199"></a>**L199**　：对，不过事先我们应该充分做好准备工作和计划工作。不然，接到那些人后，住宅等各方面要发生困难的。

<a id="L200"></a>**L200**　主席
