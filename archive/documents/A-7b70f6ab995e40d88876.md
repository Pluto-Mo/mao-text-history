<a id="L62"></a>**L62**　图画宣传

<a id="L63"></a>**L63**　（一）图画宣传的重要

<a id="L64"></a>**L64**　中国人不识文字者占百分之九十以上。全国民众只能有一小部分接受本党的文字宣传，图画宣传乃特别重要。

<a id="L65"></a>**L65**　（二）经过之成绩

<a id="L66"></a>**L66**　（1）中央的  去年四月起才实行，做得颇少，又偏在广东方面，分为下列三项：

<a id="L67"></a>**L67**　（甲）每周供给四幅小讽剌画于广州民国日报（间有缺）；

<a id="L68"></a>**L68**　（乙）每周出一种宣传画（间须两周或三周出一种）；

<a id="L69"></a>**L69**　（丙）印刷孙中山先生廖仲恺先生之小照片。

<a id="L70"></a>**L70**　（2）各军的  各军政治部于图画宣传做得很不少，尤其在战时，于军行所至之处张贴图画很多，及于民众的影响很大。

<a id="L71"></a>**L71**　（3）各民众团体的  广东工农两会做了不少的图画宣传，最能激动工农群众。北京上海两处也有一点。

<a id="L72"></a>**L72**　口头宣传

<a id="L73"></a>**L73**　（一）口头宣传，于宣传中，在分量上，在效力上，均占重要地位。

<a id="L74"></a>**L74**　（二）在农民工人兵士学生召集会议，在此会议中作各种内容的演说，是为经常的口头宣传。

<a id="L75"></a>**L75**　（三）在各种政治变动，成示威运动时，作各种的演说，是为临时的口头宣传。中央党部曾数次组织宣传队。各省各埠大规模有组织的宣传，五三十运动中及以后，做得很多。

<a id="L76"></a>**L76**　（四）负责同志于开党员会时，作政治的党务的报告，是为对党内同志的教育。中央党部于总理纪念周常行之。

<a id="L77"></a>**L77**　两年来十四重要事件之宣传

<a id="L78"></a>**L78**　（一）本党改组  发布宣言政纲，明揭反抗帝国主义及其附属物。其结果：

<a id="L79"></a>**L79**　（1）使民众认识了本党及本党之目的，一变从前怀疑本党的态度。于对外宣传有极大效果。

<a id="L80"></a>**L80**　（2）统一党内目标及方法，使怀抱个人或少数人目标及方法者，逐渐淘汰出去。于党内教育收效极大。

<a id="L81"></a>**L81**　（二）收回粵海关事件  反帝宣传，帝国主义明白与本党破脸，本党亦明白反帝；在宣传上有大影响。

<a id="L82"></a>**L82**　（三）沙面罢工之反帝。

<a id="L83"></a>**L83**　（四）商团事件  使民众认识了买办阶级的罪恶。惟此事件本党的宣传做得不力，反革命派攻击本党的宣传却做得十分起劲。

<a id="L84"></a>**L84**　（五）中俄协定  国人从此明白国际上有帝国主义国家与反帝国主义国家之别。北京以及各地反帝同盟奋起。“反帝国主义”一口号开始为民众所接受，本党为此发布一宣言。

<a id="L85"></a>**L85**　（六）反直战争  民众从此对强大军阀失信用。孙先生发布北伐宣言。

<a id="L86"></a>**L86**　（七）总理北上  发布北上宣言。提出“开国民会议”“废除不平等条约”两个口号。

<a id="L87"></a>**L87**　（八）国民会议促成运动  与段祺瑞对抗，使段之善后会议民众全不信用。同时使民众更深切的认识本党政治主张，“开国民会议”“废除不平等条约”两个口号，在此运动中，深入于民众。

<a id="L88"></a>**L88**　（九）总理追悼运动  使民众认识孙先生，认识本党及本党目的。此追悼运动极普遍，达于穷乡僻壤，“开国民会议”“废除不平等条约”两个口号因此更深入民众。此时本党发布与段祺瑞绝交宣言。

<a id="L89"></a>**L89**　（十）五三十运动  空前的反帝。在此运动中提出了废除不平等条约的内容：如收回租界，收回海关，收回司法权，撤退驻华海陆军等。民众因此认识什么是不平等条约。此运动因奉系军阀高压失败。但有一成绩：即上海香港的工人起来了。此次在宣传上收效极大，乡村农民群众已普遍的知道了本党有拥护民众反抗帝国主义的宣言。

<a id="L90"></a>**L90**　（十一）廖案  民众认识了帝国主义及其附属物之残暴。本党用追悼及文字图画等的宣传，做得很不少。

<a id="L91"></a>**L91**　（十二）反奉战争  使民众明白认识帝国主义与其工具中国军阀之关系，明白认识中国军阀崩坏之迅速。在此战争中，民众有了接近革命成功之感觉。在各地的反段运动中，提出与当地军阀直接冲突的口号，如北京民众之“驱逐段祺瑞”，武汉民众之“驱逐吴佩孚”，长沙民众之“打倒赵恒惕”，一变从前避免直接冲突之和平态度，革命空气，空前的紧张。

<a id="L92"></a>**L92**　（十三）反教运动  两年来反基督教的组织和宣传，遍于全国各地，使民众认识了帝国主义之宗教的侵略。

<a id="L93"></a>**L93**　（十四）军队中平时之政治教育与战时之政治宣传  本党在黄埔军校及国民革命军中所作之政治教育，造成了反帝国主义的军事势力；在广东各次战役时所作之军民联合的宣传，使军队爱护人民，人民拥护军队。此一事仍可算得本党一大成功。

<a id="L94"></a>**L94**　敌人的宣传

<a id="L95"></a>**L95**　我们的宣传之[一]部分，不能不针对敌人的宣传去做，现在且一看两年来敌人的反革命宣传。

<a id="L96"></a>**L96**　（一）帝国主义  两年来因本党反帝国主义的宣传，特别猛进，帝国主义诬蔑攻击本党的宣传，亦特别利害。乃提出“反共产”“赤色帝国主义”两个口号，号召其在中国的工具官僚军阀买办阶级土豪劣绅，向本党进攻。香港上海天津北京奉天汉口各外报，及外国通信社之造谣诬蔑挑拨中伤，可谓无所不用其极。

<a id="L97"></a>**L97**　（二）各派军阀  国内各派大小军阀一致拥护帝国主义发出的两个口号（反共产，赤色帝国主义）而扩大之。

<a id="L98"></a>**L98**　（三）买办阶级  反革命宣传工作同上，然比任何反革命派之宣传为努力；香港工商日报，上海新闻报，可为代表。

<a id="L99"></a>**L99**　（四）研究系  拥护官僚及大地主的利益，反革命宣传工作同上，时事新报晨报可为代表。

<a id="L100"></a>**L100**　（五）安福系  代表日本帝国主义，反革命宣传工作同上。以新申报为机关。

<a id="L101"></a>**L101**　（六）联治派  拥护官僚及地主的利益，反革命宣传工作同上。中华新报乃其机关。

<a id="L102"></a>**L102**　（七）国家主义派  学了点西洋国家主义的样子，拥护小地主及华资工商资产阶级的利益，“反共产”“反苏俄”十分起劲，醒狮周报乃其代表。

<a id="L103"></a>**L103**　（八）国民党右派  本党右派自西山会议后，也学会了“反共产”“反苏俄”两句口号，跟着以上各反革命派起斗，取了敌对本党的态度；上海民国日报乃其代表。

<a id="L104"></a>**L104**　两年来在革命宣传与反革命宣传相对抗之中，革命宣传确是取一种攻势；这种攻势，在五三十运动中特别的表现出来。反革命宣传却始终是一种守势，为了招架不住，才抬出“反共产”“赤色帝国主义”这两块挡箭牌来。这种对抗攻守的现象，乃中国革命势力日益团结进取，而反革命势力日益动摇崩溃的结果。

<a id="L105"></a>**L105**　缺点

<a id="L106"></a>**L106**　从两年来的宣传工作中，发现了如下各缺点：

<a id="L107"></a>**L107**　（一）党报不健全；

<a id="L108"></a>**L108**　（二）对各重要事件的宣传指导不敏捷，而且多未能尽量的做；

<a id="L109"></a>**L109**　（三）指挥系统完全缺乏，上级与下级党部的宣传部间，完全失去连络，成了人自为战的局面，许多宣传部负责人因此放弃职务；

<a id="L110"></a>**L110**　（四）检察纠正之职务，完全旷废；

<a id="L111"></a>**L111**　（五）宣传材料之充分搜集，及供给于下级党部，完全未办；

<a id="L112"></a>**L112**　（六）有计划的党内教育，几乎没有做；

<a id="L113"></a>**L113**　（七）偏于市民，缺于农民；

<a id="L114"></a>**L114**　偏于文字，缺于图画；

<a id="L115"></a>**L115**　以上均是以前本党宣传工作中最大的缺点，以后应一一改正之。
