<a id="L9"></a>**L9**　（一九六七年七月十三日）

<a id="L10"></a>**L10**　不要怕闹，闹得越大、越长，越好。七闹八闹，总会闹出名堂来的，可以闹清楚。不管怎么闹，不要怕，越怕鬼越来。但也不要开枪，什么时候开枪也是不好的。

<a id="L11"></a>**L11**　全国大闹不可能。那里有脓包，有细菌，总要爆发的。

<a id="L12"></a>**L12**　南京街上闹得很厉害，我越看越高兴。闹得第三派那么多人，反对内战，反对武斗，这很好嘛！

<a id="L13"></a>**L13**　（张春桥。有人讲第三派是走第三条道路的。）

<a id="L14"></a>**L14**　哪有什么第三条道路呀，人家要大联合，大批判。你要诱导嘛！
