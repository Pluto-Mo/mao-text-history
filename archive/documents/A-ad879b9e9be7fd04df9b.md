<a id="L9"></a>**L9**　（一九六七年）

<a id="L10"></a>**L10**　一、现将广州、湖南军区报告两个文件，发给你们希望遵照执行。

<a id="L11"></a>**L11**　二、是错误的必须改正，如果不改正，越陷越深，到头来还得改正，威信损失就大了。及早改正威信只能比以前高。

<a id="L12"></a>**L12**　三、不能动动摇摇，犹犹豫豫，听老婆孩子从保守派那里来的错误话，信以为真。

<a id="L13"></a>**L13**　四、要受得住工人、农民、学生、战士、干部的批评，加以分析，好的接受，错的改正，解释不通的，暂时搁下来将来再说。

<a id="L14"></a>**L14**　五、要坚决相信群众大多数是好的，坏人是少数，不过百分之一、二、三，这样一想什么问题也想通了。
