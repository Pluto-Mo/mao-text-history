<a id="L19"></a>**L19**　：冀朝铸

<a id="L20"></a>**L20**　记　录

<a id="L21"></a>**L21**　：周性吾

<a id="L22"></a>**L22**　毛主席

<a id="L23"></a>**L23**　：欢迎你们。

<a id="L24"></a>**L24**　朱利叶斯·克·尼雷尔

<a id="L25"></a>**L25**　总统（以下简称尼雷尔）：谢谢。我们非常高兴再次来中国访问。主席身体怎么样？

<a id="L26"></a>**L26**　毛主席

<a id="L27"></a>**L27**　：勉勉强强，马马虎虎。

<a id="L28"></a>**L28**　尼雷尔

<a id="L29"></a>**L29**　：你看起来是很好的。

<a id="L30"></a>**L30**　毛主席

<a id="L31"></a>**L31**　：好是形式上，你好吗？

<a id="L32"></a>**L32**　尼雷尔

<a id="L33"></a>**L33**　：我身体很好。

<a id="L34"></a>**L34**　毛主席

<a id="L35"></a>**L35**　：那好。他们身体都好？

<a id="L36"></a>**L36**　尼雷尔

<a id="L37"></a>**L37**　：他们都好。

<a id="L38"></a>**L38**　毛主席

<a id="L39"></a>**L39**　：北京的气候和你们一样吗？

<a id="L40"></a>**L40**　尼雷尔

<a id="L41"></a>**L41**　：现在北京气候比达累斯萨拉姆稍为热一点。

<a id="L42"></a>**L42**　毛主席

<a id="L43"></a>**L43**　：稍为热一点。你们南纬多少度？

<a id="L44"></a>**L44**　尼雷尔

<a id="L45"></a>**L45**　：南纬12度。

<a id="L46"></a>**L46**　毛主席

<a id="L47"></a>**L47**　：南纬12度，那就热一点。

<a id="L48"></a>**L48**　尼雷尔

<a id="L49"></a>**L49**　：沿海地区还是比较热的。在4月份和北京气候差不多。现在开始凉快起来了。沿海地区从来不是太凉快的。现在开始凉快一些了。高地有时候往往比较凉快了。

<a id="L50"></a>**L50**　毛主席

<a id="L51"></a>**L51**　：你们有很高的山吗？

<a id="L52"></a>**L52**　尼雷尔

<a id="L53"></a>**L53**　：是的。

<a id="L54"></a>**L54**　毛主席

<a id="L55"></a>**L55**　：山上有雪？

<a id="L56"></a>**L56**　尼雷尔

<a id="L57"></a>**L57**　：是的。

<a id="L58"></a>**L58**　毛主席

<a id="L59"></a>**L59**　：山上还有老虎？

<a id="L60"></a>**L60**　尼雷尔

<a id="L61"></a>**L61**　：没有。非洲没有老虎。

<a id="L62"></a>**L62**　因为老虎是亚洲的动物，所以纸老虎，我们没有办法翻译成本地语言。（众笑）

<a id="L63"></a>**L63**　周总理

<a id="L64"></a>**L64**　：他们非洲有狮子。

<a id="L65"></a>**L65**　毛主席

<a id="L66"></a>**L66**　：狮子叫什么？

<a id="L67"></a>**L67**　尼雷尔

<a id="L68"></a>**L68**　：斯瓦希里语叫simba，英文叫lion。

<a id="L69"></a>**L69**　毛主席

<a id="L70"></a>**L70**　：发音和拿破仑相近。我研究法国历史时读过拿破仑传，是翻译的，一俄国人写的，实际上是吹库图佐夫。我想找一本法国人写的。我们那时候念书没有经验。读书没有经验，等于不读。他领导军队时，不许打人，不许骂人。当然他不可能提出这样的口号，要军队要为人民服务，不能侵略别的国家。他是偏要侵略别的国家。他吃亏吃在侵略的地方太大了，树立了太多的敌人。他占领了半个欧洲。几乎所有欧洲国家都同他作战，有英国、俄国、德国和奥地利。法国当时的人口是2800万。这是讲法国本土。当时德国、荷兰、比利时、卢森堡、意大利还有奥国都被他占领了。后来他还占领了西班牙和葡萄牙。他青年时候还占领过埃及和叙利亚。他占领得太多了，树敌太多。我们树敌也太多。

<a id="L71"></a>**L71**　尼雷尔

<a id="L72"></a>**L72**　：不过你们没有通过占领别人地盘而树敌。

<a id="L73"></a>**L73**　毛主席

<a id="L74"></a>**L74**　：那是对的。他们侵略我们的国家，我们没有侵略别的国家。在本国，军队消灭敌人是有利的。他们如果侵略我们国家，甚至有些右派有都会赞成打仗，因为他们侵略我们。我这里说的“右派”是指那些红卫兵要打倒的人。

<a id="L75"></a>**L75**　大使是哪一位？

<a id="L76"></a>**L76**　尼雷尔

<a id="L77"></a>**L77**　：在记录的那一位。

<a id="L78"></a>**L78**　毛主席

<a id="L79"></a>**L79**　：你来了多久？

<a id="L80"></a>**L80**　姆瓦卢科

<a id="L81"></a>**L81**　大使：不到两年。

<a id="L82"></a>**L82**　尼雷尔

<a id="L83"></a>**L83**　：他对你们文化大革命比较了解。

<a id="L84"></a>**L84**　毛主席

<a id="L85"></a>**L85**　：比较了解。北京的学生、工人闹得天翻地覆，但基本上还是有秩序的。他们做了一些有成绩的事情。有些外国新闻记者宣传红卫兵坏得很。

<a id="L86"></a>**L86**　尼雷尔

<a id="L87"></a>**L87**　：主席先生，在世界上中国是唯一的国家，能够主动的发动这样的一个革命，同时又能够控制得住。

<a id="L88"></a>**L88**　毛主席

<a id="L89"></a>**L89**　：他们要闹，让他们闹嘛！他们想闹嘛！有些人就着急了，说两年没有上课了，那怎么办啊？我说再停两年课我也赞成。大学才没有多少用处，特别是文科。已经两年了，再有两年，就四年了，你还不走啊！实际上他们也上了一课，就是文化革命的一课。他们是不反对你们的。

<a id="L90"></a>**L90**　尼雷尔

<a id="L91"></a>**L91**　：我们也没说他们反对我们。我们从来不对红卫兵表示不满。

<a id="L92"></a>**L92**　毛主席

<a id="L93"></a>**L93**　：他们从来不反对你们，不管你的官多大，也不反对你。他们对有些新闻记者也没有骂嘛。

<a id="L94"></a>**L94**　在这里要办的事情，办得差不多了吗？

<a id="L95"></a>**L95**　尼雷尔

<a id="L96"></a>**L96**　：我想我们同总理先生基本上已经办完了。今天晚上再小范围谈一下。

<a id="L97"></a>**L97**　周总理

<a id="L98"></a>**L98**　：他下午谈了继续革命的问题，教育群众的问题，殖民主义留下来的思想意识，还有封建的东西，还有怎么能进行一场同文化革命性质相似的革命。

<a id="L99"></a>**L99**　毛主席

<a id="L100"></a>**L100**　：旧社会总会遗留一些东西的。我们也是留下一些封建残余，帝国主义思想残余。

<a id="L101"></a>**L101**　周总理

<a id="L102"></a>**L102**　：买办资产阶级的东西。

<a id="L103"></a>**L103**　毛主席

<a id="L104"></a>**L104**　：非无产阶级的东西。

<a id="L105"></a>**L105**　周总理

<a id="L106"></a>**L106**　：他也了解到军队是支持文化大革命，是文化大革命的支柱。

<a id="L107"></a>**L107**　毛主席

<a id="L108"></a>**L108**　：军队要重新搞，非洲要重新创造军队，要从人民中搞起来。

<a id="L109"></a>**L109**　尼雷尔

<a id="L110"></a>**L110**　：我想这个问题是非洲的关键问题。如果非洲国家的武装部队不直接参加革命或者只是参加一部分的话，革命是不能成功的。

<a id="L111"></a>**L111**　毛主席

<a id="L112"></a>**L112**　：军队不稳定，政权也不稳定。是不是这样啊？

<a id="L113"></a>**L113**　尼雷尔

<a id="L114"></a>**L114**　：是这样的情况。我经常同其他领导人讲，帝国主义要颠覆某一个非洲国家的话就是利用两个工具：一个是利用当地的军队，一个是利用当地的知识分子。但是事实应该正好相反，军队和知识界应该是革命的先锋。所以，如果我们的军队不成为人民革命的一个组成部分，如果我们的知识界是一个特权阶层的话，那我们仍然是有危险的。帝国主义就会控制这两股力量。

<a id="L115"></a>**L115**　毛主席

<a id="L116"></a>**L116**　：他们总是打你们主意的。

<a id="L117"></a>**L117**　尼雷尔

<a id="L118"></a>**L118**　：在任何一个非洲国家中，帝国主义要颠覆这个国家的话，它就要控制当地的军队或者利用当地的知识界，或者两者都利用。

<a id="L119"></a>**L119**　毛主席

<a id="L120"></a>**L120**　：卢蒙巴怎么样被颠覆的，恩克鲁玛总统为什么不能回国了，还有伊拉克的卡塞姆也是被军队搞掉的。

<a id="L121"></a>**L121**　尼雷尔

<a id="L122"></a>**L122**　：在加纳颠覆恩克鲁玛的力量一方面是军队，一方面是文官。这方面总理变了好多。文官在加纳完全英国化。加纳被颠覆与其说是军队搞的，不如说是文官利用了军队。

<a id="L123"></a>**L123**　毛主席

<a id="L124"></a>**L124**　：在亚洲还有一个苏加诺。

<a id="L125"></a>**L125**　尼雷尔

<a id="L126"></a>**L126**　：他们利用了学生和军队。这一点的确是一个关键问题。如果我们能够使军队真正成为人民革命的工具，我们的目标一定能够达到。那时，帝国主义很难颠覆我们。帝国主义要想直接占领我们的国家也会很困难的。

<a id="L127"></a>**L127**　它只能利用我们本国国内的力量来搞我们。

<a id="L128"></a>**L128**　毛主席

<a id="L129"></a>**L129**　：你们的国家不小啊？

<a id="L130"></a>**L130**　周总理

<a id="L131"></a>**L131**　：93万平方公里，1100万人口，占我们全国面积的1/10。

<a id="L132"></a>**L132**　毛主席

<a id="L133"></a>**L133**　：我们江苏省是10万平方公里，浙江省也是10万平方公里。你们国家不太小。

<a id="L134"></a>**L134**　尼雷尔

<a id="L135"></a>**L135**　：地理上，面积大。

<a id="L136"></a>**L136**　毛主席

<a id="L137"></a>**L137**　：大有发展前途。

<a id="L138"></a>**L138**　尼雷尔

<a id="L139"></a>**L139**　：是的，是有的。

<a id="L140"></a>**L140**　毛主席

<a id="L141"></a>**L141**　：我们的江苏面积只有你们的1/9。

<a id="L142"></a>**L142**　尼雷尔

<a id="L143"></a>**L143**　：我们也是一个大国。

<a id="L144"></a>**L144**　毛主席

<a id="L145"></a>**L145**　：是一个大国，将来很有发展前途。

<a id="L146"></a>**L146**　尼雷尔

<a id="L147"></a>**L147**　：我们刚刚开始。

<a id="L148"></a>**L148**　毛主席

<a id="L149"></a>**L149**　：我们也刚刚开始。

<a id="L150"></a>**L150**　尼雷尔

<a id="L151"></a>**L151**　：我们一直被剥削，我们没有能够很好利用我们的国家来造福于我们自己。直到现在我们没有完全排除外国的剥削。

<a id="L152"></a>**L152**　毛主席

<a id="L153"></a>**L153**　：一下子也难排除。外国有不少投资吗？

<a id="L154"></a>**L154**　周总理

<a id="L155"></a>**L155**　：有不少投资。

<a id="L156"></a>**L156**　毛主席

<a id="L157"></a>**L157**　：建设工业和农业需要一个过程。

<a id="L158"></a>**L158**　周总理

<a id="L159"></a>**L159**　：他们财政部长前几天宣布取消英国文官的退休金500万镑和赔偿金900万镑。英国立刻在下议院取消对他们的援助。

<a id="L160"></a>**L160**　尼雷尔

<a id="L161"></a>**L161**　：这个问题，是很容易向总理解释清楚的，因为总理说，中国过去也是这样的情况。中国那时不是殖民地，而是半殖民地。但帝国主义的做法是一样的。

<a id="L162"></a>**L162**　毛主席

<a id="L163"></a>**L163**　：中国过去军队都是外国训练的，叫操时都用外国话，One、two、three、four。

<a id="L164"></a>**L164**　尼雷尔

<a id="L165"></a>**L165**　：我们也是一直用英文练操的。1965年开始改正，用斯瓦希里语练操。我觉得除开阿拉伯国家，在非洲只有坦桑尼亚用斯瓦希里语，用本国语言练操。其他国家不是用英文，就是用法文。

<a id="L166"></a>**L166**　毛主席

<a id="L167"></a>**L167**　：过去在中国，法国训练军队就用法国话，德国训练就用德国话，日本训练用日本话。

<a id="L168"></a>**L168**　周总理

<a id="L169"></a>**L169**　：我们康生同志是山东人。山东本来是德国的殖民地。他就会讲德文。后来在第二次世界大战以后，成了美国的。

<a id="L170"></a>**L170**　尼雷尔

<a id="L171"></a>**L171**　：开始我们是德国的属地，后来成为英国的属地。我的舅舅曾经为德国作过战，我的兄弟和表哥在第二次世界大战中为英国人作战而牺牲了。

<a id="L172"></a>**L172**　康生

<a id="L173"></a>**L173**　：以前山东属于德国，后来日本，然后又是蒋介石和美国，一直到解放。

<a id="L174"></a>**L174**　毛主席

<a id="L175"></a>**L175**　：现在美国代替英国、法国的原来地位了。

<a id="L176"></a>**L176**　周总理

<a id="L177"></a>**L177**　：还有一个大伙伴苏联。尼雷尔他们说它是新殖民主义，我说是社会帝国主义。

<a id="L178"></a>**L178**　毛主席

<a id="L179"></a>**L179**　：他们想控制一些国家，这些国家就不满意。

<a id="L180"></a>**L180**　周总理

<a id="L181"></a>**L181**　：你们民族主义者报报道我在宴会上谴责核新殖民主义时，苏修一些国家就退席了。

<a id="L182"></a>**L182**　尼雷尔

<a id="L183"></a>**L183**　：总理，你了解消息比我们还快。

<a id="L184"></a>**L184**　周总理

<a id="L185"></a>**L185**　：我从外电上知道的。

<a id="L186"></a>**L186**　毛主席

<a id="L187"></a>**L187**　：他是一个消息灵通人士。

<a id="L188"></a>**L188**　中国派到外国去也有不好的，有些是不知道怎么样做，有些就是干坏事的。

<a id="L189"></a>**L189**　周总理

<a id="L190"></a>**L190**　：中国有一个纺织专家的翻译就是这样。

<a id="L191"></a>**L191**　毛主席

<a id="L192"></a>**L192**　：他们搞大国沙文主义，欺负驻在国，不尊重所在国领导，背着当地的领导，也背着我们干坏事。遇到这样的事情就应该提出来，我们就把他们撤回来。

<a id="L193"></a>**L193**　周总理

<a id="L194"></a>**L194**　：我们已经对他们讲了，他们知道有这类事就告诉我们大使馆。

<a id="L195"></a>**L195**　尼雷尔

<a id="L196"></a>**L196**　：我想这样的情况是不会太多的。

<a id="L197"></a>**L197**　毛主席

<a id="L198"></a>**L198**　：个别也有啊。

<a id="L199"></a>**L199**　尼雷尔
