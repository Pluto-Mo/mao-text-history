<a id="L7"></a>**L7**　（1974年9—12月）

<a id="L8"></a>**L8**　1974年9月至12月，毛主席在同外宾谈话中，多次指出现在这个世界比较过去很不安宁，要准备打仗。最近在恩来、洪文同志汇报工作时，毛主席又对国内工作做了极为重要的指示，特别指示我们要学习列宁关于无产阶级对资产阶级专政的论述，要写文章，使全国知道。

<a id="L9"></a>**L9**　下面是毛主席一系列指示的要点。

<a id="L10"></a>**L10**　（一） 内容是关于国际斗争方面，略

<a id="L11"></a>**L11**　（二） 毛主席说，小平同志人才难得，政治强。开二中全会，补常委、副主席。并担任军委副主席，国务院副总理兼总参谋长三个职务。

<a id="L12"></a>**L12**　毛主席说，张春桥有才干。当汇报到有谁来担任总政治部主任的时候，毛主席说，张春桥兼。

<a id="L13"></a>**L13**　当汇报四届人大筹备工作时，毛主席说，国民党那些战犯放出来，湖南、湖北、江西、安徽都可以去嘛。愿意回台湾的，可以回台湾嘛。

<a id="L14"></a>**L14**　毛主席说，世界上的一些事，说起来难，做起来不难。比如四书五经现在都不谈了，可以一样治国嘛。

<a id="L15"></a>**L15**　凡有两派的地方，民兵不要搞进去。

<a id="L16"></a>**L16**　毛主席说，苏联人人与我们搭桥，注意。

<a id="L17"></a>**L17**　毛主席问，勃列日涅夫到中国来可以不可以？

<a id="L18"></a>**L18**　（三） 内容是关于理论问题的指示，略。
