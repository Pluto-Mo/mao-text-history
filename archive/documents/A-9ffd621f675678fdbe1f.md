<a id="L11"></a>**L11**　一、打倒日本帝国主义：

<a id="L12"></a>**L12**　对日绝交，驱逐日本官吏，逮捕日本侦探，接收日本帝国主义在华财产，否认日本外债，废除日本条约，收回日本租界。

<a id="L13"></a>**L13**　为保卫华北与沿海各地而血战到底。

<a id="L14"></a>**L14**　为收复平津与东北而血战到底。

<a id="L15"></a>**L15**　反对任何的动摇妥协。

<a id="L16"></a>**L16**　二、全国军事的总动员：

<a id="L17"></a>**L17**　动员全国海陆空军实行全国抗战。

<a id="L18"></a>**L18**　反对单纯防御的消极作战方针，釆取独立自主的积极作战方针。

<a id="L19"></a>**L19**　建立经常的国防会议，讨论与决定国防计划与作战方针。

<a id="L20"></a>**L20**　武装人民，发展抗日的游击战争，配合主力军作战。

<a id="L21"></a>**L21**　改革军队的政治工作，使指挥员与战斗员团结一致，军队与人民团结一致。发扬军队的积极性。

<a id="L22"></a>**L22**　援助东北人民革命军东北义勇军。破坏敌人后方。

<a id="L23"></a>**L23**　实现一切抗日军队的平等待遇。

<a id="L24"></a>**L24**　建立全国、各地军区，动员全民族参战，以便从雇佣兵役制转变为义务兵制。

<a id="L25"></a>**L25**　三、全国人民的总动员：

<a id="L26"></a>**L26**　全国人民除汉奸外，皆有抗日救国的言论、出版、集会、结社，及武装抗敌之自由。废除一切束缚人民爱国运动的旧法令，颁布革命的新法令。释放一切爱国的革命的政治犯，开放党禁。全国人民动员起来武装起来，参加抗战，实行有力出力，有钱出钱，有枪出枪，有知识出知识。

<a id="L27"></a>**L27**　动员蒙民回民及其他一切少数民族，在民族自决和民族自治的原则下，共同抗日。

<a id="L28"></a>**L28**　四、改革政治机构

<a id="L29"></a>**L29**　召集真正代表人民的国民大会，通过真正的民主宪法，决定抗日救国方针，选举国防政府。

<a id="L30"></a>**L30**　国防政府必须吸收各党各派及人民团体的革命分子，驱逐亲日分子。

<a id="L31"></a>**L31**　国防政府采取民主集中制，他是民主的，但又是集中的。

<a id="L32"></a>**L32**　国防政府执行抗日救国的革命政策。实行地方自治，铲除贪官污吏，建立廉洁政府。

<a id="L33"></a>**L33**　五、抗日的外交政策：

<a id="L34"></a>**L34**　在不丧失领土主权的范围内，与一切反对日本侵略主义的国家订立反侵略的同盟，及抗日的军事互相协定。

<a id="L35"></a>**L35**　拥护和平阵线，反对德日意侵略阵线。

<a id="L36"></a>**L36**　联合朝鲜台湾及日本国内的工农人民反对日本帝国主义。

<a id="L37"></a>**L37**　六、战时的财政经济政策：

<a id="L38"></a>**L38**　财政政策以有钱出钱及没收汉奸财产作抗日经费为原则，经济政策是整顿与扩大国防生产，发展农村经济，保证战时农产品的自给，提倡国货改良土产，禁绝日货，取缔奸商，反对投机操纵。

<a id="L39"></a>**L39**　七、改良人民生活：

<a id="L40"></a>**L40**　改良工人农民职员教员及抗日军人的待遇。

<a id="L41"></a>**L41**　优待抗日军人的家属。

<a id="L42"></a>**L42**　废除苛捐杂税，减租减息；救济失业；调节粮食；脤济灾荒。

<a id="L43"></a>**L43**　八、抗日的教育政策：

<a id="L44"></a>**L44**　改变教育的旧制度旧课程，实行以抗日救国为目标的新制度新课程。

<a id="L45"></a>**L45**　实施普及的义务的免费的教育方案，提高人民民族觉悟的程度。

<a id="L46"></a>**L46**　实行全国学生的武装训练．

<a id="L47"></a>**L47**　九、肃清汉奸卖国贼亲日派。巩固后方。

<a id="L48"></a>**L48**　十、抗日的民族团结：

<a id="L49"></a>**L49**　在国共两党彻底合作的基础上，建立全国各党各派各界各军的抗日民族统一战线，领导抗日战争，精诚团结、共赴国难。
