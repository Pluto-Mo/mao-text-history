<a id="L9"></a>**L9**　（一九六七年十二月十七日）

<a id="L10"></a>**L10**　林、周、中央及文革各同志：

<a id="L11"></a>**L11**　（一）绝对权威的提法不妥。从来没有单独的绝对权威，凡权威都是相对的，凡绝对的东西都只存在相对的东西之中，犹如绝对真理是无数相对真理的总和．绝对真理只存在于各个相对真理之中一样。

<a id="L12"></a>**L12**　（二）大树特树的说法也不妥。权威和戚信只能从斗争实践中自然地建立，不能由人工去建立，这样建立的威信必然会垮下来。

<a id="L13"></a>**L13**　（三）党中央很早就禁止祝寿，应通知全国重申此种禁令。

<a id="L14"></a>**L14**　（四）湖南的集会应另择日期。

<a id="L15"></a>**L15**　（五）我们不要题字。

<a id="L16"></a>**L16**　（六）会议名称，可同意湖南建议，用第一方案。

<a id="L17"></a>**L17**　以上各点请在一次会议上讨论通过为盼。

<a id="L18"></a>**L18**　毛泽东

<a id="L19"></a>**L19**　十二月十七日
