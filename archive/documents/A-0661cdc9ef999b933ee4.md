<a id="L5"></a>**L5**　毛泽东主席在巴拉圭共产党总书记克雷依特等给我党中央的三封信上的批示

<a id="L6"></a>**L6**　（1970年1月12日）

<a id="L7"></a>**L7**　【巴共总书记克雷依特等人从1969年3月至12月间，先后给我党中央和林彪数次来信，承认过去追随苏修反华是错误的，要求同我“恢复两党关系”。在毛主席此批示后，我党与巴共恢复了两党关系。】

<a id="L8"></a>**L8**　林彪同志：这些信看来似无恶意，他们被人抛弃，想寻出路，请转康生同志考虑，是否可以同他们联系。

<a id="L9"></a>**L9**　毛泽东 1月12日

<a id="L10"></a>**L10**　毛主席在来信的称呼旁又批了一段话【克雷依特来信中称林彪为“中共中央第一书记”，林彪在“第一书记”四字上打了×并批称：“外国来信，过去、现在、将来都会很多。凡遇这等不正确或带挑拨性的称呼，及类似内容，希望不要在内部印发，以免发生不良影响”。】：

<a id="L11"></a>**L11**　“至于称呼，好像他们对九大情况不大明了。”
