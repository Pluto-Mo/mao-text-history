<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东主席会见老挝人民党总书记凯山等谈话记录

<a id="L10"></a>**L10**　参加人：

<a id="L11"></a>**L11**　老方：西沙瓦、沙南、坎派

<a id="L12"></a>**L12**　中方：林彪、周恩来、康生、黄永胜、邱会作、申健

<a id="L14"></a>**L14**　记　录：吕辉祥

<a id="L15"></a>**L15**　毛主席

<a id="L16"></a>**L16**　（以下简称主席）：你们什么时候到的？

<a id="L17"></a>**L17**　凯山

<a id="L18"></a>**L18**　（以下简称凯）：6月30日到的。

<a id="L19"></a>**L19**　主席

<a id="L20"></a>**L20**　：你们明天就要走？

<a id="L21"></a>**L21**　凯

<a id="L22"></a>**L22**　：是的，明天我们去朝鲜访问。

<a id="L23"></a>**L23**　主席

<a id="L24"></a>**L24**　：很好。现在朝鲜跟你们的意见是一致的。

<a id="L25"></a>**L25**　凯

<a id="L26"></a>**L26**　：我们代表团访问中国的时候，向中国党通报了情况。根据目前的新情况，我们制定了今后3年的斗争计划，目的就是为了进一步大力推进我们的抗美救国斗争，以便夺取更大的胜利。

<a id="L27"></a>**L27**　主席

<a id="L28"></a>**L28**　：你们国家面积多大？

<a id="L29"></a>**L29**　凯

<a id="L30"></a>**L30**　：21万平方公里。我们的人口很少。

<a id="L31"></a>**L31**　主席

<a id="L32"></a>**L32**　：260万？

<a id="L33"></a>**L33**　凯

<a id="L34"></a>**L34**　：对。

<a id="L35"></a>**L35**　主席

<a id="L36"></a>**L36**　：打了这么多年，你们在人力、物力方面不感觉缺乏吗？

<a id="L37"></a>**L37**　凯

<a id="L38"></a>**L38**　：我们现在有些东西比较贫乏。

<a id="L39"></a>**L39**　主席

<a id="L40"></a>**L40**　：什么贫乏？

<a id="L41"></a>**L41**　凯

<a id="L42"></a>**L42**　：比如说人力方面，要补充兵员人很少。由于人力少，搞生产也有困难，要搞好生产为前线服务，改善群众的生活也都感到有困难。

<a id="L43"></a>**L43**　主席

<a id="L44"></a>**L44**　：看来战争要延长。

<a id="L45"></a>**L45**　凯

<a id="L46"></a>**L46**　：我们也是这样分析的，战争延长的可能性是很大的。因为美帝国主义很顽固，而且在军事、经济方面的潜力也还是巨大的。虽然战争要延长，我们有决心打下去。

<a id="L47"></a>**L47**　主席

<a id="L48"></a>**L48**　：这好。遇到困难的时候，就需要有决心。无非是困难嘛，人少嘛，物资少嘛。

<a id="L49"></a>**L49**　人多也有困难。比如说，美国它就没有困难？泰国它就没有困难？它们的困难也许比你们还大。

<a id="L50"></a>**L50**　凯

<a id="L51"></a>**L51**　：毛主席说得很对。我们的困难是胜利中的困难，美帝国主义及其走狗的困难是失败中的困难。

<a id="L52"></a>**L52**　主席

<a id="L53"></a>**L53**　：对。上次我给你说，是不是可以组织一支队伍打到泰国去。因为泰国人打你们嘛。你可以来，我不可以去呀？

<a id="L54"></a>**L54**　凯

<a id="L55"></a>**L55**　：毛主席讲的这几句话我记得很清楚。

<a id="L56"></a>**L56**　主席

<a id="L57"></a>**L57**　：泰国哪些地方住的有你们的人？

<a id="L58"></a>**L58**　凯

<a id="L59"></a>**L59**　：我们在沙耶武里的根据地是给泰共同志准备的后方。我们在南寮的根据地跟泰共的斗争也有很大的关系。这个地区泰共的运动搞得不错。

<a id="L60"></a>**L60**　主席

<a id="L61"></a>**L61**　：那个地方都是你们的民族吗？

<a id="L62"></a>**L62**　凯

<a id="L63"></a>**L63**　：整个边界地区同我们都是一个民族。

<a id="L64"></a>**L64**　主席

<a id="L65"></a>**L65**　：人口比你们国家还多？

<a id="L66"></a>**L66**　凯

<a id="L67"></a>**L67**　：多得多。光是这块地方（指泰国东部和北部）就有5、600万。

<a id="L68"></a>**L68**　主席

<a id="L69"></a>**L69**　：现在怎么归泰国了？

<a id="L70"></a>**L70**　凯

<a id="L71"></a>**L71**　：在十七、八世纪和十九世纪初叶，老挝还是一个封建割据国家，还没有进入中央集权，当时我们的边界一直到这边（指泰国东部和北部），到了十九世纪初叶和中叶，泰国的封建王朝就向老挝的封建王朝进攻，后来就把老挝分成了很多个小王国。

<a id="L72"></a>**L72**　主席

<a id="L73"></a>**L73**　：琅勃拉邦王国？

<a id="L74"></a>**L74**　凯

<a id="L75"></a>**L75**　：对。还有会晒王国，川圹王国，万象王国以及其他王国。

<a id="L76"></a>**L76**　主席

<a id="L77"></a>**L77**　：王国多得很。

<a id="L78"></a>**L78**　凯

<a id="L79"></a>**L79**　：当时老挝封建阶级还没有进入中央集权。

<a id="L80"></a>**L80**　主席

<a id="L81"></a>**L81**　：对。

<a id="L82"></a>**L82**　凯

<a id="L83"></a>**L83**　：虽然上面有一个全国性的国王，可是底下还是封建割据。后来英帝国主义和法帝国主义进来了，1893年它们签订了一个协定，把老挝分成两半，大致湄公河以西是英国的势力范围，以东是法国的势力范围。当时中国的云南也被划进法国的势力范围。

<a id="L84"></a>**L84**　主席

<a id="L85"></a>**L85**　：广东、广西直到广州湾都是法国的势力范围。

<a id="L86"></a>**L86**　俄国同日本就争夺东北，就是满洲地方。从北京到广州都是英国的势力范围，北京政府主要操纵在英国手里。所以，吴佩孚为什么打张作霖呢？就是英国人搞的，后头他自己后悔了，觉得上当了。后头英国人把在中国的势力范围都让给日本人了，因为那时希特勒起来了，他自顾不暇。

<a id="L87"></a>**L87**　凯

<a id="L88"></a>**L88**　：老挝原来是法国人的势力范围，后来美国人进来取代了法国人，现在日本人也插进来了，泰国对老挝也有野心。我们老挝这个国家虽小，可是很多个帝国主义都看中了它。所以我们说，小小的老挝也是旧中国的缩影，很多国家都看中了。

<a id="L89"></a>**L89**　主席

<a id="L90"></a>**L90**　：就是呀。

<a id="L91"></a>**L91**　凯

<a id="L92"></a>**L92**　：现在它们打着联合国的旗号，更多的国家都插进来了，什么加拿大、澳大利亚、菲律宾都进来了。

<a id="L93"></a>**L93**　主席

<a id="L94"></a>**L94**　：菲律宾不行了。

<a id="L95"></a>**L95**　凯

<a id="L96"></a>**L96**　：对。虽然我们国家小，人口少，但是美国在我们老挝花了不少钱。

<a id="L97"></a>**L97**　主席

<a id="L98"></a>**L98**　：他（指西沙瓦）是干什么的？

<a id="L99"></a>**L99**　周恩来（以下简称周）：他是军队的总参谋长。

<a id="L100"></a>**L100**　主席

<a id="L101"></a>**L101**　：你是管打仗的。你认识我们的总参谋长黄永胜同志吗？

<a id="L102"></a>**L102**　西沙瓦

<a id="L103"></a>**L103**　：我前次见过黄永胜同志。我们的关系很密切。

<a id="L104"></a>**L104**　主席

<a id="L105"></a>**L105**　：靠不住。

<a id="L106"></a>**L106**　我们帮他们的忙还太少吧？

<a id="L107"></a>**L107**　周

<a id="L108"></a>**L108**　：他们提出来的要求我们都满足了。现在就是运输比较困难。

<a id="L109"></a>**L109**　主席

<a id="L110"></a>**L110**　：不是修了一条公路吗？

<a id="L111"></a>**L111**　周

<a id="L112"></a>**L112**　：还没有完全通，只是到了孟赛，到桑怒、查尔平原还没有完全通。丰沙里那边人口少，只有9万人。

<a id="L113"></a>**L113**　主席

<a id="L114"></a>**L114**　：世界变了，从老挝来讲，也证明了这一点。

<a id="L115"></a>**L115**　帝国主义自找灭亡。它的目的就是想占地方，找人来埋葬它，我们有经验，譬如日本占了大半个中国，占了很多地方，除了四川及其他一些地方以外，都被它占领了，结果帮了我们的忙，老百姓都起来反对它。到它投降的时候，我们的军队超过了100万。开始跟日本打仗的时候，我们的军队只有2万人。

<a id="L116"></a>**L116**　我们开始跟日本打仗的时候你干什么？

<a id="L117"></a>**L117**　黄永胜

<a id="L118"></a>**L118**　（以下简称黄）：部队缩小以后当团长。

<a id="L119"></a>**L119**　主席

<a id="L120"></a>**L120**　：打日本初期，他不过是个团长。从井冈山到抗日，打了10年。他17岁当兵。

<a id="L121"></a>**L121**　林

<a id="L122"></a>**L122**　：现在我们的军事干部，数他的资格最老，秋收暴动他就当兵了。他比各大军区的干部资格都老。

<a id="L123"></a>**L123**　主席

<a id="L124"></a>**L124**　：日本人教育了中国人。后头美国人又帮助蒋介石打我们。日本投降以后，蒋介石同我们签订了和平协定，等他准备好了，他就开兵打我们。所以，我们就不大相信什么条约，什么签字这一套，这也是有点原因的。譬如说，我们两家并没有条约，也并没有签什么字，但是我们讲的话算数哇！帝国主义讲话不大算数，包括美国的走狗梭发那·富马。

<a id="L125"></a>**L125**　有些东西，你说组织联合政府也可以，但是要准备另外一手。组织联合政府的目的是为了消灭联合政府。

<a id="L126"></a>**L126**　凯

<a id="L127"></a>**L127**　：对。

<a id="L128"></a>**L128**　主席

<a id="L129"></a>**L129**　：永远的联合政府？没有那个道理。

<a id="L130"></a>**L130**　凯

<a id="L131"></a>**L131**　：我们也有过几次谈判、两次组织联合政府的教训。第一次联合政府搞了一年多，后来他就镇压了，破坏了，所以又重新打起来了。第二次联合政府只有8个月，他又破坏了，所以又重新打了起来。毛主席刚才说得很对，联合政府不是目的，不过是个手段，为了继续把革命向前推进，完成民族民主革命，然后搞社会主义。所以搞联合政府，是为了消灭政府。

<a id="L132"></a>**L132**　主席

<a id="L133"></a>**L133**　：就是这几句话。越南也好，柬埔寨也好，泰国也好，缅甸也好，都是这样。现在缅甸、泰国的游击队都有发展，虽然规模还不算大。游击队是一个训练干部的学校。资产阶级决不会为我们训练共产主义干部。

<a id="L134"></a>**L134**　凯

<a id="L135"></a>**L135**　：毛主席说得很对。

<a id="L136"></a>**L136**　主席

<a id="L137"></a>**L137**　：它的武装想消灭我们，那好，我们就打嘛。你打，就要有一支队伍，这支队伍就能够训练干部。我们应该首先说明，要有人民，要有军队的战士。但是人民同战士要干部领导，没有领导是散的。

<a id="L138"></a>**L138**　我们同老挝接近的有些什么族？

<a id="L139"></a>**L139**　周

<a id="L140"></a>**L140**　：同老挝族接近的，有傣族、壮族、傣族、壮族的话可以听懂40%，这两个族都跟他们接近。西双版纳的傣族也跟他们接近。

<a id="L141"></a>**L141**　凯

<a id="L142"></a>**L142**　：中国西双版纳的人可能跟我们是一个民族。

<a id="L143"></a>**L143**　主席

<a id="L144"></a>**L144**　：人口不多？

<a id="L145"></a>**L145**　凯

<a id="L146"></a>**L146**　：不多。

<a id="L147"></a>**L147**　主席

<a id="L148"></a>**L148**　：广西的壮族呢？

<a id="L149"></a>**L149**　凯

<a id="L150"></a>**L150**　：广西壮族的语言在生活方面跟我们通一点。

<a id="L151"></a>**L151**　主席

<a id="L152"></a>**L152**　：有点汉化了。

<a id="L153"></a>**L153**　凯

<a id="L154"></a>**L154**　：现在广西的壮话很多汉话。

<a id="L155"></a>**L155**　主席

<a id="L156"></a>**L156**　：叫他们老挝化好了。

<a id="L157"></a>**L157**　黄

<a id="L158"></a>**L158**　：老挝苗族不少。

<a id="L159"></a>**L159**　凯

<a id="L160"></a>**L160**　：北寮很多苗族。我们川圹是苗族最集中的一块地方，人比较多。桑怒、丰沙里、琅勃拉邦、乌多姆赛、沙耶武里、万象都有苗族分布。

<a id="L161"></a>**L161**　主席

<a id="L162"></a>**L162**　：有几十万人？

<a id="L163"></a>**L163**　凯

<a id="L164"></a>**L164**　：大概有20万人。

<a id="L165"></a>**L165**　黄

<a id="L166"></a>**L166**　：老挝的苗族跟广西的苗族是一样的。

<a id="L167"></a>**L167**　主席

<a id="L168"></a>**L168**　：你怎么知道？

<a id="L169"></a>**L169**　黄

<a id="L170"></a>**L170**　：我调查过。

<a id="L171"></a>**L171**　林

<a id="L172"></a>**L172**　：他在广东工作了很长时间。

<a id="L173"></a>**L173**　主席

<a id="L174"></a>**L174**　：他是广东的司令员。

<a id="L175"></a>**L175**　历史上大汉族主义可厉害了，强迫少数民族同化，不同化就打。所以，苗族、瑶族、壮族、彝族历史上不晓得受过多少战争，可是他们能打。汉族人多，欺负他们。

<a id="L176"></a>**L176**　凯

<a id="L177"></a>**L177**　：我们那里苗族人也能打仗。所以，现在美国人利用苗族人建立了一支“特种部队”，企图长期利用这支力量来破坏老挝革命。

<a id="L178"></a>**L178**　主席

<a id="L179"></a>**L179**　：要打到泰国去：

<a id="L180"></a>**L180**　周

<a id="L181"></a>**L181**　：泰国参加打老挝、柬埔寨，它已经突破了国界嘛！

<a id="L182"></a>**L182**　主席

<a id="L183"></a>**L183**　：泰国人口多，3000万。不晓得泰国是什么族。

<a id="L184"></a>**L184**　周

<a id="L185"></a>**L185**　：基本上是泰族。

<a id="L186"></a>**L186**　主席

<a id="L187"></a>**L187**　：历史上战争没有断过。我前次同黎笋同志说过，看来这个世界不那么和平。世界上还有帝国主义要捣乱。各国人民我看也快起来了，包括帝国主义国家的人民。有搞和平运动的，有打游击的，有在思考问题的，也有许多人尚未觉悟。各国人民起来反对帝国主义，这叫做革命。能够相信，只有十月革命，或者中国革命、越南革命、老挝革命，其他地方就不革命了吗？不可能嘛！

<a id="L188"></a>**L188**　林

<a id="L189"></a>**L189**　：哪里有压迫和剥削，哪里就有革命。

<a id="L190"></a>**L190**　主席

<a id="L191"></a>**L191**　：如果其他地方不革命，那马克思列宁主义就不灵了。列宁说帝国主义是快要灭亡的资本主义，不然就是改名为帝国主义是上升的资本主义了。

<a id="L192"></a>**L192**　帝国主义也不那么舒服。你说尼克松就那么舒服吗？

<a id="L193"></a>**L193**　周

<a id="L194"></a>**L194**　：成天不能睡觉。

<a id="L195"></a>**L195**　主席

<a id="L196"></a>**L196**　：那位同志（指沙南）是干什么的？

<a id="L197"></a>**L197**　凯

<a id="L198"></a>**L198**　：负责宣传工作。那一位同志中坎派，是我们党驻河内的代表。

<a id="L199"></a>**L199**　主席

<a id="L200"></a>**L200**　：这个名字我熟悉。

<a id="L201"></a>**L201**　问题清楚了，你们的谈话我也看了。
