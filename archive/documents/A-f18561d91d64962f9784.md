<a id="L9"></a>**L9**　（一九三七年十月二十四日）

<a id="L10"></a>**L10**　我要与同志们说的，在这次伟大的事业中获得成就的原因，把它总括起来说，就是能够克服困难与联系群众，过去的十年斗争经验均证明着，你们这次挖窑洞也证明着，将来在抗日战争中还要证明着，如能如此，可以战胜一切！

<a id="L11"></a>**L11**　克服自然困难战胜泥土与克服活的敌人，战胜日寇虽然有很多方面相同，然而有很多方面不完全相同，它将更艰苦更困难些，所以在抗战中，不独要有克服困难与联系群众的方针，还要善于应用战略战术，还要善于组织动员领导群众与争取同盟军等工作补充起来才行。

<a id="L12"></a>**L12**　你们现在已经有克服困难与联系群众的精神，只要在这个基础上经你们的天才把他继续发扬与发挥起来，战胜日本，驱逐日本出中国是完全有可能的。

<a id="L13"></a>**L13**　（见抗大校刊《我们的伟大事业》第十四期）
