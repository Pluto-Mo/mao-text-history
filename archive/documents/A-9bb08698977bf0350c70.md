<a id="L8"></a>**L8**　红军第四军司令部布告

<a id="L9"></a>**L9**　（一九二九年）

<a id="L10"></a>**L10**　红军宗旨，民权革命，赣西一军，声威远震。

<a id="L11"></a>**L11**　此番计划，分矢前进，辅佐民夫，服从命令。

<a id="L12"></a>**L12**　平买平卖，事实为证，乱烧乱杀，在所必禁。

<a id="L13"></a>**L13**　全国各地，压迫太甚，工人农人，十分痛苦。

<a id="L14"></a>**L14**　土豪劣绅，横行乡镇，重息要租，人人悲愤。

<a id="L15"></a>**L15**　白军士兵，饥寒交并，小资产者，捐税极重。

<a id="L16"></a>**L16**　洋债越多，国债受困，帝国主义，哪个不恨。

<a id="L17"></a>**L17**　国民匪党，完全反动，口是心非，不能过硬。

<a id="L18"></a>**L18**　蒋桂冯阎，同床异梦，冲突已起，军阀倒运。

<a id="L19"></a>**L19**　饭可充饥，药可医病，共产主张，极为公正。

<a id="L20"></a>**L20**　地主田地，农民收种，债不要还，租不要送。

<a id="L21"></a>**L21**　增加工钱，老板担任，八时工作，恰好相称。

<a id="L22"></a>**L22**　军人待遇，必须改订，发给田地，士兵有份。

<a id="L23"></a>**L23**　敌方士兵，可以投顺，以前行动，可以不问。

<a id="L24"></a>**L24**　累进税法，最为适用，苛捐杂税，扫除一净。

<a id="L25"></a>**L25**　城市商人，积珠累财，只要服从，余昔不论。

<a id="L26"></a>**L26**　对待外人，必须严峻，工厂银行，没收归并。

<a id="L27"></a>**L27**　外资外债，概不承认，外兵外舰，不准入境。

<a id="L28"></a>**L28**　打倒列强，人人高兴，打倒军阀，除恶务尽。

<a id="L29"></a>**L29**　统一中华，举国称庆，满蒙回藏，章程自定。

<a id="L30"></a>**L30**　国民政府，一群恶棍，合力铲除，肃清乱政。

<a id="L31"></a>**L31**　全国工农，风发雷奋，夺取政权，为期日近。

<a id="L32"></a>**L32**　革命成功，尽在民众，布告四方，大家起劲。
