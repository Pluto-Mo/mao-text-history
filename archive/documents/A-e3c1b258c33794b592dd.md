<a id="L9"></a>**L9**　（一九六七年八月二十七日）

<a id="L10"></a>**L10**　一、许世友要帮助过关，他是一个战将，文化革命以来，落后了，跟不上；

<a id="L11"></a>**L11**　二、要出马恩列斯语录；

<a id="L12"></a>**L12**　三、文化大革命要搞三年，一年发动一年胜利，一年扫尾；

<a id="L13"></a>**L13**　四、天津南开大学卫东红卫兵写了一篇好文章（指《要大胆使用革命干部》），提出了一个新问题，红卫兵小报是好东西；

<a id="L14"></a>**L14**　五、不要把党内一小撮走资派和军内一小撮走资派并提，只提党内一小撮。把解放军搞垮了还要不要政府？

<a id="L15"></a>**L15**　六、群众组织提以我为核心，这样提是极蠢的；

<a id="L16"></a>**L16**　七、依靠青年人；

<a id="L17"></a>**L17**　八、依靠群众，加强专政，新疆办大型劳改农场不一定好，要研究；

<a id="L18"></a>**L18**　九、要抓学习，把工作做好，要精兵简政。
