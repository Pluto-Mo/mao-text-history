<a id="L2"></a>**L2**　中文马克思主义文库

<a id="L3"></a>**L3**　-&gt;

<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东会见墨西哥总统埃切维里亚的谈话

<a id="L6"></a>**L6**　（1973年4月20日）

<a id="L7"></a>**L7**　【埃切维里亚·阿尔瓦雷斯（1922-）1970-1976年就任墨西哥总统。执政期间，颁布新选举法，放宽各政党登记和竞选条件及参政年龄限制。鼓励私人企业扩大生产，将1600万公顷土地分配给农民，兴建公共工程，扩大交通运输和住宅建设，同时还增加教育拨款，建立科研机构，增设大学和技术专科学校。积极发展同亚洲、非洲和欧洲国家的关系，扩大同第三世界的经济贸易联系。】

<a id="L8"></a>**L8**　埃

<a id="L9"></a>**L9**　：我不是讲卫生，我只是不抽烟。

<a id="L10"></a>**L10**　我们刚才谈闯祸，其实是我们墨西哥在闯祸。

<a id="L11"></a>**L11**　毛主席

<a id="L12"></a>**L12**　：你们闯美国的祸了，那个我们赞成。

<a id="L13"></a>**L13**　安吉亚诺大使

<a id="L14"></a>**L14**　：是在我们国家闯美国的祸，不是到美国去闯祸。

<a id="L15"></a>**L15**　埃

<a id="L16"></a>**L16**　：现在有1000万黑西哥后裔住在美国的南部。

<a id="L17"></a>**L17**　毛主席

<a id="L18"></a>**L18**　：1000万？

<a id="L19"></a>**L19**　埃

<a id="L20"></a>**L20**　：1000万墨西哥后裔。所以在美国有墨西哥的影响。

<a id="L21"></a>**L21**　毛主席

<a id="L22"></a>**L22**　：那你不投票，他总统选举就困难了。

<a id="L23"></a>**L23**　埃

<a id="L24"></a>**L24**　：在美国的墨西哥后裔是参加投票的，并且多年来在竞选中经常是投了得胜者的票。

<a id="L25"></a>**L25**　毛主席

<a id="L26"></a>**L26**　：都是反对尼克松，还是支持尼克松的？

<a id="L27"></a>**L27**　埃

<a id="L28"></a>**L28**　：支持另外一个竞选人．这是美国南部的现实情况。

<a id="L29"></a>**L29**　毛主席

<a id="L30"></a>**L30**　：但是我投尼克松的票。所以现在一些所谓左派讲我是“右倾”。

<a id="L31"></a>**L31**　埃

<a id="L32"></a>**L32**　：毛主席为什么投尼克松的票？

<a id="L33"></a>**L33**　毛主席

<a id="L34"></a>**L34**　：因为他最反动！欺骗性比较少一点。美国军队到一个地方，那个地方就闹革命了。

<a id="L35"></a>**L35**　埃

<a id="L36"></a>**L36**　：现在大家关心一件事，即青年不愿意打仗，但是他们看不到明确的道路。他们目前生活富裕，物质生活好，但不满意他们的前途。这是一个很深刻的问题。

<a id="L37"></a>**L37**　毛主席

<a id="L38"></a>**L38**　：我，恐怕总理也是，我们青年时代也没有想到要革命啊。读孔夫子的书，我变成封建主义者。封建主义怎么说？

<a id="L39"></a>**L39**　黄

<a id="L40"></a>**L40**　：Fcudalismo（西班牙文：封建主义。）

<a id="L41"></a>**L41**　埃

<a id="L42"></a>**L42**　：对。

<a id="L43"></a>**L43**　毛主席

<a id="L44"></a>**L44**　：然后又读资本主义的书，变成资本主义者了。到20几岁我还不知道世界上有马克思主义。十月革命开始我才知道世界上有什么马克思、马克思主义、列宁、列宁主义。后来不知怎么样七弄八弄又转到共产党。

<a id="L45"></a>**L45**　埃

<a id="L46"></a>**L46**　：这个道理你自己一定知道。斗争的实践使你相信了马列主义。知道马列主义是唯一的道路。

<a id="L47"></a>**L47**　毛主席

<a id="L48"></a>**L48**　：也没有。我开始就搞些什么城市的工人运动，搞什么农民运动，此外搞些什么学生运动。搞些跟国民党合作的运动，就是没有准备打仗。就是要感谢我们现在在台湾的那位先生！

<a id="L49"></a>**L49**　周总理

<a id="L50"></a>**L50**　：反面教员。

<a id="L51"></a>**L51**　毛主席

<a id="L52"></a>**L52**　：他让我上山去打游击。他到处杀人，城市里头呆不下去啊，那没有法啊，只好上山啊。一打就10年，打到延安。

<a id="L53"></a>**L53**　埃

<a id="L54"></a>**L54**　：是的。

<a id="L55"></a>**L55**　毛主席

<a id="L56"></a>**L56**　：后头日本人来了，又跟蒋介石讲和，跟日本人打。日本人打完了，又跟蒋介石打。

<a id="L57"></a>**L57**　埃

<a id="L58"></a>**L58**　：这些我们知道。

<a id="L59"></a>**L59**　毛主席

<a id="L60"></a>**L60**　：你看，我是一个教书的，教小学的。我的职务是小学教师，一不知道马克思，二不知道打仗。这就是环境逼使人，它不以我的意志办事。那个环境逼得我去看马克思跟打仗。现在呢，环境又逼得我走“右倾机会主义”的道路。（众笑）请了尼克松到这个地方，又请了日本首相田中到这个地方，于是我的名誉就不好了。不晓得哪一天要“左倾”起来，恐怕要没有机会了，我80岁了。（埃笑）不以人的意志为转移。依环境，依大势。跟着跑。

<a id="L61"></a>**L61**　埃

<a id="L62"></a>**L62**　：这是主要原因。

<a id="L63"></a>**L63**　毛主席

<a id="L64"></a>**L64**　：一卷进去了，就主观起作用了。

<a id="L65"></a>**L65**　埃

<a id="L66"></a>**L66**　：是这样。这是互相配合的两种因素。
