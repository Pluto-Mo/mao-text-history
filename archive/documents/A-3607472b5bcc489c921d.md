<a id="L8"></a>**L8**　在吴旗打给林彪同志的电报

<a id="L9"></a>**L9**　（一九三五年十一月二十一日）

<a id="L10"></a>**L10**　林、聂、李、邓：

<a id="L11"></a>**L11**　一、本日已将敌三十五师骑兵团全部击溃、缴获正清查中。

<a id="L12"></a>**L12**　二、毛炳文主力尚在廿里铺红德城之线及其以东地区，距我约三、四日行程，但其先遣兵力步骑各一团则距我较近，镇铁城则有奉军一部。

<a id="L13"></a>**L13**　我军坚决准备消灭毛炳文，先遣兵力及求得整理之目的。明二十二日：

<a id="L14"></a>**L14**　甲，一纵队移至二道川、三道川一带宿营，派部队向两川上游侦察。

<a id="L15"></a>**L15**　乙，二纵队在杨城子及吴旗镇原地休息，派部队向头道川上游侦察。

<a id="L16"></a>**L16**　丙，三纵队在宁包川原地休息。

<a id="L17"></a>**L17**　丁，支队直属队在吴旗镇。

<a id="L18"></a>**L18**　四、准备二十二日再休息一天。

<a id="L19"></a>**L19**　五，加紧筹足三天粮食。

<a id="L20"></a>**L20**　六，加紧进行教育解释支队训令。

<a id="L21"></a>**L21**　毛

<a id="L22"></a>**L22**　廿一日十时

<a id="L23"></a>**L23**　林、聂：

<a id="L24"></a>**L24**　我们率二十三分队到二道川口两端十金处之刘河湾，战斗情况如何望告，廿分队留吴旗镇。

<a id="L25"></a>**L25**　毛

<a id="L26"></a>**L26**　廿一日十三时半

<a id="L27"></a>**L27**　林、聂：

<a id="L28"></a>**L28**　一、明廿二日在吴起镇附近休息一天，一纵队在二道川、三道川、纵队部驻地。

<a id="L29"></a>**L29**　二、第二纵队在吴起镇，杨城子支队部，在吴起镇各加足准备二三天粮食。

<a id="L30"></a>**L30**　毛

<a id="L31"></a>**L31**　廿一日十八时
