<a id="L5"></a>**L5**　毛泽东会见法国总统蓬皮杜谈话节选

<a id="L6"></a>**L6**　（1973年9月12日）

<a id="L7"></a>**L7**　【乔治·让·蓬皮杜（Georges Pompidou，1911—1974），法国总理（1962—1968）和总统（任期1969年至1974年，于任内去世）。他是第一位访问中国的法国国家元首，也是西方国家元首访华第一人。】

<a id="L8"></a>**L8**　主席

<a id="L9"></a>**L9**　：（对蓬）我这个人文化不行，不懂外交。

<a id="L10"></a>**L10**　蓬

<a id="L11"></a>**L11**　：但是你很了解中国人民。

<a id="L12"></a>**L12**　主席

<a id="L13"></a>**L13**　：了解一些，不完全了解。我年纪大了，搞了一些官僚主义。（对齐）也叫bureaucratism（官僚主义）吗？

<a id="L14"></a>**L14**　齐

<a id="L15"></a>**L15**　：对，英文是bureaucratism（官僚主义）。

<a id="L16"></a>**L16**　蓬

<a id="L17"></a>**L17**　：但是你过去也从事了很多活动。

<a id="L18"></a>**L18**　主席

<a id="L19"></a>**L19**　：哎呀，打了二十几年仗了，把精力也耗费得差不多。我是一个小学教员。

<a id="L20"></a>**L20**　蓬

<a id="L21"></a>**L21**　：我也是教员。

<a id="L22"></a>**L22**　总理

<a id="L23"></a>**L23**　：他当过中学教员。

<a id="L24"></a>**L24**　主席

<a id="L25"></a>**L25**　：我是primary school teacher（小学教员），形势把我逼去打仗。那么要打呢，就打吧。一打就是二十几年。后头还跟美国人在朝鲜打了一仗。跟蒋介石打得多了。跟日本人打了八年。所以外国人到中国，现在这个时代比较难。中国人打游击战争可以。（蓬笑）

<a id="L26"></a>**L26**　蓬

<a id="L27"></a>**L27**　：我曾有机会见到这两个大国的领导人，他们宣布自己是爱好和平的。我认为他们有理由现在成为爱好和平的人。

<a id="L28"></a>**L28**　主席

<a id="L29"></a>**L29**　：我不信。

<a id="L30"></a>**L30**　战争总有一天是要打的。（蓬无可奈何地举手向天。）宁可放在这个“打”字上，把第二个才放在和平上——peace（和平），不然就要丧失警惕。
