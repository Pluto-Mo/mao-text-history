<a id="L9"></a>**L9**　（一九六六年十月一日）

<a id="L10"></a>**L10**　主席问：你看左派有多少?

<a id="L11"></a>**L11**　答：上海好一点，左派队伍大。

<a id="L12"></a>**L12**　主席问：多大？答：工人有四十万、五十万、六十万。

<a id="L13"></a>**L13**　主席说：左派不会多，大概占10%。

<a id="L14"></a>**L14**　答：后期可能多一点。

<a id="L15"></a>**L15**　主席说：有20%就不得了啦。

<a id="L16"></a>**L16**　（注：以上谈话是六六年国庆节晚上在天安门上看焰火休息时进行的，张春桥同志一九六七年六月十六日在上海革委会扩大会议上传达此次谈话情况时还补充说：这是指世界观的改造，不是指一般的表现，是指世界观里有较多的马列主义、毛泽东思想。要完全的马列主义、毛泽东思想就更难了。）
