<a id="L8"></a>**L8**　对军事工程学院成立与第一学期开学的训词

<a id="L9"></a>**L9**　（一九五三年八月二十六日）

<a id="L10"></a>**L10**　军事工程学院陈院长和全体教授、助教、学院工作人员同志们：

<a id="L11"></a>**L11**　当你们开学的时候，我向你们致以热烈的祝贺。

<a id="L12"></a>**L12**　在此时机，我并向热诚帮助我们计划与创办这个学院的苏联政府、苏联专家表示衷心的感谢！

<a id="L13"></a>**L13**　中国人民解放军军事工程学院的创办，对于我国国防事业具有极重大的意义，为了建设现代化的国防，我们的陆军、空军和海军都必须有充分的机械化的装备和设备，这一切都不能离开复杂的专门的技术。今天我们迫切的希望的就是要有大批的能够掌握和驾驶技术的人，并使我们的技术能够得到不断的改善和进步。军事工程学院的创办，其目的就是为了解决这个迫切而光荣的任务。

<a id="L14"></a>**L14**　向苏联专家学习，这是我们建军史上的优良传统，无论住任何时候，任何工作部门，都应当如此。这点，对于你们这个学院有更加重要的意义。你们必须学习苏联的先进科学和技术知识，学习苏联军事科学建设的丰富经验，学习苏联专家同志的学习态度和工作态度，学习苏联专家高度的爱国主义和国际主义精神，在学习上应该是虚心诚恳，不要学到一点就自满骄傲。

<a id="L15"></a>**L15**　保持和发扬中国人民解放军的光荣传统，特别是全心全意为人民服务的精神和自我牺牲的英雄气概，这在你们学院是和全军一样，必须充分领会和一刻也不能忘记的。

<a id="L16"></a>**L16**　希望你们团结一致，办好学院，尊重专家，努力学习，为完成人民军事委员会给予你们的光荣任务而奋斗！

<a id="L17"></a>**L17**　（1953年8月26日）
