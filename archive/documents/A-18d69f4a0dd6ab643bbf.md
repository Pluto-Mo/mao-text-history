<a id="L8"></a>**L8**　对志愿军党委的指示（摘录）

<a id="L9"></a>**L9**　我中国人民志愿军进入朝鲜境内，必须对朝鲜人民、朝鲜人民军、朝鲜民主政府、朝鲜劳动党、及其它民主党派，及朝鲜人民领袖金日成同志表示友谊和尊重，严格地遵守军事纪律和政治纪律，这是保证完成军事任务的一个极重要的政治基础。

<a id="L10"></a>**L10**　（中国革命军事博物馆展出）

<a id="L11"></a>**L11**　对中国人民志愿军指示的团结朝鲜人民四项原则

<a id="L12"></a>**L12**　对中国人民志愿军指示的团结朝鲜人民四项原则：

<a id="L13"></a>**L13**　一、拥护朝鲜劳动党，朝鲜人民共和国金日成首相;

<a id="L14"></a>**L14**　二、严格遵守朝鲜政府的政策命令；

<a id="L15"></a>**L15**　三、爱护朝鲜人民利益；

<a id="L16"></a>**L16**　四、以自我批评的精神．检查缺点，增进团结。
