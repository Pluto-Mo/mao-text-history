<a id="L8"></a>**L8**　给自己诗词作的解释

<a id="L9"></a>**L9**　我的几首词发表后，注家蜂起，全是好心。一部分说对了，一部分说的不对。我有说明的责任。一九五八年在广州，见一九五八年刊本，天头甚宽，因而，写了下面一些字，谢注家兼谢读者。鲁迅在一九二七年在广州修改他的《古小说钩沉》后记中说道：“于时云海沉沉，星月澄碧餮蚊逞强，于在广州。”从那时到今天，三十一年了，大陆上的蚊灭得差不多了。当然革命尚未全成，同志们仍需努力。港台一带，餮蚊尚多，西方世界，餮蚊成阵。安得其全世界各民族千百万愚公，用他们自己的移山办法，把蚊阵一扫而空，岂不伟哉！

<a id="L10"></a>**L10**　试仿陆放翁曰：

<a id="L11"></a>**L11**　人类今天上太空，但悲不见五洲同。愚公尽扫餮蚊日，公祭毋忘告马翁。

<a id="L12"></a>**L12**　毛泽东一九五八年十二月二十一日上午十时

<a id="L13"></a>**L13**　沁园春.长沙

<a id="L14"></a>**L14**　一九二五年

<a id="L15"></a>**L15**　击水：（到中流击水，浪遏飞舟）

<a id="L16"></a>**L16**　游泳，那时初学，盛夏水涨，几死者数。一群入终于坚持到隆冬。犹在水中。当时有一篇忘记了。只记得两句：“自信人生两百年，会当击水三千里。”

<a id="L17"></a>**L17**　菩萨蛮.黄鹤楼

<a id="L18"></a>**L18**　一九二七年

<a id="L19"></a>**L19**　心潮：（把酒酌滔滔。心潮逐浪高）

<a id="L20"></a>**L20**　一九二七年大革命失败的前夕，心情苍凉，一时不知如何是好。这是那年春季。夏季八月七日，党的紧急会议决定武装斗争。从此才找到了出路。

<a id="L21"></a>**L21**　清平乐.会昌

<a id="L22"></a>**L22**　一九三四年夏

<a id="L23"></a>**L23**　踏遍青山人未老：（踏遍青山人未老，风景这边独好。）

<a id="L24"></a>**L24**　一九三四年形势危急。准备长征，心情又是郁闷的。这首清平乐与前面那首菩萨蛮一样，表露了同一的心情。

<a id="L25"></a>**L25**　忆泰娥.娄山关

<a id="L26"></a>**L26**　一九三五年

<a id="L27"></a>**L27**　万里长征，千回百折。胜少于困难不知多少倍。心情是沉郁的。过了岷山，豁然开朗，转到了反面，柳暗花明又一村了。以下几首反映了这种心情。

<a id="L28"></a>**L28**　七律.长征一九三五年十月

<a id="L29"></a>**L29**　水拍：（金沙水拍云崖暖，大渡桥横铁索寒）

<a id="L30"></a>**L30**　改水拍，这是一位不相识的朋友建议的。他说：不要一篇有两个“浪”字，是可以的。

<a id="L31"></a>**L31**　三军：（更喜岷山千里雪，三军过后尽开颜。）

<a id="L32"></a>**L32**　红军一方面军、二方面军、四方面军。不是陆海空三军，也不是古代晋国所谓上军，中军、下军的三军。

<a id="L33"></a>**L33**　念奴娇.昆仑

<a id="L34"></a>**L34**　一九三五年十月

<a id="L35"></a>**L35**　主题思想是反对帝国主义，不是别的。后一句：“一截留中国”改为“一截还东国”。忘记了日本人民是不对的。这样，英、美、日都涉及了。别的解释不合实际。

<a id="L36"></a>**L36**　清平乐.六盘山

<a id="L37"></a>**L37**　一九三五年十月

<a id="L38"></a>**L38**　苍龙：（今日长缨在手，何时缚住苍龙？）指蒋介石。不是日本人。因为当时全付精力要对付的是蒋不是日。

<a id="L39"></a>**L39**　沁园春.雪

<a id="L40"></a>**L40**　一九三六年二月

<a id="L41"></a>**L41**　反对封建主义，批判两千年来的封建主义的一个反动侧面。

<a id="L42"></a>**L42**　文釆、风骚、大雕，只能如此，须知这是写诗啊，难道可以咒骂这些人吗？别的解释是错误的。

<a id="L43"></a>**L43**　末三句，指无产阶级。

<a id="L44"></a>**L44**　七律.和柳亚子先生

<a id="L45"></a>**L45**　一九四九年四月二十九日

<a id="L46"></a>**L46**　三十一年：（三十一年还旧国。落花时节馈华章）

<a id="L47"></a>**L47**　一九一九年离开北京。一九四九年还北京。旧国之国：都城。不是Ltoho（国家）。也不是Country（首都）。

<a id="L48"></a>**L48**　浣溪纱.和柳亚子先生

<a id="L49"></a>**L49**　一九五○年十月

<a id="L50"></a>**L50**　乐奏：（万方乐奏有于阗）这里误置为“奏乐”。应改。（现版已改）

<a id="L51"></a>**L51**　水调歌头.游泳

<a id="L52"></a>**L52**　一九五六年六月

<a id="L53"></a>**L53**　长沙水：（才饮长沙水）民谣：“常德山山有德，长沙水水无沙”。所谓长沙水，在常德东。有一个有名的“白沙井”。

<a id="L54"></a>**L54**　武昌鱼：（又食武昌鱼）

<a id="L55"></a>**L55**　三国孙权一度从京口（镇江）迁都武昌。官僚、绅士、地主及富裕阶层不悦，反对迁都。造出口号云：“宁饮扬州（建业）水。不食武昌鱼”。那时的扬州人，心情如此。现在改变了。武昌鱼是颇有味道的。
