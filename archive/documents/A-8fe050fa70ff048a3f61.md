<a id="L9"></a>**L9**　（一九六七年四月十九日下午）

<a id="L10"></a>**L10**　我祝贺你，祝贺这次大会的成功。请代向全北京市革命造反派祝贺。

<a id="L11"></a>**L11**　致敬电是全世界无产者联合起来的大宣言，就不要再搞宣言了。

<a id="L12"></a>**L12**　青年人要参加你们的工作，使前辈人不脱离群众，使青年人得到锻炼。青年人不能脱产，这样会造成脱离群众的，要半官半民。

<a id="L13"></a>**L13**　北京的形势还有反复，无政府主义就是机会主义的惩罚。要不怕犯错误，各种反动的观点和反动的群众组织是极少数的。就是反动组织也要做工作，但是还得斗争。
