<a id="L7"></a>**L7**　（1967年11月26日）

<a id="L8"></a>**L8**　【德钦巴登顶（1914-1997）， 时任缅甸共产党副主席，1975年后为主席。1964年 9月, 缅共中央制定了“赢得战争，夺取政权”的革命路线，这是缅共历史上的一个重要转折点。1968年初，缅共又在缅东北开辟了新的革命根据地，并建立了依靠贫雇农、联合中农的基层人民民主政权。1968年9月24日，德钦丹东主席遇害后，由德钦巴登顶为副主席。柯生为他在中国国内的化名。】

<a id="L27"></a>**L27**　（以下简称柯）：同志们到北京大概一个多星期了。他们（指何高、杨光等）来得比较早，一个多月了。

<a id="L28"></a>**L28**　主席

<a id="L30"></a>**L30**　柯

<a id="L31"></a>**L31**　：没有。他们这一次能见到毛主席，感到非常高兴，对他们是一个很大的鼓舞。

<a id="L32"></a>**L32**　主席

<a id="L36"></a>**L36**　主席

<a id="L38"></a>**L38**　柯

<a id="L39"></a>**L39**　：17年了。

<a id="L40"></a>**L40**　主席

<a id="L44"></a>**L44**　柯

<a id="L45"></a>**L45**　：我们在中国17年不能回到缅甸去，这次主席的路线取得了胜利，我们能回去感到非常高兴。（这时主席笑了）

<a id="L46"></a>**L46**　明

<a id="L47"></a>**L47**　：我们在农村坚持了十几年，对毛主席非常敬仰。因为有毛主席，所以我们能坚持下来。请毛主席给我签一个字，留着纪念。（主席在柯明的《毛主席语录》上签字）

<a id="L48"></a>**L48**　我现在走了。非常感谢主席。

<a id="L49"></a>**L49**　主席

<a id="L50"></a>**L50**　：这不需要感谢。

<a id="L51"></a>**L51**　（这时柯明退席）

<a id="L52"></a>**L52**　（向柯生）我跟你见过几次了？

<a id="L53"></a>**L53**　柯

<a id="L54"></a>**L54**　：四次。1963年缅甸和谈时一次，最后一次是今年国庆。

<a id="L55"></a>**L55**　主席

<a id="L56"></a>**L56**　：63年到现在已经5年了。那些同志回去都好吗？

<a id="L57"></a>**L57**　（这时，罗线等四人进来，参加了谈话）

<a id="L58"></a>**L58**　柯

<a id="L59"></a>**L59**　：很好。这是罗线同志、甘底同志、赵明同志、赵云同志。

<a id="L60"></a>**L60**　主席

<a id="L61"></a>**L61**　：（对罗线）你到中国十几年了，一直没有看见你。

<a id="L62"></a>**L62**　罗线

<a id="L63"></a>**L63**　（以下简称罗）：见到主席非常高兴。

<a id="L64"></a>**L64**　主席

<a id="L65"></a>**L65**　：你一直在四川还是贵州？

<a id="L66"></a>**L66**　罗

<a id="L67"></a>**L67**　：住在贵阳。

<a id="L68"></a>**L68**　主席

<a id="L69"></a>**L69**　：看样子你并不怎么老嘛。

<a id="L70"></a>**L70**　罗

<a id="L71"></a>**L71**　：45岁了。还可以打30年仗。

<a id="L72"></a>**L72**　主席

<a id="L73"></a>**L73**　：可以。45、55、65、75，可以。

<a id="L74"></a>**L74**　重要的是要在斗争中学习，训练班也可以办一点。真正的学习是打仗。如果不去打仗，学习不到什么东西。单是课堂上学军事、学政治我看懂的还是少。

<a id="L75"></a>**L75**　你们在中国学习这些东西，回去切不可照抄。要按照你们的情况办。

<a id="L76"></a>**L76**　你们跟泰国有接触吗？

<a id="L77"></a>**L77**　柯

<a id="L78"></a>**L78**　：跟泰国南部有接触，北部没有。

<a id="L79"></a>**L79**　主席

<a id="L80"></a>**L80**　：（对罗线）在你们国家，你这个民族算少数民族。你这个民族有多少人？

<a id="L81"></a>**L81**　罗

<a id="L82"></a>**L82**　：20万。

<a id="L83"></a>**L83**　主席

<a id="L84"></a>**L84**　：还有其他少数民族？

<a id="L85"></a>**L85**　柯

<a id="L86"></a>**L86**　：很多，有100多个民族。缅甸人口的45%是少数民族。

<a id="L87"></a>**L87**　主席

<a id="L88"></a>**L88**　：少数民族政策是一项重要的政策。

<a id="L89"></a>**L89**　你们全国有多少人口？

<a id="L90"></a>**L90**　柯

<a id="L91"></a>**L91**　：2500万。

<a id="L92"></a>**L92**　主席

<a id="L93"></a>**L93**　：面积多大？

<a id="L94"></a>**L94**　柯

<a id="L95"></a>**L95**　：262000平方英里。

<a id="L96"></a>**L96**　主席

<a id="L97"></a>**L97**　：是一个大国嘛。同越南差不多，比它大一点。

<a id="L98"></a>**L98**　柯

<a id="L99"></a>**L99**　：比越南大一些。缅甸的面积比罗马尼亚、南斯拉夫、阿尔巴尼亚三个国家加起来还大。

<a id="L100"></a>**L100**　主席

<a id="L101"></a>**L101**　：26万平方英里，合60万平方公里，跟四川差不多大。

<a id="L102"></a>**L102**　你们都在中国有十几年了吗？

<a id="L103"></a>**L103**　柯

<a id="L104"></a>**L104**　：何高同志17年，杨光同志17年，古方同志15年，罗线同志18年。

<a id="L105"></a>**L105**　刘、邓路线的结果，使我们正是青春的时候在中国度过了，不过为时不晚，还可以打仗。

<a id="L106"></a>**L106**　主席

<a id="L107"></a>**L107**　：为时不晚，还可以打仗。你们这个仗是哪一年打起的？

<a id="L108"></a>**L108**　柯

<a id="L109"></a>**L109**　：1948年。

<a id="L110"></a>**L110**　主席

<a id="L111"></a>**L111**　：快20年了。

<a id="L112"></a>**L112**　柯

<a id="L113"></a>**L113**　：明年3月28日就整整20年了。

<a id="L114"></a>**L114**　主席

<a id="L115"></a>**L115**　：这是一种情况，是两个帝国主义世界大战之间、处于世界和平时期的一种战争。

<a id="L116"></a>**L116**　中国的革命你们知道，是第一次世界大战以后才发生的。1918年到1925年7年以后才有北伐战争。1927年蒋介石叛变。共产党跟国民党打仗，是从1927年开始的，一直到第二次世界大战以后。时间拖得很长。

<a id="L117"></a>**L117**　世界上还要打世界大战的。但是你们不能等它。

<a id="L118"></a>**L118**　你们估计奈温有没有可能把外国军队引进来？

<a id="L119"></a>**L119**　柯

<a id="L120"></a>**L120**　：1965年我党主席说过，如果奈温打不过，他可能把美军引进缅甸。我看目前这个可能性不太大。

<a id="L121"></a>**L121**　主席

<a id="L122"></a>**L122**　：这个可能性不太大。

<a id="L123"></a>**L123**　柯

<a id="L124"></a>**L124**　：引进美军，我们正希望他这样做。现在看来，美军运到南越很多，要再运到缅甸来有困难。我们得到一个消息，英国人告诉奈温：你不要把希望寄托在美军帮助你们缅甸上。

<a id="L125"></a>**L125**　主席

<a id="L126"></a>**L126**　：但是他们要灭亡的时候，还是要把外国军队引进来的。

<a id="L127"></a>**L127**　柯

<a id="L128"></a>**L128**　：对，我们党已经在思想上做好了准备。

<a id="L129"></a>**L129**　主席

<a id="L130"></a>**L130**　：引进来也不是一件坏事。比如，泰国就驻有美军。有帝国主义，也有封建主义。泰国共产党搞得好，很有前途，很有希望。

<a id="L131"></a>**L131**　你们这些同志过去在乡村里的人多，还是在城市里的人多？

<a id="L132"></a>**L132**　柯

<a id="L133"></a>**L133**　：大部分都是农村的。

<a id="L134"></a>**L134**　主席

<a id="L135"></a>**L135**　：在农村上过学吗？

<a id="L136"></a>**L136**　柯

<a id="L137"></a>**L137**　：有些上过学。大部分同志到了中国以后才学文化。缅文，景颇文都是到中国以后学习的。

<a id="L138"></a>**L138**　主席

<a id="L139"></a>**L139**　：有这样的教科书吗？

<a id="L140"></a>**L140**　柯

<a id="L141"></a>**L141**　：用旧的教科书。

<a id="L142"></a>**L142**　主席

<a id="L143"></a>**L143**　：也可以自己编嘛。你们的家属、小孩现在教什么？

<a id="L144"></a>**L144**　柯

<a id="L145"></a>**L145**　：现在在中国的这些家属，准备将来参加缅甸革命，因此他们现在学习五种东西，即医务、电台、修理枪支、文工团、造炸药。

<a id="L146"></a>**L146**　主席

<a id="L147"></a>**L147**　：我说的是小孩。

<a id="L148"></a>**L148**　柯

<a id="L149"></a>**L149**　：小孩也学习。

<a id="L150"></a>**L150**　主席

<a id="L151"></a>**L151**　：他们是学习缅甸文吗？

<a id="L152"></a>**L152**　柯

<a id="L153"></a>**L153**　：是学习缅甸文。

<a id="L154"></a>**L154**　主席

<a id="L155"></a>**L155**　：学习缅甸文才好。（对罗线）你们也要学习你们少数民族的文字。你们有自己的书吗？

<a id="L156"></a>**L156**　罗

<a id="L157"></a>**L157**　：有。

<a id="L158"></a>**L158**　主席

<a id="L159"></a>**L159**　：你们懂不懂缅甸文？

<a id="L160"></a>**L160**　罗

<a id="L161"></a>**L161**　：大部分都可以讲缅语。

<a id="L162"></a>**L162**　主席

<a id="L163"></a>**L163**　：这个条件好。

<a id="L164"></a>**L164**　他们单独有学校吗？

<a id="L165"></a>**L165**　周恩来

<a id="L166"></a>**L166**　（以下简称周）：现在开始单独搞了。

<a id="L167"></a>**L167**　主席

<a id="L168"></a>**L168**　：不是跟我们的孩子们在一起读书？

<a id="L179"></a>**L179**　主席

<a id="L180"></a>**L180**　：这个厂子在贵州什么地方？

<a id="L181"></a>**L181**　罗

<a id="L182"></a>**L182**　：黄平。

<a id="L188"></a>**L188**　：那是1934年底，1935年春，那时正是我们很困难的时候，我们党内犯了错误，即王明路线。

<a id="L189"></a>**L189**　听说你们党内拥护刘少奇的盛一本集团的几个人都跑掉了？

<a id="L190"></a>**L190**　康生

<a id="L196"></a>**L196**　柯

<a id="L197"></a>**L197**　：在国内有两个，在中国还有一个，即王江。

<a id="L198"></a>**L198**　主席

<a id="L199"></a>**L199**　：这个名字我熟悉。这个人我见过没有？

<a id="L200"></a>**L200**　柯

<a id="L201"></a>**L201**　：见过。

<a id="L202"></a>**L202**　主席

<a id="L203"></a>**L203**　：他写信给奈温想投降。只要不投降，人数少并不要紧。（问罗线）你过来的时候是多少人？

<a id="L204"></a>**L204**　罗

<a id="L205"></a>**L205**　：大概将近400人。

<a id="L206"></a>**L206**　主席

<a id="L207"></a>**L207**　：现在还有多少人？

<a id="L208"></a>**L208**　罗

<a id="L216"></a>**L216**　主席

<a id="L217"></a>**L217**　：他们爱和平，不爱战争。

<a id="L218"></a>**L218**　康

<a id="L220"></a>**L220**　柯

<a id="L234"></a>**L234**　柯

<a id="L235"></a>**L235**　：是的。

<a id="L236"></a>**L236**　主席

<a id="L238"></a>**L238**　柯

<a id="L240"></a>**L240**　主席

<a id="L244"></a>**L244**　主席

<a id="L246"></a>**L246**　柯

<a id="L247"></a>**L247**　：赵明同志年纪最轻，今年35岁。赵明同志、赵云同志刚到中国的时候还是小孩。

<a id="L248"></a>**L248**　主席

<a id="L249"></a>**L249**　：35岁，住了17年，到中国时是18岁。

<a id="L250"></a>**L250**　你今年四十几岁？

<a id="L251"></a>**L251**　罗

<a id="L252"></a>**L252**　：45。

<a id="L253"></a>**L253**　主席

<a id="L255"></a>**L255**　柯

<a id="L256"></a>**L256**　：我比他大，今年54。

<a id="L257"></a>**L257**　主席

<a id="L258"></a>**L258**　：你们大部分的困难还是武器和医药。武器你们主要还是向奈温要。

<a id="L259"></a>**L259**　柯

<a id="L260"></a>**L260**　：（对罗线）你要记住一条，向敌人要武器。

<a id="L261"></a>**L261**　罗

<a id="L262"></a>**L262**　：向主席保证。

<a id="L263"></a>**L263**　主席

<a id="L264"></a>**L264**　：从敌人手里夺武器，这才有保证。你们有的地方根本没有办法靠外国，如勃固山区。

<a id="L265"></a>**L265**　柯

<a id="L266"></a>**L266**　：是的，只能向敌人要。

<a id="L267"></a>**L267**　主席

<a id="L268"></a>**L268**　：我并不是说，你们向我们要武器我们不给你们。这是个辅助条件。基本的条件要靠你们自己向敌人夺取武器。

<a id="L269"></a>**L269**　有些武器也可以自己制造，像地雷、手榴弹之类。自己也可办修理厂，修理枪支。

<a id="L270"></a>**L270**　制造武器、弹药，修理枪支都不困难，这不是一个基本的问题。基本的问题是政治问题。军事不是主要的，政治是主要的。第一条，这个仗要不要打？一个要打，一个不要打。你们现在有那么一些人跑到奈温那里去，他们就是不要打的嘛。过去有这样的人，今后还会有这样的人。

<a id="L271"></a>**L271**　第二条，就是群众的问题。依靠群众，还是脱离群众？依靠群众总不会失败的，可以持久。

<a id="L272"></a>**L272**　在根据地办学校，要学会政治、学会军事、学会打仗，学会其他的工作。

<a id="L273"></a>**L273**　他们（指赵明、赵云）来的时候虽然小，那时也有些经验嘛。

<a id="L274"></a>**L274**　柯

<a id="L275"></a>**L275**　：是有一点经验。

<a id="L276"></a>**L276**　主席

<a id="L277"></a>**L277**　：（问罗线）这边是你的部队？

<a id="L278"></a>**L278**　罗

<a id="L279"></a>**L279**　：是的，他们（指赵明等）是快到中国边境时才参加部队的，参加部队3个月以后就到中国境内来了。

<a id="L280"></a>**L280**　主席

<a id="L282"></a>**L282**　罗

<a id="L283"></a>**L283**　：有，现在已经送他们回家了。

<a id="L284"></a>**L284**　主席

<a id="L286"></a>**L286**　景颇族在中国有多少？

<a id="L287"></a>**L287**　周

<a id="L288"></a>**L288**　：8万多。

<a id="L289"></a>**L289**　主席

<a id="L290"></a>**L290**　：都靠近你们边界，可以作为你们的后方嘛。

<a id="L291"></a>**L291**　缅族跟别的民族有什么联系没有？比如同泰族、同马来亚民族、同印度的民族有没有联系？你们是一个独立的民族？

<a id="L292"></a>**L292**　柯

<a id="L293"></a>**L293**　：关于缅甸民族的起源还有争论。一种认为缅甸民族是从西藏过去的，另一种认为是从甘肃过去的。缅族处在两大国之间，一个是印度，一个是中国。两国的文化对缅甸都有影响，但是缅族能独立生存下来。缅族跟马来族没有什么关系，跟泰国的泰族经常打仗。

<a id="L294"></a>**L294**　主席

<a id="L295"></a>**L295**　：跟印度的民族有没有什么关系？

<a id="L296"></a>**L296**　柯

<a id="L297"></a>**L297**　：也没有。

<a id="L298"></a>**L298**　康

<a id="L299"></a>**L299**　：缅语语法跟日语语法一样。

<a id="L300"></a>**L300**　周

<a id="L301"></a>**L301**　：缅文是不是接近藏文？

<a id="L302"></a>**L302**　柯

<a id="L303"></a>**L303**　：跟藏文没有什么关系。

<a id="L304"></a>**L304**　主席

<a id="L305"></a>**L305**　：中国民族是从哪里来的，我也搞不清楚。

<a id="L306"></a>**L306**　周

<a id="L307"></a>**L307**　：现在也说法不一，有的认为，北方人是从西北来的，南方广东、福建是从南洋来的。

<a id="L308"></a>**L308**　主席

<a id="L309"></a>**L309**　：从两条路来的。

<a id="L310"></a>**L310**　印度恐怕是从西方来的，看样子就像西方人。那加族的武装呢？

<a id="L311"></a>**L311**　徐其孝

<a id="L312"></a>**L312**　（以下简称徐）：已经出去了。

<a id="L313"></a>**L313**　主席

<a id="L314"></a>**L314**　：现在到哪里了？

<a id="L315"></a>**L315**　徐

<a id="L316"></a>**L316**　：已经到了江心坡。

<a id="L317"></a>**L317**　周

<a id="L332"></a>**L332**　：很好。

<a id="L333"></a>**L333**　康

<a id="L334"></a>**L334**　：柯生同志他们急着要回去。

<a id="L335"></a>**L335**　主席

<a id="L336"></a>**L336**　：赶快走！赶快走！

<a id="L337"></a>**L337**　康

<a id="L339"></a>**L339**　主席

<a id="L340"></a>**L340**　：不会留你们了。我们官僚主义，害得你们等了一个礼拜。

<a id="L341"></a>**L341**　柯

<a id="L342"></a>**L342**　：等一个礼拜不要紧。

<a id="L343"></a>**L343**　周

<a id="L344"></a>**L344**　：最近敌情没有变化。

<a id="L350"></a>**L350**　罗

<a id="L351"></a>**L351**　：刚才主席说可以动员中国境内的景颇族参加我们的部队，我非常高兴。我也有这个要求，同志们也有这个要求。

<a id="L352"></a>**L352**　主席

<a id="L353"></a>**L353**　：你去找，找多少就带多少，找年轻的。

<a id="L354"></a>**L354**　罗

<a id="L388"></a>**L388**　主席
