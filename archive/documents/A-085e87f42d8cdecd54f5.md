<a id="L7"></a>**L7**　(1968年11月28日)

<a id="L8"></a>**L8**　时　间

<a id="L9"></a>**L9**　：1968年11月28日21时10分至23时

<a id="L10"></a>**L10**　地　点

<a id="L11"></a>**L11**　：人民大会堂一一八室

<a id="L12"></a>**L12**　参加人

<a id="L13"></a>**L13**　：周恩来、陈伯达、康生、姚文元

<a id="L14"></a>**L14**　翻　译

<a id="L15"></a>**L15**　：冀朝铸

<a id="L16"></a>**L16**　记　录

<a id="L17"></a>**L17**　：吕辉祥

<a id="L18"></a>**L18**　毛主席

<a id="L19"></a>**L19**　（以下简称主席）：你去年也是这个时候来的吗？

<a id="L20"></a>**L20**　希尔

<a id="L21"></a>**L21**　（以下简称希）：是的，去年也是这个时候来的。

<a id="L22"></a>**L22**　主席

<a id="L23"></a>**L23**　：那个时候北京工人还不很团结，有坏人在里头挑拨，一个工厂分两派。

<a id="L24"></a>**L24**　希

<a id="L25"></a>**L25**　：现在形势有了很大的发展。

<a id="L26"></a>**L26**　主席

<a id="L27"></a>**L27**　：对。把坏人弄出来就好办了。

<a id="L28"></a>**L28**　希

<a id="L29"></a>**L29**　：是的。

<a id="L30"></a>**L30**　主席

<a id="L31"></a>**L31**　：这些工厂我们从来没有清理过，学校是资产阶级知识分子统治的，农村也有相当一部分是坏人统治的，看来搞修正主义并不那么困难。

<a id="L32"></a>**L32**　譬如我们一个公社里面，一个大队有的几百户，有的几千户，就说两千户吧，1万人口，组成一个支部，这个支部书记如果不好，大队的工作就不好办。

<a id="L33"></a>**L33**　你在北京看了两个工厂吗？

<a id="L34"></a>**L34**　希

<a id="L35"></a>**L35**　：是的。

<a id="L36"></a>**L36**　主席

<a id="L37"></a>**L37**　：那个工厂的党委书记不是坏人吗？

<a id="L38"></a>**L38**　希

<a id="L39"></a>**L39**　：我不记得他们是怎样讲的，领导人是经过更换的。

<a id="L40"></a>**L40**　主席

<a id="L41"></a>**L41**　：（向姚文元）新华印剧厂你去过吗？

<a id="L42"></a>**L42**　姚文元

<a id="L43"></a>**L43**　（以下简称姚）：去过。厂长、党委书记都不好。

<a id="L44"></a>**L44**　主席

<a id="L45"></a>**L45**　：这个厂有3000工人，连家属有1万人，清朝时期印钞票，北洋军阀时期替北洋军阀服务，日本接管时替日本服务，国民党接管时又替国民党服务，我们接管了十几年又替我们服务。其中有许多人是没有动的，主要人员是没有动的，都还是清朝末年，北洋军阀时的一些人。

<a id="L46"></a>**L46**　周恩来

<a id="L47"></a>**L47**　（以下简称周）：现在我们另外增加了一部分工人，我们扩大了一部分。

<a id="L48"></a>**L48**　主席

<a id="L49"></a>**L49**　：我主要指那些负责人员过去基本上没有动。这就是中国搞修正主义的社会基础。这些问题不发动群众，不彻底发动工人就搞不清楚，而且这还不够，要派解放军去帮助，才能解决问题。

<a id="L50"></a>**L50**　希

<a id="L51"></a>**L51**　：是的。

<a id="L52"></a>**L52**　主席

<a id="L53"></a>**L53**　：我想问你一个问题。你有没有这种感觉：帝国主义究竟怎么办？就是说，它要不要打世界大战？或者暂时不打，过一会打？你接触你们国家及欧洲国家，有这种感觉没有？

<a id="L54"></a>**L54**　希

<a id="L55"></a>**L55**　：我看它们现在还没有下定决心，它们现在面临极大的困难，看来它们一时不会打，至少它们现在还没有这么一个力量发动这场世界规模的战争。大多数人是有这种看法的。但从另一方面来讲，由于它们已失去判断的能力，有发生很大冲突的危险性。但是总的来看，它们暂时还发动不了这场大战。

<a id="L56"></a>**L56**　主席

<a id="L57"></a>**L57**　：要打仗，美国、苏联这两个大国可以打，其次是日本、西德、意大利这些战败国。至于英国和法国，它们不大想打。

<a id="L58"></a>**L58**　周

<a id="L59"></a>**L59**　：戴高乐的军事预算还减了一点。

<a id="L60"></a>**L60**　主席

<a id="L61"></a>**L61**　：就是日本和西德，现在也看不出它们想打仗。西德想吞并东德，统一德国，日本想收回冲绳。其实日本还没有独立。

<a id="L62"></a>**L62**　周

<a id="L63"></a>**L63**　：美国在军事上控制它们，有那么多军事基地。

<a id="L64"></a>**L64**　主席

<a id="L65"></a>**L65**　：第二次大战以后的情况好像比第一次大战以后的情况有些不同。不晓得这些看法对不对。第二次大战后，战败国脱离不了战胜国，不但在财政方面和投资方面，而且在国际和军事方面也脱离不了战胜国。这和第一次大战后的情况不同。第一次大战后，希特勒搞几年后就起来了。

<a id="L66"></a>**L66**　周

<a id="L67"></a>**L67**　：他不承认凡尔赛条约。

<a id="L68"></a>**L68**　主席

<a id="L69"></a>**L69**　：他不承认凡尔赛条约。当时这些国家的工人、知识分子、学生还听政府的话。德国那么大的一个共产党一下就垮了。

<a id="L70"></a>**L70**　周

<a id="L71"></a>**L71**　：意大利的共产党垮得更早。

<a id="L72"></a>**L72**　主席

<a id="L73"></a>**L73**　：社会民主党也完了。它们成立了国社党，冲锋团。

<a id="L74"></a>**L74**　这个美国，按照过去两次世界大战的规律，它都是要别的国家先打，打个两年后它才动手，它才参战。

<a id="L75"></a>**L75**　美国在朝鲜、越南都首当其冲。在欧洲还有20万兵，主要是在德国。在越南有50万，在朝鲜有两个师，7万多。在日本、台湾、菲律宾、泰国也有。它的兵力已经很分散了。它的两只手都伸了出来，一个是在欧洲，一个是在亚洲，打些小仗。当然资本家还是有它的打算的。

<a id="L76"></a>**L76**　周

<a id="L77"></a>**L77**　：可以赚钱。

<a id="L78"></a>**L78**　主席

<a id="L79"></a>**L79**　：长期不打仗，资本家就不高兴，包括澳大利亚资本家在内，也希望出点兵，但兵却不很多。

<a id="L80"></a>**L80**　康生

<a id="L81"></a>**L81**　（以下简称康）：只有4个营，22架飞机。

<a id="L82"></a>**L82**　周

<a id="L83"></a>**L83**　：它出点兵，美国给它点钱。

<a id="L84"></a>**L84**　主席

<a id="L85"></a>**L85**　：它还可以赚点钱。

<a id="L86"></a>**L86**　希

<a id="L87"></a>**L87**　：现在澳大利亚资本家赚钱赚得不够，还很不满意。

<a id="L88"></a>**L88**　主席

<a id="L89"></a>**L89**　：不满意就跟美国吵，多给它点钱。

<a id="L90"></a>**L90**　那个霍尔特怎么游泳就淹死了？

<a id="L91"></a>**L91**　希

<a id="L92"></a>**L92**　：那个地方海滨比较险恶，过去有好多人也在那里淹死了。他是去冒险的。

<a id="L93"></a>**L93**　主席

<a id="L94"></a>**L94**　：那还不错哇。

<a id="L95"></a>**L95**　希

<a id="L96"></a>**L96**　：这是处理他们的一个好办法。（众笑）

<a id="L97"></a>**L97**　主席

<a id="L98"></a>**L98**　：现在这个总理叫什么名字？

<a id="L99"></a>**L99**　希

<a id="L100"></a>**L100**　：叫戈顿。

<a id="L101"></a>**L101**　主席

<a id="L102"></a>**L102**　：这个名字好听，戈顿。

<a id="L103"></a>**L103**　希

<a id="L104"></a>**L104**　：只不过好听而已。

<a id="L105"></a>**L105**　主席

<a id="L106"></a>**L106**　：你这个名字也好听，希尔。

<a id="L107"></a>**L107**　希

<a id="L108"></a>**L108**　：主席还是第一个说我的名字好听。

<a id="L109"></a>**L109**　主席

<a id="L110"></a>**L110**　：就是好听嘛。是不是叫Hill（小山）？

<a id="L111"></a>**L111**　希

<a id="L112"></a>**L112**　：是小山。

<a id="L113"></a>**L113**　主席

<a id="L114"></a>**L114**　：索性改一个Mountain（大山）好了。我看了你写的文章。我没有你那么勤快，我懒得很，没有修改过我的什么东西。有些东西应该修改，比如第二次出版，应有所修改，第三次出版，又应有所修改。

<a id="L115"></a>**L115**　有些文章没有必要太长。还是林彪同志发明了一种方法编语录。

<a id="L116"></a>**L116**　康

<a id="L117"></a>**L117**　：主席的希腊文语录，是他们（指希尔他们）翻译的。

<a id="L118"></a>**L118**　主席

<a id="L119"></a>**L119**　：哦，是他们翻译的。

<a id="L120"></a>**L120**　孔夫子的《论语》是语录。佛教的语录。

<a id="L121"></a>**L121**　周

<a id="L122"></a>**L122**　：金刚经。

<a id="L123"></a>**L123**　主席

<a id="L124"></a>**L124**　：我这个人懒得很，没有读过圣经，读不进去。

<a id="L125"></a>**L125**　不晓得是些什么道理，拿起来不想读。

<a id="L126"></a>**L126**　希

<a id="L127"></a>**L127**　：我完全理解，我常常也有同样的感觉，读不进去。可是我小时候也被强迫读过一些圣经。

<a id="L128"></a>**L128**　主席

<a id="L129"></a>**L129**　：那好哇，强迫读的东西还有一点好处。

<a id="L130"></a>**L130**　有人说我这个人历来没有犯过错误，其实我小时候学孔夫子的封建主义，后来到了学校就学资本主义，觉得什么华盛顿、拿破仑了不起，把英国的克伦威尔、什么惠灵顿元帅、纳尔逊元帅吹得神乎其神。

<a id="L131"></a>**L131**　赫鲁晓夫那个时候经常吹战争不是不可避免的，但是他们现在不吹。说战争不是不可避免的，其实就是说可以避免的。现在这几年他们不谈这个问题了。是不是就不谈了？

<a id="L132"></a>**L132**　康

<a id="L133"></a>**L133**　：根本不谈这个问题了。他们向捷克出兵嘛。在波兰的第五次代表大会上，也不讲这个问题了。

<a id="L134"></a>**L134**　主席

<a id="L135"></a>**L135**　：这样看，它们正在准备扩大战争，不论美国、苏联还是其他的国家。

<a id="L136"></a>**L136**　从这些情况来看，似乎是要打仗了。我对这个问题没有把握，所以想请教你。也不强加于你很快回答这个问题。你是不是可以观察这个问题？在一年之内，我们再谈的时候再谈这个问题。但是，人民的觉悟也要估计到。

<a id="L137"></a>**L137**　美国停止轰炸北越，美国在越南的军队很高兴，还欢呼，这说明它们的士气不那么很高。美国兵的士气就那么高？苏联兵的士气就那么高？法国、英国、德国、日本兵的士气就那么高？

<a id="L138"></a>**L138**　资本主义国家闹学潮这件事，在欧洲历史上是个新事件。因为资本主义国家的学生照例是不闹事的。现在主要在欧洲、在美国、在拉丁美洲、在日本有学潮。

<a id="L139"></a>**L139**　在你们那里有没有？

<a id="L140"></a>**L140**　希

<a id="L141"></a>**L141**　：有。

<a id="L142"></a>**L142**　主席

<a id="L143"></a>**L143**　：我们的国家，对世界各国人民的革命运动说来，对工人运动说来，对学生运动说来，对真正的马克思主义政党的发展壮大说来，再有5年的时间，就会比较好了。日本1945年投降到现在已经23年了，再有5年，就是28年，28年不打仗吗？其实，在二次大战后，各种战争从未停止过。

<a id="L144"></a>**L144**　按照列宁所说的，资本主义就是战争。它就是离不开战争。

<a id="L145"></a>**L145**　世界上有两个大国，它们不但有常规武器，而且有原子弹。这个东西不大好碰，它们自己也知道。赫鲁晓夫的理论是原子弹打起来就会毁灭地球，没有战胜者。美国也这么说。这两个大国是核国家。我们这个国家，还可以说是无核国家，这么少一点核武器不算数。要打只能是用常规武器。因为我们既不是美国的参谋长，也不是苏联的参谋长，搞不清楚它们究竟要干什么，只能从一些表现来看问题。这两个国家的人口相等，真正要打大仗它们还会感到人力不足。现在打个中等规模的仗，比如今天在越南打的仗，美国都感到人力困难，特别是飞行员。

<a id="L146"></a>**L146**　（向陈伯达和康生）你们跟他谈了些什么？

<a id="L147"></a>**L147**　康

<a id="L148"></a>**L148**　：我们谈了一下十二中全会，谈了我们准备开九大，也谈了一下世界的马克思主义的党同小组，比如苏联的斯大林小组，捷克、波兰的一些新的马列主义的小组，也谈了一下主席同意大利同志谈的议会选举的问题。希尔同志特别有兴趣的是主席关于大树特树和绝对权威的看法，他说对他很有启发。因为去年他同主席谈话时也涉及到这个问题。

<a id="L149"></a>**L149**　主席

<a id="L150"></a>**L150**　：所谓大树特树，主要是我们的原代理总参谋长杨成武搞大树特树，实际上大树特树他自己，搞多中心论。至于所谓绝对权威，我就不认为地球上有这个东西。马克思、恩格斯、列宁他们很少讲到绝对权威，他们只讲有绝对真理。所谓绝对真理并不是别的，就是各个时代相对真理的总和，就叫绝对真理。这是他们讲过的，诸哲学家都讲过的嘛。我说是从来没有看见过房子，也没有吃过水果。看到的只是人民大会堂，你住的北京饭店这样的东西。除了这些以外，另外有所谓房子是看不见的。也没有吃过水果，也许你们吃过，我没有吃过。也没有吃过桃，也没有吃过梨，也没有吃过苹果，那个省的苹果，这个国家的苹果，那个国家的苹果，都是苹果嘛。水果是一种抽象的概念。当然不讲抽象概念也不行。所以，按照习惯，也可以说是吃水果，是住在房子里面。列宁说，个别是普遍的一方在或一部分。譬如希尔同志你这个名字可普遍了，到处都有希尔。

<a id="L151"></a>**L151**　你们这些姓是怎么来的？

<a id="L152"></a>**L152**　希

<a id="L153"></a>**L153**　：英国人的习惯，往往是你住在什么地方，就叫这个地方的名字。比如希尔吧，可能这些人在山里住。又比如米尔，是作坊的意思，跟作坊有关的人就叫米尔。

<a id="L154"></a>**L154**　主席

<a id="L155"></a>**L155**　：你们那个地方有姓水的吗？

<a id="L156"></a>**L156**　希

<a id="L157"></a>**L157**　：有。

<a id="L158"></a>**L158**　主席

<a id="L159"></a>**L159**　：中国有姓水的，也有姓山的。有姓金的，没有姓银的，外国有姓银的。中国还有姓田的。

<a id="L160"></a>**L160**　周

<a id="L161"></a>**L161**　：还有姓锡的。

<a id="L162"></a>**L162**　希

<a id="L163"></a>**L163**　：这点跟英国的习惯有点相似。

<a id="L164"></a>**L164**　主席

<a id="L165"></a>**L165**　：你们那里有姓石的吗？

<a id="L166"></a>**L166**　希

<a id="L167"></a>**L167**　：有。

<a id="L168"></a>**L168**　主席

<a id="L169"></a>**L169**　：中外都差不多。有许多姓是古代封建国家。比如我姓毛，是两千多年以前一个朝代的一个小国，就是周恩来同志那个姓，是周朝。（众笑）你（指姚文元）姓姚，是舜皇帝后代嘛，一个皇帝的后代。（众笑）实际上有没有那个皇帝很成问题。

<a id="L170"></a>**L170**　姚

<a id="L171"></a>**L171**　：是神话。

<a id="L172"></a>**L172**　主席

<a id="L173"></a>**L173**　：什么尧皇帝、舜皇帝、大禹都没有证据。大概那时候有些氏族部落。

<a id="L174"></a>**L174**　周
