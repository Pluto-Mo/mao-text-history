<a id="L5"></a>**L5**　毛泽东主席接见伊朗左派革命组织代表的谈话记录

<a id="L6"></a>**L6**　（1970年10月1日）

<a id="L7"></a>**L7**　时　间：1970年10月1日晚10时15分

<a id="L8"></a>**L8**　地　点：天安门城楼

<a id="L9"></a>**L9**　参加人：

<a id="L10"></a>**L10**　伊方—雷兹瓦尼、哈桑、穆哈森

<a id="L11"></a>**L11**　中方—林彪、周恩来、康生

<a id="L12"></a>**L12**　翻　译：伍书湖

<a id="L13"></a>**L13**　（10月1日晚焰火结束后，周恩来总理把代表团引见给毛主席。

<a id="L14"></a>**L14**　周总理

<a id="L15"></a>**L15**　对毛主席说：“他们是伊朗同志。”毛主席迎上几步同他们亲切地握手。）

<a id="L16"></a>**L16**　毛主席

<a id="L17"></a>**L17**　（以下简称主席）：伊朗就是波斯，欢迎。

<a id="L18"></a>**L18**　雷兹瓦尼

<a id="L19"></a>**L19**　（以下简称雷）：（用中文高呼）毛主席万岁！

<a id="L20"></a>**L20**　主席

<a id="L21"></a>**L21**　：（同他们一一握手）谢谢同志们。

<a id="L22"></a>**L22**　雷

<a id="L23"></a>**L23**　：见到毛主席是对我们最大的鼓舞。

<a id="L24"></a>**L24**　主席

<a id="L25"></a>**L25**　：（问康生）他们来多久了？

<a id="L26"></a>**L26**　雷

<a id="L27"></a>**L27**　：一个多月了。

<a id="L28"></a>**L28**　主席

<a id="L29"></a>**L29**　：你们愿意呆多久就呆多久。

<a id="L30"></a>**L30**　（

<a id="L31"></a>**L31**　雷

<a id="L32"></a>**L32**　用中文高呼“毛主席万岁！”）

<a id="L33"></a>**L33**　主席

<a id="L34"></a>**L34**　：同志们万岁！同志们好，欢迎你们。

<a id="L35"></a>**L35**　雷

<a id="L36"></a>**L36**　：能见到您，对我们是最大的鼓舞，我们一定努力做您的好学生。

<a id="L37"></a>**L37**　主席

<a id="L38"></a>**L38**　：我们都是同志，我们向你们学习。

<a id="L39"></a>**L39**　雷

<a id="L40"></a>**L40**　：毛主席万岁！

<a id="L41"></a>**L41**　主席

<a id="L42"></a>**L42**　：谢谢。你们很年轻，未来是属于你们的。我老了，不行了。

<a id="L43"></a>**L43**　（

<a id="L44"></a>**L44**　雷

<a id="L45"></a>**L45**　等人笑着摇头，用中文高呼“毛主席万岁！”）

<a id="L46"></a>**L46**　主席

<a id="L47"></a>**L47**　：祝你们革命胜利！

<a id="L48"></a>**L48**　（

<a id="L49"></a>**L49**　雷

<a id="L50"></a>**L50**　用中文高呼“毛主席万岁！”毛主席再次同代表团二同志一一握手告别，并向前走了几步微笑着挥手欢送他们。然后，周恩来总理把他们带到林彪面前，林从座位上站起来同他们握手。）

<a id="L51"></a>**L51**　林

<a id="L52"></a>**L52**　：欢迎你们！

<a id="L53"></a>**L53**　雷

<a id="L54"></a>**L54**　：我们看到毛主席和您，是对我们最大的鼓舞，我们一定要按照毛主席的指示办事。

<a id="L55"></a>**L55**　林

<a id="L56"></a>**L56**　：你们会逐渐取得革命胜利的。

<a id="L57"></a>**L57**　（雷等同林握手告别，又同周总理握手告别，周总理用英文向他们说“再见”。）

<a id="L58"></a>**L58**　感谢 佐仓绫奈 收集、录入及校对
