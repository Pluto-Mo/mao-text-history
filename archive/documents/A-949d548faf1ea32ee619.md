<a id="L9"></a>**L9**　（一九六七年七月二十五日）

<a id="L10"></a>**L10**　林、周、中央文革小组：

<a id="L11"></a>**L11**　拟复电如下，请讨论酌定。

<a id="L12"></a>**L12**　毛泽东

<a id="L13"></a>**L13**　一、你们现在所采取的立场和政策是正确的，公告可以发表。

<a id="L14"></a>**L14**　二、对于犯了严重错误的干部，包括你们和广大革命群众所要打倒的陈再道同志在内，只要他们不再坚持错误，认真改正，并得到群众谅解了以后，仍然可以站起来参加革命行列。

<a id="L15"></a>**L15**　三、要向思想不通的某些人员和百万雄师群众做工作，使他们转变过来。

<a id="L16"></a>**L16**　四、要向左派做工作，不要乘机报复。

<a id="L17"></a>**L17**　五、要警惕坏人捣乱，不许破坏社会秩序。
