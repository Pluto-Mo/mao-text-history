<a id="L8"></a>**L8**　【凯山·丰威汉（Kaysone

<a id="L9"></a>**L9**　Phomvihane，1920－1992），老挝人民民主共和国、老挝人民革命党和老挝人民军的主要创立者和领导人。曾担任老挝人民革命党中央委员会总书记（1955－1991）、主席（1991－1992），老挝政府总理（1975－1991）、老挝人民民主共和国主席（1991－1992）。】

<a id="L11"></a>**L11**　：1967年11月30日18时45分至20时

<a id="L12"></a>**L12**　地　点

<a id="L13"></a>**L13**　：人民大会堂

<a id="L14"></a>**L14**　参加人

<a id="L15"></a>**L15**　：

<a id="L16"></a>**L16**　老方

<a id="L17"></a>**L17**　：凯山、沙南、梅索

<a id="L18"></a>**L18**　中方

<a id="L19"></a>**L19**　：林彪、周恩来、康生、刘宁一

<a id="L20"></a>**L20**　翻　译

<a id="L21"></a>**L21**　：黄群

<a id="L22"></a>**L22**　速　记

<a id="L23"></a>**L23**　：吕辉祥

<a id="L24"></a>**L24**　毛主席

<a id="L25"></a>**L25**　（以下简称主席）：你身体好吗？

<a id="L26"></a>**L26**　凯山

<a id="L27"></a>**L27**　（以下简称凯）：一般还好。

<a id="L28"></a>**L28**　主席

<a id="L29"></a>**L29**　：你们现在住在桑怒什么地方？

<a id="L30"></a>**L30**　凯

<a id="L31"></a>**L31**　：我们现在住在山洞里。

<a id="L32"></a>**L32**　主席

<a id="L33"></a>**L33**　：可以开洞子。

<a id="L34"></a>**L34**　凯

<a id="L35"></a>**L35**　：都是天然的石洞，经过改造以后人就住在里面。以前住在外面，现在因为美国飞机轰炸，所以我们都搬到洞里去了。

<a id="L36"></a>**L36**　主席

<a id="L37"></a>**L37**　：美国飞机晚上来吗？

<a id="L38"></a>**L38**　凯

<a id="L39"></a>**L39**　：有时晚上也来。

<a id="L40"></a>**L40**　主席

<a id="L41"></a>**L41**　：桑怒到河内有多少公里？

<a id="L42"></a>**L42**　凯

<a id="L43"></a>**L43**　：300多公里。

<a id="L44"></a>**L44**　主席

<a id="L45"></a>**L45**　：现在富马这方面还有些什么人？

<a id="L46"></a>**L46**　凯

<a id="L47"></a>**L47**　：现在富马名义上是中立派，实际上同右派已经合流了。所以，富马跟右派培·萨纳尼空、库帕拉西、拉迪功，全都合流了。

<a id="L48"></a>**L48**　主席

<a id="L49"></a>**L49**　：诺萨万呢？

<a id="L50"></a>**L50**　凯

<a id="L51"></a>**L51**　：跑到泰国去了。

<a id="L52"></a>**L52**　主席

<a id="L53"></a>**L53**　：贡勒呢？

<a id="L54"></a>**L54**　凯

<a id="L55"></a>**L55**　：现在贡勒已经没有军队了。他们把他排挤出去以后，原来的中立部队跟右派部队合编了。但是，他们内部还是有矛盾的。尤其是贡勒原来的一些下级军官，对于跟右派军队合编这一点不太满意。因为他们原来还有点中立的倾向。

<a id="L56"></a>**L56**　自从1965年我们上次在上海见毛主席以来，美帝国主义强化了在老挝的特种战争，表现在加强了空军的轰炸。它有两个战略目的：

<a id="L57"></a>**L57**　第一，轰炸、破坏我们的解放区，同时进一步蚕食解放区；

<a id="L58"></a>**L58**　第二，摧毁我们的游击根据地，“绥靖”敌后地区。

<a id="L59"></a>**L59**　这两年来它们有些新的做法。

<a id="L60"></a>**L60**　在军事方面，几种军事力量互相配合。在派空军轰炸破坏的同时，又派军队向我们进攻，还派别动队到我们后方骚扰。同时，进行政治攻势和军事攻势，加强它们的心理战。尤其是在它们的占领区，利用新殖民主义的各种手段加强其对占领区的统治。

<a id="L61"></a>**L61**　现在右派的军队大概总共有7万人，美国军事顾问大概有5000人。

<a id="L62"></a>**L62**　主席

<a id="L63"></a>**L63**　：哦，这么多！

<a id="L64"></a>**L64**　凯

<a id="L65"></a>**L65**　：要是包括其他的外籍人员，如法国人、菲律宾人，大概就有12000人。

<a id="L66"></a>**L66**　他们是直接帮助傀儡政府的。美国人跟法国人有许多矛盾。

<a id="L67"></a>**L67**　主席

<a id="L68"></a>**L68**　：法国人打不打你们？

<a id="L69"></a>**L69**　凯

<a id="L70"></a>**L70**　：法国人主要是帮助他们训练部队，在后方搞教育，不在前方。

<a id="L71"></a>**L71**　刚才说的美国人，主要是指直接控制右派军队的顾问，从外地派来轰炸的那部分空军还不算在内。

<a id="L72"></a>**L72**　主席

<a id="L73"></a>**L73**　：美国飞机从什么地方起飞？

<a id="L74"></a>**L74**　凯

<a id="L75"></a>**L75**　：一般从泰国乌隆起飞。B-52也是从泰国起飞的。

<a id="L76"></a>**L76**　主席

<a id="L77"></a>**L77**　：轰炸你们桑怒没有？

<a id="L78"></a>**L78**　凯

<a id="L79"></a>**L79**　：B-52不到桑怒，主要是在中、下寮那一段轰炸。

<a id="L80"></a>**L80**　美国飞机集中在两个地区轰炸：一个是川圹，一个是桑怒。B-52主要是破坏一些庄稼、房屋，我们的军队一般不受什么损失。轰炸以来，老百姓只死了三十几个人。

<a id="L81"></a>**L81**　主席

<a id="L82"></a>**L82**　：破坏得不是那么很厉害。

<a id="L83"></a>**L83**　凯

<a id="L84"></a>**L84**　：原来听说B-52轰炸，都以为很厉害，结果并不是这样。B-52在轰炸以前，一般先派飞机侦察，在它侦察的地方，我们就事先离开，避免受损失。

<a id="L85"></a>**L85**　我们做了一些总结。这两年来，美帝国主义在政治方面、军事方面都是失败的。在政治方面，它更加孤立了；在军事方面，我们消灭了它的有生力量大约有25000人，打下飞机700多架。我们用步枪打下的飞机已经有15架了。

<a id="L86"></a>**L86**　主席

<a id="L87"></a>**L87**　：B-52从多高的空中轰炸？

<a id="L88"></a>**L88**　凯

<a id="L89"></a>**L89**　：6000米以上。

<a id="L90"></a>**L90**　总的来说，这两年来革命力量有了更大的巩固和很多良好的进步，其中包括一些新的因素。在军事方面，有些仗比过去打得好了，一些歼灭战也打得好了。

<a id="L91"></a>**L91**　在解放区，虽然我们遇到了很多困难，但是比过去还是有了进一步的巩固，群众的觉悟有了进一步的提高。我们在各个地方发动群众，搞群众运动，使基层政权进一步巩固了。

<a id="L92"></a>**L92**　主席

<a id="L93"></a>**L93**　：很好。

<a id="L94"></a>**L94**　凯

<a id="L95"></a>**L95**　：现在我们发展了解放区的经济。在解放区的经济建设方面，我们现在以农业为基础，恢复了一些小手工业生产。虽然有一些地方遇到了自然灾害，但是没有灾害的地方生产状况比较好。

<a id="L96"></a>**L96**　主席

<a id="L97"></a>**L97**　：你们少数民族的工作做得如何？

<a id="L98"></a>**L98**　凯

<a id="L99"></a>**L99**　：比1965年有进步。我们现在在苗族地区的工作做得比较好，土匪有些地方也被我们消灭了。在桑怒，少数民族工作也有进步。

<a id="L100"></a>**L100**　这两年来，我们在苗族地区瓦解土匪6000人，有些反动武装整个连都被我们争取过来了。我们放他们回家，有些人回家以后再也不干了。

<a id="L101"></a>**L101**　主席

<a id="L102"></a>**L102**　：是苗族吗？

<a id="L103"></a>**L103**　凯

<a id="L104"></a>**L104**　：大部分是苗族。

<a id="L105"></a>**L105**　主席

<a id="L106"></a>**L106**　：你们国内的少数民族主要是什么族？

<a id="L107"></a>**L107**　凯

<a id="L108"></a>**L108**　：从全国来说，一个是苗族，一个是老听族。

<a id="L109"></a>**L109**　周恩来（以下简称周）：老听族属于泰族系吗？

<a id="L110"></a>**L110**　凯

<a id="L111"></a>**L111**　：属于马来系。现在泰国的老挝族有1200万。

<a id="L112"></a>**L112**　主席

<a id="L113"></a>**L113**　：比你们国家还多。

<a id="L114"></a>**L114**　凯

<a id="L115"></a>**L115**　：我们还发展文化教育事业，开办了中小学，培养一些师资。

<a id="L116"></a>**L116**　总的来说，这两年来我们在各个方面都取得了胜利。这个胜利我们是比较来看的。

<a id="L117"></a>**L117**　在老挝的历史上，从来没有过这么紧张激烈的战斗。对我们来说，这是一个很严重的考验，经过这个考验，我们取得的这些胜利是比较稳步的、全面的。

<a id="L118"></a>**L118**　同时，我们老挝革命也产生了一些新的因素。从党的领导方面来说，通过这个斗争，我们党逐步地壮大了，在领导斗争方面比过去有了进步。

<a id="L119"></a>**L119**　当然，也有一些弱点，比如说，在敌后地区，现在我们的工作还很薄弱。

<a id="L120"></a>**L120**　主席

<a id="L121"></a>**L121**　：你是讲敌后的乡村，还是敌后的城市？

<a id="L122"></a>**L122**　凯

<a id="L123"></a>**L123**　：城市和乡村都在内。

<a id="L124"></a>**L124**　现在因为有了一块解放区，干部都愿意在解放区工作，不愿意到敌后去。遇到一些思想上的障碍和困难。

<a id="L125"></a>**L125**　我们曾经两次袭击琅勃拉邦机场，因为有了群众的支持和配合，所以打得比较好。

<a id="L126"></a>**L126**　我们还有一个弱点。群众是很好的，但是现在我们还没有很好地把他们发动起来。我们过去搞群众运动，主要是在桑怒搞了一些试点，后来在各个省都搞了一些试点。最近我们在全国普遍地搞起来了。

<a id="L127"></a>**L127**　主席

<a id="L128"></a>**L128**　：要争取群众。

<a id="L129"></a>**L129**　凯

<a id="L130"></a>**L130**　：我们在经济上也遇到了一些困难，由于战争的破坏，经济上的困难大一点。

<a id="L131"></a>**L131**　主席

<a id="L132"></a>**L132**　：跟敌人打仗，搞军队，党和人民群众几方面，你们已经取得经验了。

<a id="L133"></a>**L133**　你们打仗、搞解放区，搞了多少年了？

<a id="L134"></a>**L134**　凯

<a id="L135"></a>**L135**　：从开始打仗到现在已经22年了。

<a id="L136"></a>**L136**　主席

<a id="L137"></a>**L137**　：打了这么久了！

<a id="L138"></a>**L138**　凯

<a id="L139"></a>**L139**　：其中也有间断，但是间断的时间不长，最长的也不到两年。在日内瓦协议签订以后停了一年。停了不久，美帝国主义就向桑怒发动进攻。

<a id="L140"></a>**L140**　主席

<a id="L141"></a>**L141**　：什么时候？

<a id="L142"></a>**L142**　凯

<a id="L143"></a>**L143**　：1955年。

<a id="L144"></a>**L144**　周

<a id="L145"></a>**L145**　：萨纳尼空政府的时候。

<a id="L146"></a>**L146**　凯

<a id="L147"></a>**L147**　：后来又搞了一个万象协议，停了一阵。搞了联合政府不到两年时间（即从1957年11月到1959年5月），又重新打起仗来了。

<a id="L148"></a>**L148**　从1959年5月打到1962年，又产生了第二个日内瓦协议。协议签订后，停了8个月，又重新打了起来，一直打到现在。

<a id="L149"></a>**L149**　主席

<a id="L150"></a>**L150**　：协议没有用嘛。

<a id="L151"></a>**L151**　凯

<a id="L152"></a>**L152**　：现在打仗的规模比过去越来越大了。过去打仗时敌人调动的兵力不多，现在每次打仗都要调动大批的军队。因为他们没有士气，所以只好用人去壮胆。现在士气低落到这种程度，要派飞机，要有大炮配合，不然，他们就不敢出来打仗。

<a id="L153"></a>**L153**　主席

<a id="L154"></a>**L154**　：你们没有飞机，还不是照样打？我们跟你们一样，过去二十几年也没有飞机。有飞机的打败仗，没有飞机的打胜仗。第一次世界大战还没有什么飞机，第二次世界大战才有。

<a id="L155"></a>**L155**　凯

<a id="L156"></a>**L156**　：从局势的发展来看，根据我们的分析，目前第一个可能性就是美帝国主义继续强化在老挝的特种战争，配合它在南越的战场。它强化特种战争的主要特点是加强空军的轰炸。泰国也会出一些兵帮助它进攻我们的解放区。美国也可能用直升飞机把其军队派到中、下寮，以便占领一些重要地区，并加以巩固以后，美国兵就可能撤走。

<a id="L157"></a>**L157**　第二个可能性，美国出兵中、下寮，直接在中、下寮打。要是它出兵北越的话，可能会同时进攻我们的北寮。

<a id="L158"></a>**L158**　我们现在分析，第二个可能性不是很明显。因为目前美国碰到的困难比较大。

<a id="L159"></a>**L159**　在这方面，我们要随时准备好，随时提高警惕。我们已经作好了精神上的准备。

<a id="L160"></a>**L160**　主席

<a id="L161"></a>**L161**　：准备好了，不来也没有关系。

<a id="L162"></a>**L162**　凯

<a id="L163"></a>**L163**　：也要考虑到第一个可能性。就是美国人在南越被打败了，在老挝也会被打败。我们取得了胜利，局势就可能缓和一些。

<a id="L164"></a>**L164**　我们现在要做最坏的准备。

<a id="L165"></a>**L165**　主席

<a id="L166"></a>**L166**　：现在泰国境内发展游击战争很重要。

<a id="L167"></a>**L167**　凯

<a id="L168"></a>**L168**　：我们的基本方针还是没有变化，要继续保住解放区，巩固和建设我们的解放区，把解放区建设成为一个具有国家规模的地区，作为解放全国的根据地。同时，在解放区建立新制度，使全国人心向往我们的解放区。在有条件时，就扩大我们的解放区。

<a id="L169"></a>**L169**　主席

<a id="L170"></a>**L170**　：扩大到泰国去。

<a id="L171"></a>**L171**　凯

<a id="L172"></a>**L172**　：第二个方针，我们要十分重视敌后地区的工作，要加强敌后地区的工作。

<a id="L173"></a>**L173**　主席

<a id="L174"></a>**L174**　：主要的敌后地区在泰国，不在你们本国。你们把泰国赤化了，这个地方它就走不掉了。

<a id="L175"></a>**L175**　他们怕你们到泰国去，那里农村力量薄弱。

<a id="L176"></a>**L176**　周

<a id="L177"></a>**L177**　：泰国现在已经出兵到南越了。

<a id="L178"></a>**L178**　主席

<a id="L179"></a>**L179**　：出兵也好，不出兵也好，他们跟泰国没有外交关系，美国的飞机从泰国来轰炸嘛。

<a id="L180"></a>**L180**　凯

<a id="L181"></a>**L181**　：我们现在人员太少。

<a id="L182"></a>**L182**　主席

<a id="L183"></a>**L183**　：加上1200万就多了嘛。

<a id="L184"></a>**L184**　凯

<a id="L185"></a>**L185**　：我们现在要加强敌后工作，正如毛主席刚才问我们的一样，我们要加强城市和农村的工作。

<a id="L186"></a>**L186**　我们的方针是政治工作、军事工作同时进行。同时，使各个地区加以转化，从游击区转化为游击根据地，从游击根据地转化为解放区。

<a id="L187"></a>**L187**　主席

<a id="L188"></a>**L188**　：整个泰国有多少人口？

<a id="L189"></a>**L189**　凯

<a id="L190"></a>**L190**　：大概有3000万人。

<a id="L191"></a>**L191**　主席

<a id="L192"></a>**L192**　：面积呢？

<a id="L193"></a>**L193**　周

<a id="L194"></a>**L194**　：比缅甸稍为大一点。

<a id="L195"></a>**L195**　主席

<a id="L196"></a>**L196**　：现在富马也不要求开会了。

<a id="L197"></a>**L197**　凯

<a id="L198"></a>**L198**　：培·萨纳尼空跟库帕拉西都是右派。

<a id="L199"></a>**L199**　主席

<a id="L200"></a>**L200**　：比富米·诺萨万还右。

<a id="L201"></a>**L201**　凯

<a id="L202"></a>**L202**　：对。

<a id="L203"></a>**L203**　主席

<a id="L204"></a>**L204**　：除诺萨万以外，还有什么人？

<a id="L205"></a>**L205**　凯

<a id="L206"></a>**L206**　：还有库帕拉西、培·萨纳尼空和温·萨那尼空。温·萨那尼空经常写文章，观点是极端反动的。

<a id="L207"></a>**L207**　富马有时要求和我们见面，我们说，现在没有条件。如果要见面，我们的代表就住在万象。我们在那里还有一批人。原来我们有一个连在那个地方，后来撤回来一些，实际上只剩下一个排。我们在那个地方给群众的印象还是很好的。我们在代表机构那里放电影，老百姓来看的很多，尤其是中国帮我们拍的一部片子，放映时来看的人很多。

<a id="L208"></a>**L208**　主席

<a id="L209"></a>**L209**　：哦！

<a id="L210"></a>**L210**　凯

<a id="L211"></a>**L211**　：警察想把老百姓轰走，老百姓不走。最后没有办法，他们自己也去看。

<a id="L212"></a>**L212**　后来，他们就以内务部的名义，下令不让我们放电影，同时还往里面扔手榴弹。

<a id="L213"></a>**L213**　我们放电影政治影响很好。

<a id="L214"></a>**L214**　主席

<a id="L215"></a>**L215**　：现在不让你们放了，怎么办呢？

<a id="L216"></a>**L216**　凯

<a id="L217"></a>**L217**　：就跟他们斗争嘛。在我们驻地范围内还是有权放的。

<a id="L218"></a>**L218**　主席

<a id="L219"></a>**L219**　：他们还允许你们在万象，他们要搞掉你们是很容易的。

<a id="L220"></a>**L220**　凯

<a id="L221"></a>**L221**　：我们在万象的机构自己动手搞生产，给群众的印象比较好。

<a id="L222"></a>**L222**　主席

<a id="L223"></a>**L223**　：这个好。

<a id="L224"></a>**L224**　凯

<a id="L225"></a>**L225**　：我们的战士上街买东西，出去一个人警察都很注意。

<a id="L226"></a>**L226**　主席

<a id="L227"></a>**L227**　：有点像重庆谈判的味道。

<a id="L228"></a>**L228**　凯

<a id="L229"></a>**L229**　：过去周恩来同志在重庆也是这样。

<a id="L230"></a>**L230**　现在，连敌占区的老百姓也看得很清楚了，只有我们能救老百姓。过去他们对富马还有一点幻想，现在幻想越来越小了。连中间阶层也有这样的倾向。国王也有某种程度的民族主义情绪。

<a id="L231"></a>**L231**　主席

<a id="L232"></a>**L232**　：要做国王的工作。

<a id="L233"></a>**L233**　凯

<a id="L234"></a>**L234**　：国王有些时候也不同意富马那些做法。我们也给他写信。

<a id="L235"></a>**L235**　主席

<a id="L236"></a>**L236**　：多做些工作嘛。他管一个琅勃拉邦吗？

<a id="L237"></a>**L237**　凯

<a id="L238"></a>**L238**　：实际上他没有什么权力，让他呆在琅勃拉邦，养着他就是了。

<a id="L239"></a>**L239**　我们认为，虽然老挝还碰到很多困难，但是总的情况还是很好的。

<a id="L240"></a>**L240**　主席

<a id="L241"></a>**L241**　：还有越南同志在你们那里工作吗？

<a id="L242"></a>**L242**　凯

<a id="L243"></a>**L243**　：还有专家。

<a id="L244"></a>**L244**　主席

<a id="L245"></a>**L245**　：只有专家？

<a id="L246"></a>**L246**　凯

<a id="L247"></a>**L247**　：还有一些志愿军。

<a id="L248"></a>**L248**　美国对九号公路很痛心，对它没有办法。麦克纳马拉要在那里搞什么防线，从南越一直到沙湾拿吉，作为它们的封锁钱。

<a id="L249"></a>**L249**　主席

<a id="L250"></a>**L250**　：嚷了好多年，又不动手。

<a id="L251"></a>**L251**　麦克纳马拉不赞成再打，因为每年要消耗多少万，有打死的，有打伤的，还有病了的。实际上能打仗的只有十几万人。

<a id="L252"></a>**L252**　周

<a id="L253"></a>**L253**　：在西原地区打了20多天，损失很大。

<a id="L254"></a>**L254**　凯

<a id="L255"></a>**L255**　：现在在下寮的战略要地，一个是九号公路，一个是波罗芬高原。现在美国、日本都很重视这个地区。

<a id="L256"></a>**L256**　主席

<a id="L257"></a>**L257**　：日本有多少人？

<a id="L258"></a>**L258**　凯

<a id="L259"></a>**L259**　：老挝过去大约有150个日本人，这次佐藤访问万象，跟富马进行了密谈，签订了一个协议，准备再增加500人。

<a id="L260"></a>**L260**　周

<a id="L261"></a>**L261**　：是些什么人？

<a id="L262"></a>**L262**　凯

<a id="L263"></a>**L263**　：是一些农业技术人员。他们说那块地方很肥沃，要开发那个地方。说是农业技术人员，很可能会派一些军事人员去。

<a id="L264"></a>**L264**　我们有两个比较重要的战略区，一个是川圹，一个是波罗芬高原。

<a id="L265"></a>**L265**　主席

<a id="L266"></a>**L266**　：好。听了你的介绍，我很高兴。你们现在是回国去，还是在中国呆一个时候？

<a id="L267"></a>**L267**　凯

<a id="L268"></a>**L268**　：今天见了主席以后，明天到上海，然后到广州去一下，就回国。

<a id="L271"></a>**L271**　凯
