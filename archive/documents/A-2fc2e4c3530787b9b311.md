<a id="L3"></a>**L3**　-&gt;

<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东主席会见印度驻华大使尼赫鲁谈话记录

<a id="L6"></a>**L6**　（未经毛主席审阅）

<a id="L7"></a>**L7**　（1955年12月8日）

<a id="L8"></a>**L8**　【拉·库·尼赫鲁大使（Ratan Kumar Nehru），是1955年11月6日至1958年1月23日的印度驻华大使，他是印度总理贾瓦哈拉尔·尼赫鲁的亲戚。】

<a id="L9"></a>**L9**　时　间

<a id="L10"></a>**L10**　：1955年12月8日下午5时30分

<a id="L11"></a>**L11**　地　点

<a id="L12"></a>**L12**　：中南海勤政殿

<a id="L13"></a>**L13**　参加人

<a id="L14"></a>**L14**　：

<a id="L15"></a>**L15**　印方

<a id="L16"></a>**L16**　—拉·库·尼赫鲁及夫人

<a id="L17"></a>**L17**　中方

<a id="L18"></a>**L18**　—章汉夫、陈家康、柯华

<a id="L19"></a>**L19**　毛主席

<a id="L20"></a>**L20**　：：我很高兴看到印度人口的增多，印度的工业、农业、国防、文化等各方面在发展和加强。

<a id="L21"></a>**L21**　拉·库·尼赫鲁大使

<a id="L22"></a>**L22**　（以下简称尼赫鲁）：我也很高兴看到中国在阁下的英明领导下日益繁荣和发展。

<a id="L23"></a>**L23**　毛主席

<a id="L24"></a>**L24**　：：我们刚开始搞，工业、交通要比印度差，印度的科学和文化水平也比我们高。

<a id="L25"></a>**L25**　尼赫鲁夫人

<a id="L26"></a>**L26**　：中国人民的精神是伟大的。这种精神能克服一切的困难。

<a id="L27"></a>**L27**　毛主席

<a id="L28"></a>**L28**　：：是的，我们有很多事情要做，而且也愿意去做。中国是一个大国，但不是一个富和强国。飞机、汽车、坦克，什么都不能造，只是人口很多。

<a id="L29"></a>**L29**　尼赫鲁

<a id="L30"></a>**L30**　：富强是基于人民的精神，如人民有富强的愿望，国家就可以强盛起来。目前印度和中国都落后于其他的强国。

<a id="L31"></a>**L31**　毛主席

<a id="L32"></a>**L32**　：：亚非各国中，除日本外，都还很落后。

<a id="L33"></a>**L33**　尼赫鲁

<a id="L34"></a>**L34**　：我们大家都不向往日本的地位。

<a id="L35"></a>**L35**　尼赫鲁夫人

<a id="L36"></a>**L36**　：日本能造飞机、汽车，并且有强大的海军，但这些都没有使日本成为强国。

<a id="L37"></a>**L37**　毛主席

<a id="L38"></a>**L38**　：：日本不懂得如何利用她的富强。最近我同一些日本人谈话时说过：日本被打败是一件好事，因为它丧失了海军和殖民地，这样就有权利来批评美国和英国。用中国的古话来说，这是因祸得福。

<a id="L39"></a>**L39**　尼赫鲁夫人

<a id="L40"></a>**L40**　：极大的痛苦能锻炼一个人，印度有一句谚语：金子要经过火烧后才能变成纯金。

<a id="L41"></a>**L41**　毛主席

<a id="L42"></a>**L42**　：：中国的谚语是：真金不怕火烧。

<a id="L43"></a>**L43**　尼赫鲁

<a id="L44"></a>**L44**　：我们虽然到中国只有1个月零3天，但却到了很多地方，如西安、成都、重庆。

<a id="L45"></a>**L45**　毛主席

<a id="L46"></a>**L46**　：：你们到过的地方比我还多，我没有去过西安和成都，只是蒋介石强迫我到过一次重庆。三峡也没有去过。我们被蒋介石在山上关了十几年，近六年来也没有功夫到西北去。如果从成都到西安的铁路修好了，可以去一次。

<a id="L47"></a>**L47**　尼赫鲁

<a id="L48"></a>**L48**　：听说这条铁路几个月后就可以修好了，这条铁路对四川省是很重要的。四川很富饶，农业很发达。

<a id="L49"></a>**L49**　毛主席

<a id="L50"></a>**L50**　：：四川省有6000万人口，是我们的后方。

<a id="L51"></a>**L51**　尼赫鲁夫人

<a id="L52"></a>**L52**　：四川好像是中国的神经中枢，正像我们的故乡联合省是印度的神经中枢，那一省有6500万人口。

<a id="L53"></a>**L53**　尼赫鲁

<a id="L54"></a>**L54**　：四川是中国第一个同印度有往来的省份。在汉朝时，中国有一位皇帝派了一位将军到西域去，结果在那里发现有从四川经印度运过去的丝绸。

<a id="L55"></a>**L55**　毛主席

<a id="L56"></a>**L56**　：：是的。

<a id="L57"></a>**L57**　尼赫鲁夫人

<a id="L58"></a>**L58**　：实际上印度同中国在古代的联系比史书上的记载还要早。最近我们听说古代在福建沿海地区曾有印度移民住过。

<a id="L59"></a>**L59**　尼赫鲁

<a id="L60"></a>**L60**　：我们已经耽误了阁下很多的时间……

<a id="L61"></a>**L61**　毛主席

<a id="L62"></a>**L62**　：：就想走了？再谈一会吧。我们同印度人好谈话，因为谈话时不要防备，讲错了话不要紧，你们不会抓住这些错误来整我们，同样我们也不会整你们。我曾同尼赫鲁总理谈过这些话。

<a id="L63"></a>**L63**　尼赫鲁

<a id="L64"></a>**L64**　：我们在中国感到如同在自己的家一样。

<a id="L65"></a>**L65**　毛主席

<a id="L66"></a>**L66**　：：这是由于我们有很多共同之点，不仅我们的地位是相同的，而且我们大家都不做损人利已的事。

<a id="L67"></a>**L67**　尼赫鲁

<a id="L68"></a>**L68**　：我们2000多年来一直就是这样的。

<a id="L69"></a>**L69**　尼赫鲁夫人

<a id="L70"></a>**L70**　：这2000多年是我们之间永恒的友谊的历史，我们希望阁下能去印度访问，使这种友谊更加巩固。

<a id="L71"></a>**L71**　毛主席

<a id="L72"></a>**L72**　：：有机会的话，我很愿意去印度。

<a id="L73"></a>**L73**　尼赫鲁

<a id="L74"></a>**L74**　：中印两国人民间有难以形容的友谊，而我们对欧洲人就没有这种感情。

<a id="L75"></a>**L75**　毛主席

<a id="L76"></a>**L76**　：：那是很自然的，首先，欧洲人看不起我们，这样事情就难办了。

<a id="L77"></a>**L77**　尼赫鲁

<a id="L78"></a>**L78**　：我们对欧洲人的殖民主义倒是很有经验的，例如我们有果阿问题。

<a id="L79"></a>**L79**　毛主席

<a id="L80"></a>**L80**　：：我们也有澳门的问题。

<a id="L81"></a>**L81**　尼赫鲁

<a id="L82"></a>**L82**　：美国人支持葡萄牙占领果阿，但是没有支持葡萄牙占领澳门，这是对印度的一种特殊“照顾”。

<a id="L83"></a>**L83**　毛主席

<a id="L84"></a>**L84**　：：不，昨天杜勒斯在记者招待会也表示支持葡萄牙在澳门的地位。

<a id="L85"></a>**L85**　尼赫鲁夫人

<a id="L86"></a>**L86**　：那末可以说我们都被“照顾”到了。这样使我们的关系更为密切。

<a id="L87"></a>**L87**　毛主席

<a id="L88"></a>**L88**　：：美国、英国、法国、比利时、葡萄牙、荷兰这些殖民国家大力加强他们的防御，但是他们没有理由。他们是债务国，而我们是债权国，我们的政治资本大。只有钢铁，没有政治资本的国家是要垮台的，历史上已有很多证明，如希特勒、墨索里尼、日本都垮台了。苏联革命刚成功时，也只有400多万吨钢。印度现在年产多少吨钢？

<a id="L89"></a>**L89**　尼赫鲁

<a id="L90"></a>**L90**　：目前是240万吨，跟中国的产量差不多。当第二个五年计划完成时可达到600万吨，并且要集中力量发展重工业，增加发电量，75%的投资是拨给重工业的。

<a id="L91"></a>**L91**　毛主席

<a id="L92"></a>**L92**　：：印度是个大国，有广大的国内市场。印度尼西亚也是个大国，有国内市场，印度和印尼都可以建立自己的工业。但是还要解决农业的问题。美国在经济上也是主要依靠国内的市场。美国一开始就实行资本主义的农业制度，建立大农场，所以国内市场大。

<a id="L93"></a>**L93**　尼赫鲁

<a id="L94"></a>**L94**　：美国有大量的处女地，而且开始时有来自欧洲的投资。美国不像中国和印度那样有人口多而土地少的问题。

<a id="L95"></a>**L95**　毛主席

<a id="L96"></a>**L96**　：：印度土地少吗？

<a id="L97"></a>**L97**　尼赫鲁

<a id="L98"></a>**L98**　：是的，跟中国情况差不多。

<a id="L99"></a>**L99**　毛主席

<a id="L100"></a>**L100**　：：小农经济经不起天灾，给国家生产的粮食和工业原料很少。组织起来就可以用机器耕作，可以迅速发展农业。

<a id="L101"></a>**L101**　尼赫鲁

<a id="L102"></a>**L102**　：在稻田里不能使用机器，在麦田里可以。

<a id="L103"></a>**L103**　毛主席

<a id="L104"></a>**L104**　：：我们现在还不靠机器，而是靠组织起来。估计七、八年后可以增产一倍。

<a id="L105"></a>**L105**　尼赫鲁

<a id="L106"></a>**L106**　：这是合作化必然的结果，印度有同样的经验。在印度，每人的土地量很少，而且很分散。50年前，我们就开始了合作化运动，我在20多年前曾负责过合作化运动。第一步是建立信贷合作社，取消高利贷；第二步是农民互相交换土地，集中土地，减少土地分散的现象；第三步是建立生产合作社。到目前为止合作化的进展不如中国大。

<a id="L107"></a>**L107**　尼赫鲁夫人

<a id="L108"></a>**L108**　：印度农民中入合作社的不到农业人口的一半，妇女们也不像中国妇女那样的积极入社。所以我来中国前主要是在农村工作，教育农村妇女加入合作社。

<a id="L109"></a>**L109**　尼赫鲁

<a id="L110"></a>**L110**　：印度还有一种合作社，七、八十个村子组成一单位，组织合作社……

<a id="L111"></a>**L111**　毛主席

<a id="L112"></a>**L112**　：：是用机器耕作吗？

<a id="L113"></a>**L113**　尼赫鲁

<a id="L114"></a>**L114**　：使用一些机器，但在稻田里不能用。毛主席：我们应该研究出一种小机器，适合稻田用的。尼赫鲁：日本有一种耕作办法很好，实行后，产量增加一倍。

<a id="L115"></a>**L115**　毛主席

<a id="L116"></a>**L116**　：：什么办法？

<a id="L117"></a>**L117**　尼赫鲁

<a id="L118"></a>**L118**　：插秧实行密植法。

<a id="L119"></a>**L119**　毛主席

<a id="L120"></a>**L120**　：：听说日本有一种梅花形的种植方法，七、八棵秧插在一起，形成一团。这办法很好，值得研究。我们插秧的办法是一棵棵地插。

<a id="L121"></a>**L121**　尼赫鲁

<a id="L122"></a>**L122**　：印度很仔细地研究了日本的种值方法，并加以推广。

<a id="L123"></a>**L123**　毛主席

<a id="L124"></a>**L124**　：：大使刚才所说的，对我是一种启发。有了好的办法，大家应该互相帮助，互相研究。

<a id="L125"></a>**L125**　尼赫鲁

<a id="L126"></a>**L126**　：我们两国可以互派农业专家，互相学习。据我看到中国四川地区的粮食产量比印度的产量高。

<a id="L127"></a>**L127**　毛主席

<a id="L128"></a>**L128**　：：很好。中国四川、浙江的产量高，广东汕头附近，一亩地可产500公斤粮食。

<a id="L129"></a>**L129**　尼赫鲁

<a id="L130"></a>**L130**　：目前在印度有二种国营农场：第一种是小农场，主要任务是指导农民如何耕作；第二种就是布尔加宁和赫鲁晓夫参观过的大农场，用机器进行耕作。
