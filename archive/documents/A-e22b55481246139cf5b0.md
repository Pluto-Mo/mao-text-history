<a id="L17"></a>**L17**　毛主席

<a id="L20"></a>**L20**　：我们这次又重新见面了，很高兴！

<a id="L21"></a>**L21**　毛主席

<a id="L22"></a>**L22**　：很欢迎！

<a id="L23"></a>**L23**　金日成

<a id="L26"></a>**L26**　毛主席

<a id="L27"></a>**L27**　：我的腿不好，讲话不好，眼睛也有白内障，腿也不好。你好吗？

<a id="L28"></a>**L28**　金日成

<a id="L29"></a>**L29**　：很好。我跟主席两年没见了！

<a id="L30"></a>**L30**　毛主席

<a id="L31"></a>**L31**　：很欢迎，welcome（欢迎）！我发音不好，讲外国语。

<a id="L32"></a>**L32**　金日成

<a id="L33"></a>**L33**　：这次来再次见到你，非常高兴。

<a id="L34"></a>**L34**　毛主席

<a id="L35"></a>**L35**　：你们的事办得还好吗？

<a id="L36"></a>**L36**　金日成

<a id="L37"></a>**L37**　：还不错。我们现在是三个工作：第一，社会主义建设；第二，支持南朝鲜民主化的斗争；第三，和第三世界团结。这是我们的三个中心工作，还算不坏。

<a id="L38"></a>**L38**　毛主席

<a id="L39"></a>**L39**　：我们也是：社会主义、台湾、第三世界。

<a id="L40"></a>**L40**　金日成

<a id="L41"></a>**L41**　：我们的路线是一样的，我们跟主席同志学习。

<a id="L42"></a>**L42**　毛主席

<a id="L43"></a>**L43**　：我还要向你们学习。南朝鲜、台湾麻烦。

<a id="L44"></a>**L44**　金日成

<a id="L45"></a>**L45**　：是个麻烦事情。

<a id="L46"></a>**L46**　毛主席

<a id="L47"></a>**L47**　：美国人霸住不走啊！

<a id="L48"></a>**L48**　金日成

<a id="L49"></a>**L49**　：我们看到你们周总理在大会上的报告，讲到革命斗争的形势。我看帝国主义经济危机，能来个大乱，美国鬼子就从南朝鲜、台湾滚出去了。

<a id="L50"></a>**L50**　毛主席

<a id="L51"></a>**L51**　：它不想走啊！

<a id="L52"></a>**L52**　现在柬埔寨、越南好。

<a id="L53"></a>**L53**　金日成

<a id="L54"></a>**L54**　：是啊，他们取得了很大的胜利。他们的胜利就和我们的胜利一样，我们感到很高兴！

<a id="L55"></a>**L55**　毛主席

<a id="L56"></a>**L56**　：西哈努克亲王去接你了没有？

<a id="L57"></a>**L57**　金日成

<a id="L58"></a>**L58**　：车站接了。

<a id="L59"></a>**L59**　毛主席

<a id="L60"></a>**L60**　：那好。

<a id="L61"></a>**L61**　金日成

<a id="L62"></a>**L62**　：将来我还要找个时间拜访他一下子。

<a id="L63"></a>**L63**　主席听还是好，啊？

<a id="L64"></a>**L64**　毛主席

<a id="L65"></a>**L65**　：听，好。（指耳朵）这个好，（指眼睛）这个不好，（指嘴角）这个不好，（指腿）这个不好。

<a id="L66"></a>**L66**　你今年还要去Europe（欧洲）、Africa（非洲）？

<a id="L67"></a>**L67**　金日成

<a id="L68"></a>**L68**　：回去以后，5月初到罗马尼亚、阿尔及利亚。现在有消息说还有毛里塔尼亚。其它一些还没有回答，这三个国家确定了时间。因为他们来了朝鲜，要我去答复他们。

<a id="L69"></a>**L69**　毛主席

<a id="L70"></a>**L70**　：我们也是欠债啊！

<a id="L71"></a>**L71**　金日成

<a id="L72"></a>**L72**　：所以，他们已经催了多次，我打算就去一次，看一看！特别重要的是去阿尔及利亚，他们的主席到过朝鲜。每次我们的代表团去，他都要我去，说是在平壤没有谈完，要到他那里去谈，谈第三世界团结的问题。他是第三世界不结盟国家的主席，要我们去谈。

<a id="L73"></a>**L73**　毛主席

<a id="L74"></a>**L74**　：布迈丁这个人相当有头脑。

<a id="L75"></a>**L75**　金日成

<a id="L76"></a>**L76**　：这个人很坚决，我看他很坚决。他们准备明年召开不结盟国家会议，在斯里兰卡开会，他的意思是要我们去参加会议。还没有谈完，我们去谈谈看。参加会议，我们觉得有意思，争取他们支持我们的斗争，去一次看一看。

<a id="L77"></a>**L77**　主要是这几个国家。有时间就去看看保加利亚，应该去访问，但是还没有回答。

<a id="L78"></a>**L78**　毛主席

<a id="L79"></a>**L79**　：不到阿尔巴尼亚呀？

<a id="L80"></a>**L80**　金日成

<a id="L81"></a>**L81**　：还没有决定。阿尔巴尼亚同我们关系正常了，好了。

<a id="L82"></a>**L82**　毛主席

<a id="L83"></a>**L83**　：那好。他们不喜欢越南，也不喜欢我们。我们请了尼克松，他们不高兴。

<a id="L84"></a>**L84**　金日成

<a id="L85"></a>**L85**　：阿尔巴尼亚吗？

<a id="L86"></a>**L86**　毛主席

<a id="L87"></a>**L87**　：嗯。

<a id="L88"></a>**L88**　金日成

<a id="L89"></a>**L89**　：是不是越南也不高兴？

<a id="L90"></a>**L90**　毛主席

<a id="L91"></a>**L91**　：越南也不高兴。

<a id="L92"></a>**L92**　金日成

<a id="L93"></a>**L93**　：我相信他们是没有理解你的革命外交路线。

<a id="L94"></a>**L94**　毛主席

<a id="L95"></a>**L95**　：我们请了尼克松，请了基辛格。基辛格是个很坏的人，尼克松比较好。

<a id="L96"></a>**L96**　金日成

<a id="L97"></a>**L97**　：基辛格可能狡猾一点。你们请尼克松，我们发表了社论，绝对支持，后来，我又做了演说，是主席的革命路线嘛。

<a id="L98"></a>**L98**　毛主席

<a id="L99"></a>**L99**　：主要是通过尼克松接触美国人民。

<a id="L100"></a>**L100**　金日成

<a id="L101"></a>**L101**　：好嘛，他们封锁中国好几十年，这是很大的胜利。我们很理解。为什么他们不高兴，我们也不知道。

<a id="L102"></a>**L102**　毛主席

<a id="L103"></a>**L103**　：他们不高兴，现在好一些了。

<a id="L104"></a>**L104**　金日成

<a id="L105"></a>**L105**　：我那个时候说，这是中国一个很大的胜利。中国不是去找他们，是一个很大的胜利。

<a id="L106"></a>**L106**　毛主席

<a id="L107"></a>**L107**　：我说是尼克松自己要来的。

<a id="L108"></a>**L108**　金日成

<a id="L109"></a>**L109**　：这是一个很大的胜利，你们的胜利就是我们共同的胜利，应该庆祝嘛。不知道他们为什么不理解。我跟总理谈过这个。

<a id="L110"></a>**L110**　毛主席

<a id="L111"></a>**L111**　：我们premier（总理）有病，一年里开过三次刀。一个是膀胱，开过两次。然后是大肠外面长了一个东西，又开了刀。

<a id="L112"></a>**L112**　金日成

<a id="L113"></a>**L113**　：邓小平副主席讲过这个事。

<a id="L114"></a>**L114**　邓小平

<a id="L115"></a>**L115**　：专门请他们的玄峻极大使回去报告了这件事。

<a id="L116"></a>**L116**　毛主席

<a id="L117"></a>**L117**　：董必武同志去世了。总理生病，我也生病，康生同志也害病，刘伯承同志也害病。你们好一些。崔庸健同志的腿好一些吗？

<a id="L118"></a>**L118**　金日成

<a id="L119"></a>**L119**　：他的腿不好，现在好一些。他也不能说话，听不懂他的话。第一是不能走；第二是不能讲话，听不懂，我也听不懂；第三，心脏也不好。所以，他现在不参加工作，在家看书。

<a id="L120"></a>**L120**　我们金一同志，他本来很健康，我本来打算不到外国去，由他代替去看看，答复一下。去年他也生了病了，腿也不好，走不了，是因为脑子里生了一个良性的瘤子，有鸡蛋那么大。我们没有发现，我们发现不了，也治不了。

<a id="L121"></a>**L121**　罗马尼亚齐奥塞斯库主席来电报告诉我，他们有好的医生能治。请总理派了飞机送他到罗马尼亚开刀。脑子做手术的时候，他昏过去三回。现在好了，但是腿也不好。他已经回国，能够工作了，但不能走，他不能指挥腿和胳膊。

<a id="L122"></a>**L122**　就是这两位，其余都好，年轻一些。崔庸健岁数大一点，比总理小1岁，76岁。他的身体别的地方都没有毛病。他在家里，不能参加政治局会议，因为他不能讲话，讲了别人都听不懂，大会上就不好发言了。一般的他的意见都能发表，讲话听不懂就写意见书交换意见。

<a id="L123"></a>**L123**　毛主席

<a id="L124"></a>**L124**　：我这回去了湖北、湖南、江西、浙江几个地方，差不多住了一年。因为你要来，我又回来见面。

<a id="L125"></a>**L125**　金日成

<a id="L126"></a>**L126**　：谢谢。

<a id="L127"></a>**L127**　毛主席

<a id="L128"></a>**L128**　：早几天才回来，回来才几天。我今年82了，快不行了，靠你们了。

<a id="L129"></a>**L129**　金日成

<a id="L130"></a>**L130**　：谢谢。祝你保持健康，保持好的身体！

<a id="L131"></a>**L131**　毛主席

<a id="L132"></a>**L132**　：我能想，能吃饭，能睡觉，这三个好。

<a id="L133"></a>**L133**　金日成

<a id="L134"></a>**L134**　：这也是很重要的，因为你的存在对中国人民、朝鲜人民、亚洲人民、世界人民、第三世界人民有很大的鼓舞，所以你长寿对你们是很宝贵的事。

<a id="L135"></a>**L135**　毛主席

<a id="L136"></a>**L136**　：不行了。

<a id="L137"></a>**L137**　金日成

<a id="L138"></a>**L138**　：为什么不行？

<a id="L139"></a>**L139**　毛主席

<a id="L140"></a>**L140**　：上帝请我喝烧酒。（笑）

<a id="L141"></a>**L141**　金日成

<a id="L142"></a>**L142**　：还早！

<a id="L143"></a>**L143**　毛主席

<a id="L144"></a>**L144**　：还早啊？你叫我不去啊？（笑）

<a id="L145"></a>**L145**　金日成

<a id="L146"></a>**L146**　：我们不希望你去。

<a id="L147"></a>**L147**　毛主席

<a id="L148"></a>**L148**　：我不能抽烟了。抽烟几十年了，现在又不能抽了。你能抽，好啊。

<a id="L149"></a>**L149**　金日成

<a id="L150"></a>**L150**　：我也不常抽，有时候抽，有时候也不抽，随便。主席记忆力好。

<a id="L151"></a>**L151**　毛主席

<a id="L152"></a>**L152**　：你们那里找到石油吗？

<a id="L153"></a>**L153**　金日成

<a id="L154"></a>**L154**　：还没有发现。总理很关心，中国也派了专家去钻探，还没有发现。

<a id="L155"></a>**L155**　毛主席

<a id="L156"></a>**L156**　：可能海里有吧？

<a id="L157"></a>**L157**　金日成

<a id="L158"></a>**L158**　：可能有，因为你们的技术和我们的技术还不行，只能到（海）边上去钻。

<a id="L159"></a>**L159**　毛主席

<a id="L160"></a>**L160**　：我不谈政治，由他（指邓小平）来跟你谈了。（笑）此人叫邓小平。

<a id="L161"></a>**L161**　金日成

<a id="L162"></a>**L162**　：我们很早就认识了，他做过很多工作，是老朋友，老同志了。

<a id="L163"></a>**L163**　毛主席

<a id="L164"></a>**L164**　：他（指邓小平）会打仗。

<a id="L165"></a>**L165**　金日成

<a id="L166"></a>**L166**　：不但会打仗，而且会做政治工作，进行思想斗争。

<a id="L167"></a>**L167**　毛主席

<a id="L168"></a>**L168**　：还会反修正主义。

<a id="L169"></a>**L169**　金日成

<a id="L170"></a>**L170**　：是啊，我们很清楚他。我和邓小平副主席十年没见了。

<a id="L171"></a>**L171**　毛主席

<a id="L172"></a>**L172**　：红卫兵整他，现在无事了。那个时候打倒了好几年，现在又起来了。

<a id="L173"></a>**L173**　金日成

<a id="L174"></a>**L174**　：很好，我们欢迎！

<a id="L175"></a>**L175**　毛主席

<a id="L176"></a>**L176**　：我们要他！

<a id="L177"></a>**L177**　金日成

<a id="L178"></a>**L178**　：我们也欢迎他！

<a id="L179"></a>**L179**　毛主席

<a id="L180"></a>**L180**　：你们去谈话，我不谈了。

<a id="L181"></a>**L181**　（张玉凤报告朝方记者要求进来摄影，以及还有三名团员前边没有赶上握手，请示怎么办。）

<a id="L182"></a>**L182**　来。（做手势）

<a id="L183"></a>**L183**　（指张玉凤）她是东北人，讲东北话，黑龙江的。

<a id="L185"></a>**L185**　观察形势，situation（形势）。（指唐闻生）此人是美国人，英文名字叫Nancy Tang。

<a id="L191"></a>**L191**　金日成

<a id="L192"></a>**L192**　：我们吃饭用筷子。

<a id="L193"></a>**L193**　（朝鲜劳动党中央委员会委员、贸易部长桂应泰，朝鲜劳动党中央委员会委员、对外经济事业部部长郑南松和朝鲜劳动党中央委员会委员、人民军空军司令吴克列进来。毛主席和他们一一握手。祝毛主席健康长寿。）
