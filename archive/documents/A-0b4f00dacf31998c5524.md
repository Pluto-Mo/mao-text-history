<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东主席会见缅共副主席德钦巴登顶谈话记录

<a id="L6"></a>**L6**　（1970年10月1日）

<a id="L7"></a>**L7**　（事后追记，未经本人审阅）

<a id="L8"></a>**L8**　时　间：1970年10月1日晚上9时20分至10时10分

<a id="L9"></a>**L9**　地　点：天安门城楼休息厅

<a id="L10"></a>**L10**　参加人：周恩来、康生

<a id="L11"></a>**L11**　翻译兼记录：黄里

<a id="L12"></a>**L12**　毛主席

<a id="L13"></a>**L13**　（以下简称主席）：有一件事要同你商量，我们考虑同缅甸奈温政府搞好国家关系，互派大使，想听听你们的意见。奈温、吴努，这两派都是反共反人民的。吴努曾经要求同我们发生关系，我们没有理他。奈温最近派来一个华侨商人，要求同我们恢复外交关系。这个华侨名叫陈……

<a id="L14"></a>**L14**　周恩来

<a id="L15"></a>**L15**　（以下简称周）：名字叫陈国和，我们官方没有正式和他接触。

<a id="L16"></a>**L16**　主席

<a id="L17"></a>**L17**　：即使我们同奈温政府恢复国家关系，也不会影响你们打仗。

<a id="L18"></a>**L18**　周

<a id="L19"></a>**L19**　：现在，我们把你安排在主席台上，奈温政府没有提出抗议，过去是要提抗议的。

<a id="L20"></a>**L20**　主席

<a id="L21"></a>**L21**　：你们再好好打一下，把缅甸东北部大片地区打下来，把腊戍打下来，有十几万，二十几万人口，那就好了，你们就有发言权了。现在，奈温为什么来找我们？就是因为你们在缅甸东北部打了他们。

<a id="L22"></a>**L22**　你们的同志过去在中国回不去，这次利用奈温反华的机会，都回去了。

<a id="L23"></a>**L23**　罗线同志的情况怎么样？他是缅甸的少数民族？

<a id="L24"></a>**L24**　德钦巴登顶

<a id="L25"></a>**L25**　（以下简称巴）：他是克钦族，同中国境内的景颇族一样。

<a id="L26"></a>**L26**　如果毛主席认为目前的时机已经适合于恢复中、缅两国关系，并且又不影响我们的革命斗争，我们也同意恢复中、缅两国关系。当然，中、缅两国关系一改善，我们党内下面的同志中间会产生一些思想混乱。但是不要紧，我们可以做工作。

<a id="L27"></a>**L27**　主席

<a id="L28"></a>**L28**　：恢复两国关系，就是恢复外交关系。奈温要求同我们搞好关系，目的是为了搞点经济利益。我们帮他们搞点经济建设，将来缅甸解放了，还不是你们的？！

<a id="L29"></a>**L29**　我们同四十多个国家建立了外交关系，基本上是靠这些国家的人民，不是靠这些国家的政府。苏联是靠这些国家的政府，不是靠这些国家的人民。这是路线问题。

<a id="L30"></a>**L30**　巴

<a id="L31"></a>**L31**　：只要对中国的对外关系有好处。我们同意恢复两国的关系。中、缅两国恢复关系后，我们内部下面的同志将会产生思想混乱。1949年（应为1950年——译者注）中、缅两国开始建交时，我们党内下面的同志里头，就产生过思想混乱。但是我们要做工作，可以解决。

<a id="L32"></a>**L32**　主席

<a id="L33"></a>**L33**　：你们的主席现在在哪里？

<a id="L34"></a>**L34**　巴

<a id="L35"></a>**L35**　：在勃固山区。

<a id="L36"></a>**L36**　主席

<a id="L37"></a>**L37**　：你们中央在勃固山区打仗，没有你们东北部这个地区打得好，主要是没有很好发动群众。你们的路线是对的，搞武装路线是对的，是正确的。

<a id="L38"></a>**L38**　我们的外交路线是依靠人民的。我们同奈温政府搞好关系，是过渡的，奈温是个过渡人物。

<a id="L39"></a>**L39**　我同印度代办说过，印度人民是伟大的人民。我请他向他们的总统、总理问候。这个代办就回去汇报了。印度政府不可靠，它既亲美，又亲苏。现在为了搞平衡，它要求同我们恢复外交关系，互派大使。恢复国家关系后，它会要求我们不支持印度的马列主义左派党，会要求我们停止援助印度的少数民族米佐和那加的武装斗争。

<a id="L40"></a>**L40**　我们对欧洲的帝国主义国家，一般不骂或少骂。要争取他们，如英国、法国、西德等。这对我们有利，他们是第二中间势力。

<a id="L41"></a>**L41**　第一中间势力是第三世界，即亚洲、非洲、拉丁美洲地区。

<a id="L42"></a>**L42**　各国垄断资本家都是怕人民的，奈温也是怕人民。

<a id="L43"></a>**L43**　你们有些仗没有打好。中国人的话不要全听，你们要按照你们自己的实际情况去搞。

<a id="L44"></a>**L44**　周

<a id="L45"></a>**L45**　：访问组同你们东北军区的意见有分歧，开了会，我们批评了访问组。

<a id="L46"></a>**L46**　主席

<a id="L47"></a>**L47**　：你们有批评中国人的权利。马列主义者是不分国界线的。中国同志错了，就是错了；你们错了，就是错了。

<a id="L48"></a>**L48**　缅甸外交部长拉汉在曼谷对新闻记者说，在缅甸东北部同缅甸政府打的不是中国人，是缅共。

<a id="L49"></a>**L49**　巴

<a id="L50"></a>**L50**　：拉汉还说，缅甸政府同中国政府的关系有了很大改善。

<a id="L51"></a>**L51**　周

<a id="L52"></a>**L52**　：他们派陈国和来，我们官方根本没有同他接触。我们是通过正常的外交途径的。他们已提出大使人选，要求我们也派大使去。

<a id="L53"></a>**L53**　主席

<a id="L54"></a>**L54**　：奈温现在有困难，主要是经济困难，大米减产了。但是，缅甸的情况还是比印度好。在延安时，一个美国记者告诉我说，缅甸有希望，印度没有希望，印度这个国家，一发生饥荒，就有二三百万人死亡。

<a id="L55"></a>**L55**　周

<a id="L56"></a>**L56**　：印度收容了我西藏叛匪达赖等一伙人，干涉我们内政，因此我们支援米佐和那加的斗争，它就没有话说。

<a id="L57"></a>**L57**　主席

<a id="L58"></a>**L58**　：你住在北京，能知道缅甸国内的情况吗？

<a id="L59"></a>**L59**　巴

<a id="L60"></a>**L60**　：看缅甸的报纸，可以知道一些情况。我们在缅甸掸邦有一个中央委员，我们同他有电台联系，他也报来一些情况。但是不幸，这位中央委员已于今年9月上旬的一次战斗中牺牲了。电台的下落还不知道。

<a id="L61"></a>**L61**　主席

<a id="L62"></a>**L62**　：你们要提高警惕，敌人会派人打进我们内部来。你们前任主席德钦丹东同志就是被敌人的特务打死的嘛！

<a id="L63"></a>**L63**　巴

<a id="L64"></a>**L64**　：如果对中国有利，并且不影响缅甸的革命斗争，我们同意中国同缅甸恢复外交关系。

<a id="L65"></a>**L65**　主席

<a id="L66"></a>**L66**　：试一试，看看究竟如何，有了进展以后，还要给你通通消息。奈温同印度不同。奈温对美国和苏联都有疑虑。他右怕吴努，左怕你们。

<a id="L67"></a>**L67**　假如奈温来中国，你要不要见他？

<a id="L68"></a>**L68**　巴

<a id="L69"></a>**L69**　：可以见。

<a id="L70"></a>**L70**　主席

<a id="L71"></a>**L71**　：打仗是打仗，外交是外交。

<a id="L72"></a>**L72**　巴

<a id="L73"></a>**L73**　：请毛主席放心，我们一定要努力打好仗。

<a id="L74"></a>**L74**　主席

<a id="L75"></a>**L75**　：要逐步消灭敌人。假如你们能打到勃固山区去，那就好了。你们在缅甸东北地区已经打了几年？

<a id="L76"></a>**L76**　巴

<a id="L77"></a>**L77**　：还不到3年，是1968年出去的，69年，70年，还不到3年。我们已经消灭敌人好几个营。我们把敌人的主力师99师打垮了，现在又调来77师。

<a id="L78"></a>**L78**　主席

<a id="L79"></a>**L79**　：要打好仗，首先要摸清情况，能吃的，就把它吃掉，吃不下来就不吃。打仗并不困难，可以概括为两句话：你打你的，我打我的；打得赢就打，打不赢就走。你打我，无非是要消灭我。我打你，打得赢就打，打不赢就走。我们要集中优势兵力，集中多数，打少数，不打对等数。比如，五打五，就不好打；五打一，就可以打，可以打赢。

<a id="L80"></a>**L80**　巴

<a id="L81"></a>**L81**　：但是，要把毛主席的这个军事思想运用到实际斗争中去，那是很困难的，是不容易的。

<a id="L82"></a>**L82**　主席

<a id="L83"></a>**L83**　：好吧！就谈到这里。

<a id="L84"></a>**L84**　（谈话进行中，西哈努克夫妇来向毛主席告辞，毛主席介绍西哈努克同巴登顶认识。）
