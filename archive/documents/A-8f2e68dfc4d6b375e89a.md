<a id="L9"></a>**L9**　（一九五八年八月九日）

<a id="L10"></a>**L10**　毛主席特别强调布置各项工作必通过群众鸣放辩论，他说：计划、指示不经过群众辩论，主意是你们的；辩论后，群众自己是主人了，干劲自然更足。

<a id="L11"></a>**L11**　领导必须多到下面去看，帮助基层干部总结经验，就地进行领导。

<a id="L12"></a>**L12**　还是办人民公社好，它的好处是，可以把工、农，商、学、兵合在一起，便于领导。

<a id="L13"></a>**L13**　你们的小米长得不好嘛，我看群众的干劲太少！

<a id="L14"></a>**L14**　好，你这个人（指历城县北园乡北园农业社主任李书成。）不干就不干，一干就大干的。

<a id="L15"></a>**L15**　你好，你（指山东省农科所付所长秦杰）学的学问能用上了。

<a id="L16"></a>**L16**　是应该压迫你们一下，不压迫，你们就不会上梁山。

<a id="L17"></a>**L17**　你们研究一下（棉花）为什么落桃，（棉花落桃）的问题，是否可以研究个办法，叫它少落或不落。

<a id="L18"></a>**L18**　你们行还是农民行？

<a id="L19"></a>**L19**　那很好，你们要继续努力，力争上游。

<a id="L20"></a>**L20**　（在接见山东著名的劳动模范，农业社的干部们时说）你们干得很好，都鼓足了干劲。
