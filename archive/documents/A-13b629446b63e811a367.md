<a id="L8"></a>**L8**　怎样看待别人

<a id="L9"></a>**L9**　（抄自毛泽东同志青少年时代）

<a id="L10"></a>**L10**　世界上的两种人，一种是部分材，一种是组织材，前者多而后者少。但每个人都有他的长处。我们就应该鼓励、发展、运用他们的长处。不管那长处是很少的，有限的，我们看人首先就应看他的长处。

<a id="L11"></a>**L11**　（注：此话是主席对同学的谈话。主席以后（领导革命时期）也说过，无论跛子、哑子聋子、瞎子对革命都有用处。对组织部工人谈话说：对一个同志首先要看他的相同处…他革命，他信仰马克思列宁主义……然后看他的不同处，有缺点、思想意识上有毛病……）
