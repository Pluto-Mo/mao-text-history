<a id="L8"></a>**L8**　对机要保密工作的指示

<a id="L9"></a>**L9**　（一九六五年十二月十四日）

<a id="L10"></a>**L10**　毛主席在一九六五年十二月十四月听取李质忠同志请示工作时，对机要保密工作作了如下指示：

<a id="L11"></a>**L11**　主席说：机要保密，警卫工作很重要，要保住党的机密，不要被修正主义利用，并防止内部出修正主义，打起仗来要警惕牛鬼蛇神会出来破坏。要把这个意思告诉中央机要局、机要室，还要告诉军队的机要局、广播事业局的负责同志都要注意。

<a id="L12"></a>**L12**　主席问：如何在机要部门防止出修正主义？

<a id="L13"></a>**L13**　质忠同志答：

<a id="L14"></a>**L14**　（一）活学活用主席著作，加强思想武装思想；

<a id="L15"></a>**L15**　（二）组织干部参加“四清”，并组织机关干部参加劳动和当兵，锻炼革命意志。

<a id="L16"></a>**L16**　主席说：好嘛！青年知识分子就是会出修正主义的。
