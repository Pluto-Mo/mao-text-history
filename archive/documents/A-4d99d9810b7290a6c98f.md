<a id="L4"></a>**L4**　毛泽东

<a id="L5"></a>**L5**　毛泽东会见马里国家元首特拉奥雷的谈话

<a id="L6"></a>**L6**　（1973年6月22日）

<a id="L7"></a>**L7**　【穆萨·特拉奥雷（Moussa Traoré）（1936年9月25日，卡伊，——）马里军事和政治领袖、军人独裁者、外交家、军事活动家、国务活动家。1968年11月19日发动不流血的军事政变，推翻莫迪博·凯塔政权，1968年11月19日-1969年9月19日任马里全国解放军事委员会主席、国家元首；1969年9月19日-1979年6月19日任马里共和国国家元首兼政府首脑。穆萨·特拉奥雷统治马里长达近23年，是马里执政时间最长的总统。1991年3月26日被军事政变推翻。】

<a id="L8"></a>**L8**　毛主席

<a id="L9"></a>**L9**　：我们都是叫作第三世界，就是叫做发展中的国家。你不要看中国有什么展览会啊，其实啊，是一个很穷的国家。我说，I say（英文：我说），越穷越好！就会革命啊。西方国家呢，不大行了。

<a id="L10"></a>**L10**　毛主席

<a id="L11"></a>**L11**　：无论怎么样，这些西方资本主义国家是创造的文化，创造了科学，创造了工业。现在我们第三世界可以处用他们制造商学、工业、文化—包括语言—的好的部分。

<a id="L12"></a>**L12**　拿破仑，无论怎么样，使后人向他表示尊敬。你不要说我是天才，你说拿破仑好了。这样好一点啊，那个人相当聪明。马罗法典，他也读过啊。他所以能创造法国的法典，就是因为他读过罗马法典。而我呢，法国法典也没有读过，罗马法典也没有读过，可见得不行啊。因此请你少吹一点了，我的好朋友啊。

<a id="L13"></a>**L13**　特

<a id="L14"></a>**L14**　：的确，你说的是真实的情况，那些资本家创造了你所说的那些东西。如果我记得对的话，列宁在哪一篇文章中写过，我们要拿起帝国主义的武器攻打帝国主义。

<a id="L15"></a>**L15**　毛主席

<a id="L16"></a>**L16**　：（咳嗽）我也不行了吧，你看。

<a id="L17"></a>**L17**　特

<a id="L18"></a>**L18**　：不。

<a id="L19"></a>**L19**　继续我刚才说的，确实，拿破仑读了你刚才讲的法典，然后又用它来为他的第二祖国制定你刚才所说的法典，因为这个人记性好。

<a id="L20"></a>**L20**　毛主席

<a id="L21"></a>**L21**　：而且推进到了德国的莱茵河流域。

<a id="L22"></a>**L22**　特

<a id="L23"></a>**L23**　：对。

<a id="L24"></a>**L24**　毛主席

<a id="L25"></a>**L25**　：莱茵河以东的德国就得保守，南德意志也不行，全国分为好几个国家，又不统一。

<a id="L26"></a>**L26**　特

<a id="L27"></a>**L27**　：你应该同意我这点意见，即任何事情都是由领袖创造出来的。当然，可以和他的同事讨论。

<a id="L28"></a>**L28**　毛主席

<a id="L29"></a>**L29**　：没有同事不行啊，如果我没有他们（用手指在座的各位中国同志），我也不行啊，话都讲不通。

<a id="L30"></a>**L30**　特

<a id="L31"></a>**L31**　：我说一个人是天才，就是指他的思想。

<a id="L32"></a>**L32**　毛主席

<a id="L33"></a>**L33**　：我是地才（众笑），地是land（英文：土地）吧。

<a id="L34"></a>**L34**　特

<a id="L35"></a>**L35**　：你不信，可以问周恩来总理，我多次向他提过你的名字，并且总理在和我谈话时，也多次提到过。

<a id="L36"></a>**L36**　周总理

<a id="L37"></a>**L37**　：（笑）但没有谈到天才，今天是特别发挥，原来没有讲过这个字，讲过毛泽东思想。

<a id="L38"></a>**L38**　毛主席

<a id="L39"></a>**L39**　：（对特）你也不要强加于我……

<a id="L40"></a>**L40**　特

<a id="L41"></a>**L41**　：强加什么？

<a id="L42"></a>**L42**　毛主席

<a id="L43"></a>**L43**　：天才啊。（特无可奈何地笑，众笑。）咱们讲平等好了，我也不强加于你，你也不强加于我。
