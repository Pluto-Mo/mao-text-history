<a id="L8"></a>**L8**　对中央警卫团支左部队的三点指示

<a id="L9"></a>**L9**　（一九六七年六月二十六日）

<a id="L10"></a>**L10**　一、下去后要做好宣传工作，要做深入的、细致的、艰苦的思想政治工作。厂子里女工多，要派些女同志下去，便于工作。

<a id="L11"></a>**L11**　二、下去后不要匆匆忙忙急于表态，经过调查研究，如果两派都是革命的群众组织，就要逐步地把他们联合起来。就是两派严重对立的群众组织，群众也是愿意联合的，不愿意联合的只是少数的几个头头。

<a id="L12"></a>**L12**　三、要向工人群众学习，不怕犯错误，错了就改。要关心群众生活，组织个医疗组，给他们看病。

<a id="L13"></a>**L13**　（附注：这是主席在中央警卫团即八三四一部队去北京针织总厂及其两个分厂支左临行前所作的指示。十一月十一日，北京针织总厂成立革命委员会，八三四一部队向毛主席报喜，主席当即批示：“看过，很好．谢谢同志们！”）
