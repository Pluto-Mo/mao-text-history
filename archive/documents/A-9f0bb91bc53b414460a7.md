<a id="L9"></a>**L9**　（一九六七年三月）

<a id="L10"></a>**L10**　一、批判要踏实，要调查确实，不然会一风吹。

<a id="L11"></a>**L11**　二、文章要一、二千字，短一点，写一个问题。一个问题说明了就行了。不能超过三千字，长了没人看，看了也记不清。

<a id="L12"></a>**L12**　三、驯服工具论要批判，但也要有无产阶级纪律，服从、团结都是有条件的。四、托拉斯不能都推翻吧？旧名词可以有新内容，主要批判他走资本主义道路。
