<a id="L8"></a>**L8**　在中央常委扩大会上的四点指示

<a id="L9"></a>**L9**　（一九六六年十二月）

<a id="L10"></a>**L10**　一、大家要挺身而出，同群众见面，接受群众的批评，并进行自我批评，引火烧身。

<a id="L11"></a>**L11**　二、大家要挺身而出，向群众解释政策。戴高帽子、抹黑脸的，脱帽洗脸，立即上班工作。

<a id="L12"></a>**L12**　三、从长远利益出发，团结多数。牛鬼蛇神就是地、富、反、坏、右少数。有些人就是犯了严重错误，还得挽救他，使之改过自新。不然，怎么能团结95％以上呢？

<a id="L13"></a>**L13**　四、说服干部，使他们懂得，不要人人过关，都搞得灰溜溜的，两个挺身而出，不要怕字当头。敢字当头，最大的问题也能解决。怕字当头，价钱越来越高。
