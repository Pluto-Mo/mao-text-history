<a id="L9"></a>**L9**　（一九五九年八月）

<a id="L10"></a>**L10**　“游泳是同大自然作斗争的一种运动，你们应该到大江大海去锻炼。”

<a id="L11"></a>**L11**　毛主席轻快自如地领头游着，并风趣地问一位同志：“你说是人怕水，还是水怕人？”

<a id="L12"></a>**L12**　那位同志回答说：“人怕水？”

<a id="L13"></a>**L13**　毛主席笑着说：“我看是水怕人。水怕人压迫他。”

<a id="L14"></a>**L14**　（1959年8月毛主席去九江和江西省歌舞团的同志游泳时的谈话）
