# 资料与发布边界

这是公开研究仓库。原创代码与研究性元数据可以入库；第三方出版物的全文不因可以在线阅读就自动拥有再发布许可。

MIA Charter 第一节区分公版材料、明确标注版权的材料、志愿者原创材料：
https://www.marxists.org/admin/legal/charter.htm

本次没有为每本出版物确认可公开复制全文的授权。因此公共采集器只提交题名、URL、卷册登记、来源定位、哈希与研究摘要，不提交书籍全文或连续长摘录。原始页面只保存在运行器临时 .cache/；工作流不把它们变为可下载artifact。

用户合法提供的文本可通过 corpus.py ingest 进入 local/，该目录被git忽略。取得转载许可后应登记具体权利人、授权范围、依据URL/文件、核验日期，再单独评审公开导入，不能取消所有资料的权利检查。

代码中的robots检查用于访问约束，不是版权许可证明。遇登录、付费或访问控制，不绕过。
