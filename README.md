# 毛泽东文本演变研究库

本仓库用于把作品、不同版次、历史时间线与证据出处连接起来，供 Agent 进行可回溯的文本演变研究。

## 范围

- 《毛泽东选集》：第一至四卷与1977年第五卷分别建档。
- 《建国以来毛泽东文稿》：旧13册与2023年修订20册分别建档。
- 《毛泽东年谱》：旧版建国前／后分组与2023年九卷本分别建档。
- 中文马克思主义文库中的毛泽东资料：主目录及直接关联的集、补卷、1968年武汉版资料。

## 当前状态

远程仓库已初始化，正在提交工具与来源登记。**本提交不代表四套原书全文已收齐。**后续状态以实际清单和校验结果为准，目录、可访问正文、取得的文件、获准转载的文件分别统计。

## 证据规则

1. 作品日期、文本版本日期、出版日期和采集时间分别记录。
2. Git commit 记录研究库的变动，不伪装成1957年的作者提交。
3. 不同网页是文本见证本；文字差异不自动等于历史改稿。
4. 原文、编者说明、研究者解释及待核线索分开。
5. 公开可读不等于获准转载；本公开仓库不上传授权未明确的整套书全文。
