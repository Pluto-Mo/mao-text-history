# 《正处》：第一条可讨论的研究链

从 zhengchu-1957.json 开始。它不是全体中间稿的重建，而是把已知端点、见证本、后出题注、研究转引和查书路线连接起来。

例如询问“阶级斗争的判断何时变化”，先读 E002：那是后出编者题注的说明，不是当前研究者直接持有每个改稿。再读 E003：修改次数存在不同统计口径，但此处取得的是论文转引信息，仍需原书页验证。

1957年的查阅路线：2023九卷本年谱第六卷（E006）。《文稿》旧13册与2023新版20册分别检索；不能把旧版第六册某页迁移到新版同册号。MIA正式文本和标称讲话稿是不同网页见证本，不自动标成相邻两个稿本。

每增加一份材料，先更新来源与收据，再提出可证伪的差异断言。只有标题/日期候选时，不生成虚构的逐字diff。
